<p style="margin: 0 0 1em 0;">19세기 중반, 낭만주의 음악은 크게 두 갈래로 나뉘어 흐름.</p>

<p style="margin: 0 0 1em 0;">리스트와 바그너를 중심으로, 문학이나 회화와 같은 외부의 아이디어와 결합하는 ‘표제음악(Program Music)’과 새로운 형식(교향시 등)을 추구했던 ‘<strong>신독일 악파(New German School)</strong>’임.</p>

<p style="margin: 0 0 1em 0;">그런데, 이러한 흐름에 반대하며 음악 자체의 형식과 논리, 즉 ‘<strong>절대 음악(Absolute Music)</strong>’의 가치를 옹호하는 보수적인 흐름이 있었음. 베토벤과 고전주의 대가들이 완성한 소나타, 교향곡, 실내악과 같은 전통적인 형식이 여전히 심오한 감정을 표현할 수 있는 가장 완벽한 형태라고 생각함.</p>

<p style="margin: 0 0 1em 0;">이런 보수적 낭만주의의 중심이 요하네스 브람스(Johannes Brahms, 1833-1897)임.</p>

<p style="margin: 0 0 1em 0;">브람스는 낭만주의 시대의 풍부한 화성과 서정성을 바탕으로 하면서도, 바흐의 대위법과 베토벤의 구조적 엄격함을 결합하여 논리적이고 견고한 음악을 만들어냄. 그래서 브람스의 음악은 전반적으로 감성을 지성으로 통제하는 듯한 독특한 매력을 보인다고 평가됨.</p>
