<p style="margin: 0 0 1em 0;">바흐는 쾨텐 궁정의 악장시절 레오폴트 대공에게 연봉 400~450탈러를 받았음.</p>

<p style="margin: 0 0 1em 0;">당시 쾨텐 궁정에서 일하던 행정 총 책임자인 궁정 원수가 550탈러였고, 그 다음이 바흐였으니 대단한 대우였음.</p>

<p style="margin: 0 0 1em 0;">쾨텐 궁정은 개혁교파인 칼뱅파로 교회에서 화려한 음악을 쓰는 것을 금지했기 때문에 매주 미사를 위해 마감을 맞춰야 하는 스트레스도 없었고, 레오폴트가 좋아할 만한 음악을 편하게 할 수 있었음.</p>

<p style="margin: 0 0 1em 0;">그러다 레오폴트가 결혼한 새 아내가 음악을 싫어해서 입지가 좁아지고 아들들을 대학에 보내기 위해 라이프치히로 이사를 하면서 라이프치히 시의회에 고용된 칸토르(공무원)으로 일하기 시작함.</p>

<p style="margin: 0 0 1em 0;">이때 기본급으로 연간 100 탈러를 받았고, 바흐가 평생 시의회의 행정관료와 싸우고 스트레스를 받았던 이유임.(말단 행정관료들도 100탈러를 받았음)</p>

<p style="margin: 0 0 1em 0;">시의회는 바흐가 급여 인상을 요구할 때마다 가외로 벌어들이는 부수입을 핑계삼아 거절했다고 함.</p>

<p style="margin: 0 0 1em 0;">하지만, 여가시간이 많아 행사(주로 장례식)를 디니면서 부수입으로 년간 약 600탈러를 더해 쾨텐 시절보다 수입은 높아짐.</p>

<p style="margin: 0 0 1em 0;">- 각종 유산 / 재단에서 나오는 정기금: 약 50탈러</p>

<p style="margin: 0 0 1em 0;">- 결혼식 / 장례식 음악료: 연 400~500탈러 정도(해마다 변동)</p>

<p style="margin: 0 0 1em 0;">- 교회 / 도시 관련 행사 추가 수입: 50~100탈러</p>

<p style="margin: 0 0 1em 0;">이 시기 바흐가 친구와 주고받은 편지에</p>

<p style="margin: 0 0 1em 0;">"올해는 날씨가 너무 좋아서 장례식이 별로 없었다네. 그래서 100탈러를 손해봤다..."라는 한탄이 있는데,</p>

<p style="margin: 0 0 1em 0;">쾨텐 시절 보다 총수입은 늘었지만, 그 때처럼 숙식까지 해결되는 게 아니라서 12~5명이나 되는 대가족을 부양하기에 충분한 금액은 아니었다고 함.</p>

<img src="/images/작곡가들의-수입-(바흐-&-헨델)-2.jpg" alt="작곡가들의 수입 (바흐 & 헨델) 이미지 2" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

<p style="margin: 0 0 1em 0;">반면, 헨델은 영국 런던으로 귀화 후 왕실에서만 연 200~600파운드 정도의 후원을 받았던 것으로 추정됨(출처마다 금액이 다름). 파운드 가치를 당시 독일권의 화폐로 주먹구구로 환산하면, 대략 수천 탈러에 이르는 규모로, 바흐의 소득을 크게 웃도는 수준이었음.</p>

<p style="margin: 0 0 1em 0;">원래 독일에 있던 시절에 헨델은 하노버의 선제후 게오르크 아래서 궁정 악장으로 일했는데, 잠시 여행 간 런던에 무단으로 정착한 것임.</p>

<p style="margin: 0 0 1em 0;">런던에서 앤 여왕의 총애를 받으며 잘 지냈으나, 여왕이 죽고 즉위한 새 왕이 하필이면 헨델이 무단으로 도망쳤던 선제후 게오르크(조지 1세)였음.</p>

<p style="margin: 0 0 1em 0;">헨델은 조지 1세의 마음을 돌리기 위해 템즈강에서 열리는 왕의 뱃놀이에 맞춰 수상음악 을 작곡함. 뱃놀이 당일 헨델은 오케스트라를 배에 태워, 조지 1세와 귀족들이 탄 배 주위를 돌며 이 곡을 연주하고 국왕에게 헌정함.</p>

<p style="margin: 0 0 1em 0;">헨델 작품 번호 348~350, Water Music suite.</p>

<p style="margin: 0 0 1em 0;"><a href="https://www.youtube.com/watch?v=GquYpoKqdZA" target="_blank" style="color: inherit; text-decoration: underline;">https://www.youtube.com/watch?v=GquYpoKqdZA</a></p>

<p style="margin: 0 0 1em 0;">조지 1세는 이 음악이 너무 마음에 들어 헨델을 용서한 건 물론 연금을 두 배로 올려줌.(올려 준 건 썰)</p>

<p style="margin: 0 0 1em 0;">뒤를 이은 조지 2세도 헨델을 끔찍이 아껴서, 대관식 찬가 제사장 사독 작곡을 맡겼는데, 이 곡은 지금도 영국 왕 대관식 때마다 연주하고, 찰스 3세 때도 연주됨.</p>

<p style="margin: 0 0 1em 0;">헨델은 쾨텐 시절의 바흐나 하이든처럼 매일 출근해야하는 종속된 신분이 아니라 왕실이 스폰서로 뒤를 봐주는 자유로운 형태라서 별도로 오페라와 오라토리오(메시아 등) 티켓 판매 수익이나 악보 출판으로도 대단한 수입을 올림.</p>

<p style="margin: 0 0 1em 0;">헨델이 죽을 때 남긴 유산은 2만 파운드였는데,</p>

<p style="margin: 0 0 1em 0;">이것을 당시 재화와 현재를 단순 비교하면 약 400~500만 파운드(80억 ~ 90억 원)이지만, 당시는 인건비가 매우 쌌기 때문에, 2만 파운드가 가진 사회적 고용 능력으로 환산하면 약3,000만~5,000만 파운드(500억 ~ 850억 원)임.</p>

<p style="margin: 0 0 1em 0;">역사학자들이 헨델이 재벌이었다라고 말할 때는 이 소득 가치(약 800억)를 인용한 것임.</p>

<p style="margin: 0 0 1em 0;">바흐는 죽을 때 악기들과 책 만 남겼지만 800억에 달하는 유산을 남긴 헨델과 죽는 방식은 같았으니...</p>
