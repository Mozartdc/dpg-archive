<p style="margin: 0 0 1em 0;">2024년 3월 25일</p>

<p style="margin: 0 0 1em 0;">Current Biology에 올라온 저널인데</p>

<p style="margin: 0 0 1em 0;">유전체 연구진이 간질환 같은 건강 문제를 보려고</p>

<p style="margin: 0 0 1em 0;">베토벤 머리카락에서 DNA 뽑아서 분석하고 있었는데</p>

<p style="margin: 0 0 1em 0;">다른 팀이 그 데이터를 가지고 음악 재능 관련</p>

<p style="margin: 0 0 1em 0;">유전 점수도 계산해보고 정리해서 발표한 것임.</p>

<p style="margin: 0 0 1em 0;">분석 내용은</p>

<p style="margin: 0 0 1em 0;">현대인이 얼마나 박자 감각에</p>

<p style="margin: 0 0 1em 0;">유전적으로 소질이 있는지를 점수화한 걸</p>

<p style="margin: 0 0 1em 0;">베토벤 유전체에 대입해봤더니…</p>

<p style="margin: 0 0 1em 0;">박자 감각 유전자 점수가 9~11퍼센타일!</p>

<p style="margin: 0 0 1em 0;">그러니까 하위권임.</p>

<img src="/images/베토벤의-유전체로부터의-단상-2.png" alt="베토벤의 유전체로부터의 단상 이미지 2" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

<p style="margin: 0 0 1em 0;">그래서 결론은</p>

<p style="margin: 0 0 1em 0;">베토벤이 박자 감각이 하위권이라는 게 맞겠냐?</p>

<p style="margin: 0 0 1em 0;">그러니까 유전적 점수는 예측력도 제한적이고,</p>

<p style="margin: 0 0 1em 0;">절대적인 기준도 아님.</p>

<p style="margin: 0 0 1em 0;">창의성이나 예술성 같은 복합 능력은</p>

<p style="margin: 0 0 1em 0;">유전적 점수 평가로 설명 불가능하다는 것임.</p>

<p style="margin: 0 0 1em 0;">여기까지가 저널의 내용이고</p>

<p style="margin: 0 0 1em 0;">요즘 유전자 기반 예측으로 의학이나 교육학에서</p>

<p style="margin: 0 0 1em 0;">치료계획이나 교육 성취도 평가같은걸</p>

<p style="margin: 0 0 1em 0;">지나치게 남용한다고 생각하는 사람들이 있는데</p>

<p style="margin: 0 0 1em 0;">유전적 소인의 일부만을 반영해서</p>

<p style="margin: 0 0 1em 0;">중요한거 결정하고 그러면 안된다.</p>

<p style="margin: 0 0 1em 0;">환경적 요인이나 윤리적 의식이 필요하다</p>

<p style="margin: 0 0 1em 0;">라는 주장의 일환으로</p>

<p style="margin: 0 0 1em 0;">베토벤의 결과를 발표한듯</p>

<p style="margin: 0 0 1em 0;">혹시 궁금한 사람 있을까봐</p>

<p style="margin: 0 0 1em 0;">저널 다운로드 받을 수 있게 뽑아 옴</p>
