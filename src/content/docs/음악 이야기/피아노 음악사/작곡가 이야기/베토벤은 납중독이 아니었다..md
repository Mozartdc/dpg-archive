<p style="margin: 0 0 1em 0;">베토벤이 1827년 3월에 사망한 직후, 그를 돌보던 의사 안톤 브라우네르트와 친구 안톤 슈인들러 등이 머리카락을 잘라 기념품처럼 보관했음.</p>

<p style="margin: 0 0 1em 0;">베토벤 머리카락 8개 중 5개로 전장 유전체(24×) 복원해 다양한 검사 결과를 발표한 사이트</p>

<img src="/images/베토벤은-납중독이-아니었다.-2.jpg" alt="베토벤은 납중독이 아니었다. 이미지 2" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

<p style="margin: 0 0 1em 0;"><strong><a href="https://www.cam.ac.uk/stories/beethovens-dna-reveals-health-and-family-history-clues" target="_blank" style="color: inherit; text-decoration: underline;">Beethoven's DNA</a></strong></p>

<p style="margin: 0 0 1em 0;"><a href="https://www.cam.ac.uk/stories/beethovens-dna-reveals-health-and-family-history-clues" target="_blank" style="color: inherit; text-decoration: underline;">Scientists have sequenced Beethoven’s genome from locks of his hair, revealing clues to the composer’s health and family history.</a></p>

<p style="margin: 0 0 1em 0;"><a href="https://www.cam.ac.uk/stories/beethovens-dna-reveals-health-and-family-history-clues" target="_blank" style="color: inherit; text-decoration: underline;">www.cam.ac.uk</a></p>

<p style="margin: 0 0 1em 0;">- 유전자 검사를 통하 청력과 위장 문제의 명확한 유전적 원인은 못 찾았지믄 간질환 고위험 유전소인과 B형간염 바이러스 흔적은 확인함. 이를 통해 알코올 섭취와 함께 말기 간질환에 대한 근거를 찾음.</p>

<p style="margin: 0 0 1em 0;">- 현존하는 베토벤의 남계 친족의 Y염색체와 불일치한 것을 통해 과거 누군가 혼외 부친이 있었음을 알아냄. 누군지, 베토벤과 어느정도 관계인지는 알 수 없음.</p>

<p style="margin: 0 0 1em 0;">- 베토벤이 납중독이었다는 검사의 대상이 베토벤 머리카락이 아닌 어떤 여성의 것으로 밝혀져 납중독설은 사실이라고 단정 할 수 없음.</p>

<p style="margin: 0 0 1em 0;">그리고, 간질환 소인 / HBV 감염이 유력한 사망 원인이라고 밝힘.</p>

<p style="margin: 0 0 1em 0;">그 외 다양한 결과들과 검사 자료가 있음.</p>
