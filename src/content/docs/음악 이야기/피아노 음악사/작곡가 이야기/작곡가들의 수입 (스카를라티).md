<p style="margin: 0 0 1em 0;">이탈리아에서 활동하던 스카를라티는 30대 중반에 포르투갈 국왕 주앙 5세의 스카우트를 받아 리스본 궁정 예배당의 지휘자로 취직함.</p>

<p style="margin: 0 0 1em 0;">그리고 국왕의 딸인 마리아 바르바라 공주에게 하프시코드를 가르쳤는데, 공주는 왕족으로서의 지위뿐만 아니라, 하프시코드 연주자로서도 이름을 알릴 만큼 음악적 재능이 뛰어났음.</p>

<img src="/images/작곡가들의-수입-(스카를라티)-2.png" alt="작곡가들의 수입 (스카를라티) 이미지 2" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

<p style="margin: 0 0 1em 0;">이후 공주가 스페인 왕세자(후에 페르난도 6세)와 결혼하게 되었을 때, 음악 선생님을 데려가겠다고 요구하고, 스카를라티는 공주를 따라 스페인 마드리드로 이주해 죽을 때까지 약 30년 동안 개인 음악 교사로 활동함.</p>

<img src="/images/작곡가들의-수입-(스카를라티)-3.gif" alt="작곡가들의 수입 (스카를라티) 이미지 3" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

<p style="margin: 0 0 1em 0;">스카를라티가 이런 화려한 복장으로 초상화를 남길 수 있었던 것은 그가 산티아고 기사단 기사 (Knight of the Order of Santiago) 작위를 받았기 때문임.</p>

<p style="margin: 0 0 1em 0;">초상화의 왼쪽 가슴에 붉은 십자가 브로치가 그 증표임.(포르투갈 국왕 주앙 5세 서임.)</p>

<img src="/images/작곡가들의-수입-(스카를라티)-4.gif" alt="작곡가들의 수입 (스카를라티) 이미지 4" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

<p style="margin: 0 0 1em 0;">스카를라티는 건반 소나타에서는 역사살 가장 많은 작품(555곡)을 님겼고, 건반음악 전체에선 역대 3번째로 많은 곡을 쓴 작곡가임.</p>

<p style="margin: 0 0 1em 0;">- 1위 지몬 제히터 (Simon Sechter). 푸가만 5,000곡을 남김.</p>

<p style="margin: 0 0 1em 0;">- 2위 카를 체르니 (Carl Czerny). op. 861곡.</p>

<p style="margin: 0 0 1em 0;">스카를라티가 이렇게 많은 건반 소나타를 남긴 이유는</p>

<img src="/images/작곡가들의-수입-(스카를라티)-5.gif" alt="작곡가들의 수입 (스카를라티) 이미지 5" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

<p style="margin: 0 0 1em 0;">"스카를라티는 하프시코드 앞에서는 천재였지만, 도박 테이블 앞에서는 바보였다. 여왕이 빚을 갚아주지 않았다면 그는 파멸했을 것이다."</p>

<p style="margin: 0 0 1em 0;">영국의 음악학자 찰스 버니가 쓴 여행기(1771년)에 기록된 내용으로 스카를라티의 가장 친한 친구, 카스트라토 가수인 파리넬리의 인터뷰 내용임.(우리가 아는 그 파리넬리 맞음)</p>

<p style="margin: 0 0 1em 0;">스카를라티는 왕실에서 가장 많은 연봉을 받는 음악가였지만, 심각한 도박 중독자였음.</p>

<img src="/images/작곡가들의-수입-(스카를라티)-6.gif" alt="작곡가들의 수입 (스카를라티) 이미지 6" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

<p style="margin: 0 0 1em 0;">돈을 버는 족족 당시 유행하던 카드 게임 파로(Faro)에 날리고, 빚쟁이들에게 쫒기며 감옥에 갈 위기를 수차례 겪음.</p>

<p style="margin: 0 0 1em 0;">그때마다 마리아 바르바라 왕비가 도박 빚을 대신 갚아주고 그 대가로 내가 연주할 소나타를 써 달라고 해서 그많은 건반 소나타를 작곡한 것임.</p>

<p style="margin: 0 0 1em 0;">1757년 그가 죽었을 때, 재산은커녕 가족들이 당장 길거리에 나앉을 정도로 빚더미였는데, 바르바라 왕비가 빚을 다 갚아주고 스카를라티가 받던 급여 그대로 가족에게 매년 유산으로 지급해줌.</p>

<p style="margin: 0 0 1em 0;">스카를라티 연구의 권위자인 랄프 커크패트릭이 쓴 Domenico Scarlatti(1953, Princeton University Press)라는 책에 보면, 가장 마지막 Appendix편에 왕실 지출 장부를 옮겨놓은 내용에 자세히 나와있음.</p>

<p style="margin: 0 0 1em 0;">keyboard sonata 555곡은 대부분 대물변제곡임.</p>
