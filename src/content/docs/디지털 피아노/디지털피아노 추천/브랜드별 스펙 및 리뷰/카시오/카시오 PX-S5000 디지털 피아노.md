PX-S5000은 2022년에 발표한 Casio Privia PX-S 시리즈 모델로, <a href="/디지털-피아노/디지털피아노-추천/브랜드별-스펙-및-리뷰/카시오/카시오-px-s1100-디지털-피아노/" style="color: inherit; text-decoration: underline;">PX-S1100</a> / <a href="/디지털-피아노/디지털피아노-추천/브랜드별-스펙-및-리뷰/카시오/카시오-px-s3100-디지털-피아노/" style="color: inherit; text-decoration: underline;">PX-S3100</a>이 가진 232mm 초슬림 본체와 미니멀한 디자인은 유지하면서, 건반을 Smart Hybrid Hammer Action으로 바꾸고, 외장 마감과 음향 표현을 더 고급스럽게 다듬은 모델임.


### 건반 / 사운드

PX-S5000은 PX-S1100 / PX-S3100보다 상위 건반인 Smart Hybrid Hammer Action을 사용하는데, 본체 깊이는 232mm로 같아서 피벗도 여전히 짧음. 대신 소재와 소프트웨어로 터치감과 표현력을 보완했음.

흰 건반에 스프루스 목재와 수지 복합 재질을 사용하고 검은 건반은 무광, 흰 건반은 아이보리 느낌의 표면으로 마감함.

또, 건반마다 다른 무게감과 발음 타이밍을 디지털로 보정하는 88-Key Digital Scaling을 적용함. Hammer Response는 4단계와 Off, Key Off Response는 3단계, 터치 감도는 5단계와 Off로 조절 가능함.

구조적으로는 건반 쿠션감이 다르고 액션의 소음도 차이가 남.



<img src="/images/카시오-PX-S5000-디지털-피아노-2.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

사운드는 Multi-dimensional Morphing AiR 음원을 사용함. 피아노 음색은 콘서트 그랜드 계열을 중심으로 하고, 해머 반응, 키오프 반응, 스트링 레조넌스, 댐퍼 레조넌스, 키 액션 노이즈, 댐퍼 노이즈도 구현함.

음색 수는 총 23개임. 그랜드 피아노 3종, 그 외 피아노 7종, 전자피아노 4종, 베이스 1종, 기타 음색 8종으로 구성됨.

최대 동시발음은 192음이라, 페달을 쓰는 일반적인 피아노 연주에서는 충분한 편임. 사운드 보정은 Hall Simulator 4종, Reverb 8종, Surround 2종, Chorus 4종, Brilliance 조절, 일부 음색용 DSP가 들어감.

스피커는 16cm x 8cm 오벌 스피커 2개를 쓰고, 출력은 8W x 2임. PX-S1100 / PX-S3100과 같은 스피커 규격이지만, 상위 라인답게 건반과 사운드 쪽 완성도를 더 높인 모델임.



<img src="/images/카시오-PX-S5000-디지털-피아노-3.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />


### 디자인 및 조작부

PX-S5000은 PX-S1100 / PX-S3100과 같은 초슬림 본체를 씀. 크기는 1322 x 232 x 102mm, 무게는 배터리 제외 11.5kg임. 88건반 해머 액션과 내장 스피커가 있는 모델 중에서는 매우 얇은 편이고, 방이나 거실에 놓았을 때 전자피아노 특유의 부피감이 적음.

디자인은 상판이 평평하고, 블랙 하이글로시 마감과 골드 로고를 사용함. PX-S1100이 단순한 미니멀 디자인이라면, PX-S5000은 같은 방향을 유지하면서 마감이 더 고급스러움



<img src="/images/카시오-PX-S5000-디지털-피아노-4.png" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />



<img src="/images/카시오-PX-S5000-디지털-피아노-5.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

LG 휘센처럼 진짜 금은 아님.

조작부는 터치식 버튼을 사용함. 버튼 수가 많지 않고 화면도 없기 때문에, 세부 기능을 본체에서 바로 만지기는 편하지 않음. 음색 변경, 레조넌스 조정, 메트로놈, 내장곡 같은 기능을 자주 만질 거면 CASIO MUSIC SPACE 앱을 같이 쓰는 편이 훨씬 편함.



<img src="/images/카시오-PX-S5000-디지털-피아노-6.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

PX-S5000은 Layer와 Split을 지원함. 두 음색을 겹치거나, 왼손과 오른손 영역에 다른 음색을 배치할 수 있음. 다만 PX-S3100처럼 자동반주와 리듬을 적극적으로 쓰는 모델은 아니고, 피아노 중심 사용에 필요한 기본 기능을 넣은 쪽에 가까움. Duet Mode도 지원해서, 레슨용으로 같은 음역처럼 나눠 쓰는 것도 가능함.

USB Type B로 유선 MIDI 연결이 가능하고, USB Type A에는 WU-BT10 무선 MIDI 오디오 어댑터를 꽂아 Bluetooth Audio와 Bluetooth MIDI를 사용할 수 있음. 스마트폰 음악을 PX-S5000 스피커로 틀고 같이 연주하거나, 앱으로 본체 설정을 조작할 수 있음.



<img src="/images/카시오-PX-S5000-디지털-피아노-7.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

헤드폰 단자는 3.5mm 스테레오 미니 단자 2개임. Line Out은 L/MONO, R 표준 단자로 따로 있어서 외부 스피커나 오디오 인터페이스에 연결할 수 있음. Audio In은 없고, 외부 음원 재생은 WU-BT10의 Bluetooth Audio를 쓰는 방식임.

페달은 기본 SP-3가 포함되고, 별매 SP-34 3페달 유닛을 쓰면 댐퍼, 소프트, 소스테누토를 사용할 수 있음. 하프페달은 SP-34 연결 시 지원함.

전원은 DC 12V 어댑터를 사용하고, AA 건전지 6개로도 구동 가능함. 배터리 사용 시간은 알카라인 기준 약 4시간임.
