### 건반 / 사운드

AP-S200과 AP-300은 Smart Scaled Hammer Action을 사용함. <a href="/디지털-피아노/디지털-피아노-구매--추천-가이드/5-브랜드별-스펙-및-리뷰/카시오/카시오-px-s1100-디지털-피아노/" style="color: inherit; text-decoration: underline;">PX-S1100</a> / <a href="/디지털-피아노/디지털-피아노-구매--추천-가이드/5-브랜드별-스펙-및-리뷰/카시오/카시오-px-s3100-디지털-피아노/" style="color: inherit; text-decoration: underline;">PX-S3100</a>에 들어가는 Smart Scaled Hammer Action과 같은 건반을 사요왐.

셀비아노 라인이지만 PX-S1100을 콘솔형 캐비닛에 넣고 고정 3페달, 20W + 20W 스피커를 넣은 모델이라고 보는 편이 맞음.

Smart Scaled Hammer Action은 얇은 본체에 넣기 위해 소형화한 해머 액션이고, 소재나 디지털 제어로 터치감과 표현력을 보완한 방식이라 건반 안쪽으로 갈수록 누르는 데 힘이 더 들어가고 불편함.

건반마다 다른 무게감과 발음 타이밍은 88-Key Digital Scaling으로 디지털로 보정하는 함. Hammer Response는 4단계와 Tone, Off, Key Off Response도 지원함. 키를 누를 때의 반응과 뗄 때의 댐핑 뉘앙스를 모두 디지털로 보정하는 방식임.

흰 건반은 아이보리 느낌의 표면으로 마감하고, 검은 건반은 에보니 느낌의 질감 처리가 들어감. 터치 감도는 5단계와 Off로 조절 가능함.



<img src="/images/카시오-AP-S200-AP-300-디지털-피아노-4.webp" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

사운드는 Multi-Dimensional Morphing AiR 음원을 사용함. 피아노 음색은 그랜드 피아노 계열이 중심이고, 스트링 레조넌스, 댐퍼 레조넌스, 키 액션 노이즈, 댐퍼 노이즈 같은 어쿠스틱 시뮬레이션도 들어감.

음색 수는 총 19개임. 기본 피아노와 전자피아노, 오르간, 스트링 등 피아노 연주에 필요한 음색만 넣은 구성임. 최대 동시발음은 192음임. 페달을 쓰는 일반적인 피아노 연주에서는 충분한 편임.

사운드 보정은 Hall Simulator 4종, Reverb 4종, Surround, Chorus, Brilliance, 일부 음색용 DSP가 들어감. 작은 볼륨에서도 저역과 고역의 밸런스를 보정하는 Volume Sync EQ도 지원함.

스피커는 12cm 스피커 2개를 쓰고, 출력은 20W + 20W임. AP-300은 AP-S200과 같은 2스피커 구성이지만, 더 깊은 캐비닛과 상판 개폐 기능으로 캐비닛 울림과 소리 확산 방향에서 차이가 있음.


### 디자인 및 조작부

AP-S200의 크기는 1393 x 299 x 802mm이고, 무게는 34.0kg임.

AP-300의 크기는 1401 x 440 x 869mm이고, 무게는 47.1kg임. 상판 개폐가 가능하고, 전체적인 외형도 전통적인 콘솔형 디지털 피아노에 더 가까움.

색상은 블랙, 화이트, 브라운 계열이 있음. AP-S200은 블랙 우드, 화이트 우드, 로즈우드 계열의 슬림형 가구 느낌이고, AP-300은 블랙, 화이트, 브라운 계열의 클래식 캐비닛 느낌에 가까움.

두 모델 모두 슬라이드형 키 커버가 들어감. AP-S200은 슬림형 캐비닛에 맞춘 키 커버를 쓰고, AP-300은 키 커버와 함께 상판 개폐 기능도 들어감. AP-300은 상판을 열면 소리 확산과 외형에서 조금 더 어쿠스틱 피아노 같은 느낌을 줄 수 있음.

조작부는 터치 버튼 6개와 Tone Select 버튼 1개를 사용함. 본체 버튼 수가 많지 않아서 세부 설정은 CASIO MUSIC SPACE 앱을 같이 쓰는 편이 편함. 음색 변경, 터치 감도, 레조넌스, 메트로놈, 내장곡 같은 기능을 앱에서 다루기 좋음.

AP-S200과 AP-300은 Layer와 Split을 지원함. 두 음색을 겹치거나, 왼손과 오른손 영역에 다른 음색을 배치할 수 있음. Duet Mode도 지원해서, 레슨용으로 같은 음역처럼 나눠 쓰는 것도 가능함.



<img src="/images/카시오-AP-S200-AP-300-디지털-피아노-5.webp" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

USB Type B로 유선 MIDI 연결이 가능하고, USB Type A에는 WU-BT10 무선 MIDI 오디오 어댑터를 꽂아 Bluetooth Audio와 Bluetooth MIDI를 사용할 수 있음. 스마트폰 음악을 본체 스피커로 틀고 같이 연주하거나, 앱으로 본체 설정을 조작할 수 있음.

헤드폰 / 출력 단자는 스테레오 표준 단자 2개임. 별도 Line Out은 없고, 외부 스피커나 오디오 인터페이스로 보낼 때는 PHONES / OUTPUT 단자를 같이 쓰는 방식임.

AP-S200과 AP-300은 고정 3페달이 기본 포함됨. 댐퍼, 소프트, 소스테누토를 지원하고, 하프댐퍼도 지원함. AP-S200은 댐퍼 페달 2단계와 하프댐퍼를 지원하고, 소프트 페달은 일반 소프트 방식임. AP-300은 댐퍼 페달과 소프트 페달 모두 2단계 조절을 지원함.

AP-300은 높낮이 조절 벤치와 헤드폰 걸이가 기본 구성품에 포함됨. AP-S200은 WU-BT10, 보면대, AC 어댑터가 기본 구성품이고, 벤치는 별매임.

전원은 DC 24V 어댑터를 사용함
