PX-S6000은 2022년에 발표한 Casio Privia PX-S 시리즈 모델로, <a href="/디지털-피아노/디지털-피아노-구매--추천-가이드/5-브랜드별-스펙-및-리뷰/카시오/카시오-px-s7000-디지털-피아노/" style="color: inherit; text-decoration: underline;">PX-S7000</a>, <a href="/디지털-피아노/디지털-피아노-구매--추천-가이드/5-브랜드별-스펙-및-리뷰/카시오/카시오-px-s5000-디지털-피아노/" style="color: inherit; text-decoration: underline;">PX-S5000</a>과 함께 나온 상위 라인 모델임. S5000과 동일한 Smart Hybrid Hammer Action을 적용하고, 256음 동시발음, 350음색, 4스피커 Spatial Sound System, LCD 화면, 피치벤드 휠, 노브, 마이크 입력을 넣은 모델임.

PX-S5000에 음색 수, 조작부, 스피커, 실시간 컨트롤, 마이크 입력을 크게 추가한 모델임. <a href="/디지털-피아노/디지털-피아노-구매--추천-가이드/5-브랜드별-스펙-및-리뷰/카시오/카시오-px-s3100-디지털-피아노/" style="color: inherit; text-decoration: underline;">PX-S3100</a>처럼 200리듬 자동반주를 넣은 편곡용 모델은 아니고, 피아노 연주와 라이브 컨트롤, 음색 활용 기능을 추가한 것임.


### 건반 / 사운드

PX-S6000은 Smart Hybrid Hammer Action을 사용함. PX-S5000, PX-S7000과 같은 건반이고, 흰 건반에는 스프루스 목재와 수지 복합 재질을 사용하고, 흰 건반과 검은 건반 모두 질감 처리가 들어감.



<img src="/images/카시오-PX-S6000-디지털-피아노-2.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

PX-S5000과 같은 건반인 Smart Hybrid Hammer Action을 사용하는데, 본체 깊이는 232mm로 같아서 피벗도 여전히 짧음. 대신 소재와 소프트웨어로 터치감과 표현력을 보완했음.

흰 건반에 스프루스 목재와 수지 복합 재질을 사용하고 검은 건반은 무광, 흰 건반은 아이보리 느낌의 표면으로 마감함.

또, 건반마다 다른 무게감과 발음 타이밍을 디지털로 보정하는 88-Key Digital Scaling을 적용함. Hammer Response는 4단계와 Off, Key Off Response는 3단계, 터치 감도는 5단계와 Off로 조절 가능함.

구조적으로는 건반 쿠션감이 다르고 액션의 소음도 차이가 남.



<img src="/images/카시오-PX-S6000-디지털-피아노-3.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

사운드는 Multi-dimensional Morphing AiR 음원을 사용함. 피아노 음색은 Privia Grand 계열 3종이 중심이고, 해머 반응, 키오프 반응, 스트링 레조넌스, 댐퍼 레조넌스, 키 액션 노이즈, 댐퍼 노이즈도 구현함.

음색 수는 총 350개임. 그랜드 피아노 3종, 다양한 피아노 12종, 클래식 전자피아노 계열, GM 음색, 드럼 세트, 기타 음색까지 들어감. 최대 동시발음은 256음임.

사운드 보정은 Hall Simulator 8종, Reverb 8종, Surround 3종, Chorus 12종, Brilliance 25단계, DSP 100프리셋과 편집 기능이 들어감. 마이크 이펙트도 25종 지원함.

PX-S6000은 50종 아르페지에이터를 지원함. PX-S3100처럼 리듬과 자동반주를 중심으로 쓰는 모델은 아니지만, 코드나 패턴을 잡고 음색을 움직이는 용도로는 활용 가능함. 레지스트레이션은 96개까지 저장 가능해서, 자주 쓰는 음색 조합, 레이어, 스플릿, 이펙트 세팅을 저장해 두고 불러올 수 있음.



<img src="/images/카시오-PX-S6000-디지털-피아노-4.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

스피커는 16cm x 8cm 오벌 스피커 4개를 쓰고, 출력은 8W x 2 + 8W x 2임. 배터리 구동 시에는 3W x 2 + 3W x 2로 줄어듦. PX-S5000보다 스피커 수와 출력이 늘었고, 4채널 4스피커 Spatial Sound System을 사용함. Piano Position 기능도 있어 스탠드 위, 벽 근처, 방 중앙, 테이블 위 같은 설치 위치에 따라 소리 보정을 바꿀 수 있음.


### 디자인 및 조작부

PX-S6000은 크기는 1340 x 242 x 102mm, 무게는 배터리 제외 14.8kg임. PX-S5000보다 깊이는 10mm 늘고 무게도 늘었지만, 88건반 해머 액션과 4스피커, LCD, 마이크 입력까지 들어간 모델치고는 여전히 얇은 편임.



<img src="/images/카시오-PX-S6000-디지털-피아노-5.png" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

조작부는 터치 버튼, LED Touch Ring, 백라이트 풀도트 LCD 화면을 사용함. PX-S5000은 화면이 없어서 앱 의존도가 높은 편인데, PX-S6000은 본체에서 음색, 기능, 설정을 다루기 훨씬 편함. 음색 수가 350개이고 DSP와 레지스트레이션까지 들어간 모델이라, 화면과 조작부 차이가 실제 사용성이 좋아짐.

PX-S6000은 Layer와 Split을 지원함. 두 음색을 겹치거나, 왼손과 오른손 영역에 다른 음색을 배치할 수 있음. Duet Mode도 지원해서, 레슨용으로 같은 음역처럼 나눠 쓰는 것도 가능함.



<img src="/images/카시오-PX-S6000-디지털-피아노-6.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />



<img src="/images/카시오-PX-S6000-디지털-피아노-7.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

PX-S6000에는 피치벤드 휠과 노브 2개, Control 버튼이 들어감. 노브는 필터 컷오프, 레조넌스, 어택, 릴리즈, DSP 파라미터 같은 값을 실시간으로 조절하는 용도임.

USB Type B로 유선 MIDI 연결이 가능하고, USB Type A에는 WU-BT10 무선 MIDI 오디오 어댑터를 꽂아 Bluetooth Audio와 Bluetooth MIDI를 사용할 수 있음. 스마트폰 음악을 PX-S6000 스피커로 틀고 같이 연주하거나, 앱으로 본체 설정을 조작할 수 있음.

헤드폰 단자는 6.3mm 스테레오 표준 단자 1개와 3.5mm 스테레오 미니 단자 1개임. Line Out은 L/MONO, R 표준 단자로 따로 있고, Mic In도 있어 마이크를 연결할 수 있음. 마이크 볼륨 노브와 마이크 이펙트도 지원해서, 간단한 보컬 연주나 라이브용으로 쓸 수 있음.

페달은 기본 SP-3가 포함됨. PX-S6000은 기본 페달을 Expression / Assignable 단자에 연결하는 방식이고, 별매 SP-34 3페달 유닛을 쓰면 댐퍼, 소프트, 소스테누토를 사용할 수 있음. 하프페달은 SP-34 연결 시 지원함. Expression / Assignable 단자에는 일반 익스프레션 페달도 연결 가능함.

전원은 DC 24V 어댑터를 사용하고, AA 건전지 8개로도 구동 가능함. 배터리 사용 시간은 알카라인 기준 약 4시간임.
