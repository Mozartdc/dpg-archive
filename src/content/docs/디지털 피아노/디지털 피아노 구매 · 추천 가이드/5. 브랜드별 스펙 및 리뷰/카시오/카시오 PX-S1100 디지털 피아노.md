PX-S1100은 2021년에 발표한 Casio Privia PX-S 시리즈 모델로, 기존 PX-S1000의 후속기임. PX-S1000의 232mm 초슬림 본체와 미니멀한 디자인은 유지하면서, 스피커 내부 설계와 음향 표현, 무선 연결성을 개선한 모델임. 함께 발표한 <a href="/디지털-피아노/디지털-피아노-구매--추천-가이드/5-브랜드별-스펙-및-리뷰/카시오/카시오-px-s3100-디지털-피아노/" style="color: inherit; text-decoration: underline;">PX-S3100</a>과 88건반 Smart Scaled Hammer Action, Multi-dimensional Morphing AiR 음원, 192음 동시발음, 18음색, 16cm x 8cm 오벌 스피커 2개, WU-BT10 무선 MIDI 오디오 어댑터를 공유함.


### 건반 / 사운드

PX-S1100은 Smart Scaled Hammer Action을 사용함. 깊이 232mm의 본체에 맞춰 작게 설계한 해머 액션이고, 건반마다 다른 무게감과 발음 타이밍을 디지털로 보정하는 88-Key Digital Scaling을 적용함.

터치 감도는 5단계와 Off로 조절 가능함. PX-S1100은 해머 액션으로 얇고 휴대하기 쉬운 본체에 맞춰 피벗을 짧게 만들어 건반 안쪽을 누를 때, 특히 코드를 잡을 때 깊이감이나 무게감이 동급의 디지털 피아노보다 불편하다는 평이 많음.

사운드는 Multi-dimensional Morphing AiR 음원을 사용함. 피아노 음색은 독일 콘서트 그랜드가 메인이고, 해머 반응, 키오프 반응, 스트링 레조넌스, 댐퍼 레조넌스, 키 액션 노이즈, 댐퍼 노이즈도 구현함.

음색 수는 피아노와 전자피아노, 오르간, 스트링 등 기본 연주에 필요한 음색만 넣은 구성으로 총 18개임. 최대 동시발음은 192음이라, 페달을 쓰는 일반적인 피아노 연주에서는 충분한 편임. 스피커는 16cm x 8cm 오벌 스피커 2개를 쓰고, 출력은 8W x 2임. PX-S1000보다 내부 스피커 구조를 개선해서 고역의 선명도와 저역의 반응을 다듬은 모델임.


### 디자인 및 조작부



<img src="/images/카시오-PX-S1100-디지털-피아노-2.png" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />



<img src="/images/카시오-PX-S1100-디지털-피아노-3.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

PX-S1100의 가장 큰 특징은 얇은 본체임. 크기는 1322 x 232 x 102mm, 무게는 배터리 제외 11.2kg임. 88건반 해머 액션과 내장 스피커가 있는 모델 중에서는 매우 얇은 편이고, 방이나 거실에 놓았을 때 전자피아노 특유의 부피감이 적음. 디자인은 상판이 평평하고, 조작부는 터치식 버튼을 사용함. 전원이 꺼져 있을 때는 버튼이 거의 드러나지 않아서, 전체적으로 가구나 인테리어 소품처럼 보이게 만든 모델임. 다만 조작부가 미니멀한 만큼, 세부 기능을 본체에서 바로 만지기는 어렵고 CASIO MUSIC SPACE 앱을 써야 음색 변경, 레조넌스 조정, 메트로놈, 내장곡 같은 기능을 쓰기 편함.

PX-S1100은 Layer와 Split을 지원함. 두 음색을 겹치거나, 왼손과 오른손 영역에 다른 음색을 배치할 수 있음. Duet Mode도 지원해서, 레슨용으로 같은 음역처럼 나눠 쓰는 것도 가능함.

USB Type B로 유선 MIDI 연결이 가능하고, USB Type A에는 WU-BT10 무선 MIDI 오디오 어댑터를 꽂아 Bluetooth Audio와 Bluetooth MIDI를 사용할 수 있음. 스마트폰 음악을 PX-S1100 스피커로 틀고 같이 연주하거나, 앱으로 본체 설정을 조작할 수 있음.

헤드폰 단자는 3.5mm 스테레오 미니 단자 2개임. Line Out은 L/MONO, R 표준 단자로 따로 있어서 외부 스피커나 오디오 인터페이스에 연결할 수 있음. 페달은 기본 SP-3가 포함되고, 별매 SP-34 3페달 유닛을 쓰면 댐퍼, 소프트, 소스테누토를 사용할 수 있음. 하프페달은 SP-34 연결 시 지원함.

전원은 DC 12V 어댑터를 사용하고, AA 건전지 6개로도 구동 가능함.
