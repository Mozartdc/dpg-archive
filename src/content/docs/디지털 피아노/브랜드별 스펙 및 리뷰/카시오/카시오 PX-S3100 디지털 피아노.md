PX-S3100은 2021년에 발표한 Casio Privia PX-S 시리즈 모델로, 기존 PX-S3000의 후속기임.

함께 발표한 <a href="/디지털-피아노/브랜드별-스펙-및-리뷰/카시오/카시오-px-s1100-디지털-피아노/" style="color: inherit; text-decoration: underline;">PX-S1100</a>과 232mm 초슬림 본체, 88건반 Smart Scaled Hammer Action, Multi-dimensional Morphing AiR 음원, 192음 동시발음, 16cm x 8cm 오벌 스피커 2개, WU-BT10 무선 MIDI 오디오 어댑터를 공유함.

PX-S1100은 피아노 중심 기본기능만 있고, PX-S3100은 같은 본체와 건반에 음색, 리듬, 자동반주, LCD, 피치벤드 휠, 노브, 레지스트레이션을 넣은 확장형 모델임.


### 건반 / 사운드

PX-S3100은 Smart Scaled Hammer Action을 사용함. 깊이 232mm의 본체에 맞춰 작게 설계한 해머 액션이고, 건반마다 다른 무게감과 발음 타이밍을 디지털로 보정하는 88-Key Digital Scaling을 적용함.

터치 감도는 5단계와 Off로 조절 가능함. PX-S3100은 PX-S1100과 같은 해머 액션이라 건반감 자체가 상위 모델은 아님. 얇고 휴대하기 쉬운 본체에 맞춰 피벗을 짧게 만든 액션이라, 건반 안쪽을 누를 때, 특히 코드를 잡을 때 깊이감이나 무게감이 동급의 일반 디지털 피아노보다 불편하다는 평이 많음.



<img src="/images/카시오-PX-S3100-디지털-피아노-2.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

사운드는 Multi-dimensional Morphing AiR 음원을 사용함. 피아노 음색은 독일 콘서트 그랜드가 메인이고, 해머 반응, 키오프 반응, 스트링 레조넌스, 댐퍼 레조넌스, 키 액션 노이즈, 댐퍼 노이즈도 구현함.

PX-S3100은 피아노, 전자피아노, 오르간, 스트링, 신스, 브라스, 기타, 베이스, 드럼 계열까지 넓게 넣은 모델임. 최대 동시발음은 192음으로 일반적인 피아노 연주에서는 충분한 편임.

PX-S3100은 200개 리듬과 자동반주를 지원함. 그래서 단순 피아노 연습용이라기보다, 코드 반주를 잡고 리듬을 깔거나 여러 음색을 바꿔 쓰는 실용음악용 포터블 피아노에 가까움. 아르페지에이터 100종, 뮤직 프리셋 310개, 오토 하모나이즈 12종도 들어감.

스피커는 16cm x 8cm 오벌 스피커 2개를 쓰고, 출력은 8W x 2임. PX-S1100과 같은 스피커 규격이고, PX-S1000 / PX-S3000 세대보다 고역의 선명도와 저역의 반응을 개선한 모델임.


### 디자인 및 조작부

PX-S3100은 PX-S1100과 같은 초슬림 본체를 씀. 크기는 1322 x 232 x 102mm, 무게는 배터리 제외 11.4kg임. 88건반 해머 액션과 내장 스피커, 자동반주 기능이 들어간 모델치고는 매우 얇은 편이고, 디지털 피아노 특유의 부피감도 없음.



<img src="/images/카시오-PX-S3100-디지털-피아노-3.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />



<img src="/images/카시오-PX-S3100-디지털-피아노-4.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

디자인은 상판이 평평하고, 조작부는 터치식 버튼과 LCD 화면을 사용함. PX-S1100보다 버튼과 화면이 많아서 세부 기능을 본체에서 다루기 훨씬 편함. 음색 수가 700개이고 리듬도 200개라, PX-S1100처럼 앱에만 의존하면 불편한 모델인데, PX-S3100은 본체 조작부 자체가 기능형으로 구성되어 있음.



<img src="/images/카시오-PX-S3100-디지털-피아노-5.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

PX-S3100은 Layer와 Split을 지원함. 두 음색을 겹치거나, 왼손과 오른손 영역에 다른 음색을 배치할 수 있음. Duet Mode도 지원해서, 레슨용으로 같은 음역처럼 나눠 쓰는 것도 가능함.

PX-S3100에는 피치벤드 휠과 노브 2개가 들어감. 피아노만 칠 때는 큰 의미가 없지만, 신스, 기타, 브라스, 리드 음색을 쓸 때 표현을 더할 수 있음. 레지스트레이션은 96개까지 저장 가능해서, 자주 쓰는 음색 조합이나 리듬 세팅을 저장해 두고 불러올 수 있음.

USB Type B로 유선 MIDI 연결이 가능하고, USB Type A에는 WU-BT10 무선 MIDI 오디오 어댑터를 꽂아 Bluetooth Audio와 Bluetooth MIDI를 사용할 수 있음. 스마트폰 음악을 PX-S3100 스피커로 틀고 같이 연주하거나, 앱으로 본체 설정을 조작할 수 있음.



<img src="/images/카시오-PX-S3100-디지털-피아노-6.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

헤드폰 단자는 3.5mm 스테레오 미니 단자 2개임. Line Out은 L/MONO, R 표준 단자로 따로 있고, Audio In도 있어서 외부 기기 소리를 본체로 받을 수 있음. Expression / Assignable 단자도 들어가 PX-S1100보다 연결성이 더 넓음.

페달은 기본 SP-3가 포함되고, 별매 SP-34 3페달 유닛을 쓰면 댐퍼, 소프트, 소스테누토를 사용할 수 있음. 하프페달은 SP-34 연결 시 지원함.

전원은 DC 12V 어댑터를 사용하고, AA 건전지 6개로도 구동 가능함. 다만 PX-S3100은 기능이 많은 모델이라 배터리 사용 시간은 PX-S1100보다 짧은 편임.
