PX-S7000은 2022년에 발표한 Casio Privia PX-S 시리즈 모델로, <a href="/디지털-피아노/브랜드별-스펙-및-리뷰/카시오/카시오-px-s6000-디지털-피아노/" style="color: inherit; text-decoration: underline;">PX-S6000</a>, <a href="/디지털-피아노/브랜드별-스펙-및-리뷰/카시오/카시오-px-s5000-디지털-피아노/" style="color: inherit; text-decoration: underline;">PX-S5000</a>과 함께 나온 상위 라인 모델임. S6000과 동일한 Smart Hybrid Hammer Action을 적용하고, 256음 동시발음, 400음색, 4스피커 Spatial Sound System, LCD 화면, 피치벤드 휠, EX 버튼, 마이크 입력, 고정 스탠드, 고정 3페달 유닛을 넣은 모델임.

<a href="/디지털-피아노/브랜드별-스펙-및-리뷰/카시오/카시오-px-s6000-디지털-피아노/" style="color: inherit; text-decoration: underline;">카시오 PX-S6000 디지털 피아노</a>

거의 모든 사양은 위 PX-6000과 동일함.

PX-S7000에서 추가된 사양은

- 음색 수가 총 400개로 늘어나 그랜드 피아노, 전자피아노, 오르간, 스트링, 신스, 기타, 베이스, 드럼 계열까지 들어감. 또, 대중음악에서 자주 쓰였던 피아노 사운드를 모아 Best-Hit Pianos를 만들어, 특정 곡 분위기에 맞춘 가공된 음색을 쓸 수 있음.

- 고정 스탠드 / 고정 3페달 유닛 / 금속 프레임

- 색상과 인테리어형 외장 / LED 조명 연동



<img src="/images/카시오-PX-S7000-디지털-피아노-2.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

PX-S7000에서 변경된 사양은

- PX-S6000의 노브 2개 대신 EX 버튼 2개가 들어감.

EX 버튼은 값을 돌려 조절하는 컨트롤 노브가 아니라, Arpeggio On/Off, Layer, Split, Sustain, Registration 호출, 앱 재생 제어 같은 기능을 배정해 두고 빠르게 호출하는 단축 버튼임. 그래서 실시간으로 음색 파라미터를 만지는 용도는 PX-S6000의 노브가 더 직관적이고, PX-S7000의 EX 버튼은 자주 쓰는 기능을 바로 켜고 끄는데 적합함.
