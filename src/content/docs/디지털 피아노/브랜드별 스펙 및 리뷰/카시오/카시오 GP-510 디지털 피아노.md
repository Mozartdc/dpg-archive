GP-510은 2019년에 나온 CELVIANO Grand Hybrid 최상위 모델임. GP-310과 같은 Natural Grand Hammer Action, AiR Grand 음원, 256음 동시발음, 4채널 6스피커 Grand Acoustic System을 쓰고, 35가지 음색과 추가 공명 조절, Scene, 유광 블랙 마감을 더한 모델임.

건반과 세 가지 그랜드 피아노 음색, 스피커 구성은 GP-310과 같음. GP-510에 더 들어간 기능은 기본 타건감이나 출력보다 음색 편집과 설정 저장, 외장 마감에 집중돼 있음. GP-310만으로도 연주와 직접 관련된 구조는 대부분 얻을 수 있지만, 여러 곡에 맞춘 음색과 홀 설정을 저장해 바꿔 쓰거나 공명을 세밀하게 조정하려면 GP-510이 편함.


### 건반 / 음원

GP-510은 Natural Grand Hammer Action을 사용함. 길게 만든 스프루스 목재 키스틱 뒤쪽에 별도의 ABS 해머를 달아, 건반을 누르면 해머가 어쿠스틱 그랜드 피아노와 같은 수직 방향으로 올라감.



<img src="/images/카시오-GP-510-디지털-피아노-2.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />



<img src="/images/카시오-GP-510-디지털-피아노-3.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

일반 디지털 피아노는 작은 금속 해머 웨이트가 건반 아래에서 회전하지만, GP-510은 건반 뒤쪽 해머의 운동과 무게로 관성을 만듦. 건반 앞뒤의 무게 차이가 작고, 눌렀을 때 내려가는 감각과 손을 뗀 뒤 돌아오는 움직임도 일반 디지털 피아노 액션보다 그랜드 피아노에 가까움.

해머는 현을 때리거나 소리를 만드는 부품이 아님. 건반의 관성과 복귀 반응을 만들려고 넣은 기계 장치임. 현을 때릴 필요가 없으므로 목재와 펠트로 만든 무거운 어쿠스틱 해머 대신 규격을 일정하게 만들기 쉬운 ABS 해머를 사용함. 온도와 습도에 따른 변형이 적고, 펠트 마모나 해머 정렬도 관리할 필요가 없음.

어쿠스틱 그랜드 액션의 잭과 레피티션 레버, 렛오프 기구는 들어가지 않음. 건반을 천천히 누를 때 손끝에 걸리는 렛오프 감각도 없음. 부품 수를 줄여 동작을 단순하게 만들고 반복 타건과 복귀 속도를 확보했지만, 어쿠스틱 액션의 이중 이탈 구조와 렛오프 직전의 저항 변화까지 재현하지는 못함.

이 구조 때문에 Yamaha AvantGrand와 Kawai NOVUS처럼 어쿠스틱 그랜드 액션 전체를 넣은 하이브리드와는 차이가 있음.

GP-510은 실제 그랜드 액션을 센서로 읽는 모델이 아니라, 긴 목재 키스틱과 별도 해머를 중심으로 그랜드 피아노의 관성을 재구성한 디지털 피아노 액션임.

타건감은 무겁게 버티기보다 처음부터 부드럽게 내려가고, 바닥에는 완충감이 있음. 빠른 반복도 비교적 자연스럽지만 렛오프가 없어서 어쿠스틱 그랜드 특유의 걸림은 느껴지지 않음. 전작인 GP-500보다 액션의 유격과 규제가 개선됐고, 무게와 반복 속도, 바닥 완충이 어쿠스틱 피아노에 가까워졌다고 평가됨.

흰 건반 표면은 일반적인 아이보리 질감보다 매끈한 아크릴 마감에 가까우며, 새 제품을 만지면 손에 조금 달라붙는 느낌이 있음.

터치 감도는 5단계와 Off로 조절 가능함. GP-500보다 약한 타건의 벨로시티 반응과 다이내믹 범위를 다듬었으며, Hammer Response는 10단계와 Off로 조절할 수 있음.

음원은 AiR Grand를 사용함. 최대 동시발음은 256음이고, 전체 음색은 35개임.

중심이 되는 그랜드 피아노 음색은 Berlin Grand, Hamburg Grand, Vienna Grand 세 가지이며, 각 음색에 Mellow와 Bright 변형이 따로 들어감.

Berlin Grand는 C. Bechstein과 공동 개발한 음색임. 어택이 또렷하고 음색 변화가 선명하며, 중·고역의 색채가 잘 드러남. 인상주의 음악이나 여러 성부를 분명하게 나눠야 하는 곡에 잘 맞음.

Hamburg Grand는 저음과 어택이 강하고 다이내믹 범위가 넓음. 세 음색 중 가장 익숙한 콘서트 그랜드 성향이며, 클래식부터 재즈와 대중음악까지 무난하게 사용할 수 있음.

Vienna Grand는 저음이 두껍고 어택이 둥글며, 세 음색 중 가장 부드럽고 어두운 편임. 고전주의와 낭만주의 음악에서 따뜻한 소리를 만들기 쉬움.

세 음색은 단순히 EQ만 바꾼 프리셋이 아니라 어택, 감쇠, 다이내믹 변화와 공명 성향이 서로 다름. GP-510은 GP-500보다 음의 감쇠 시간을 늘리고 약한 타건의 반응을 다듬음.

GP-510에는 Damper Resonance와 String Resonance 외에 Open String Resonance와 Aliquot Resonance가 들어감. 댐퍼가 없는 고음 현과 알리쿼트 현에서 생기는 공명까지 따로 조절할 수 있으며, 각 공명과 기계 소음은 대부분 10단계와 Off로 설정 가능함.

Damper Noise, Pedal Action Noise, Key On Action Noise, Key Off Action Noise도 조절할 수 있음. GP-310보다 어쿠스틱 피아노의 부수적인 울림과 기계 소리를 세밀하게 맞출 수 있지만, 값을 지나치게 올리면 음색보다 효과음이 먼저 들릴 수 있음.

소프트 페달은 음량만 줄이지 않고 타건 세기에 따라 음색 변화도 함께 계산함. 약하게 칠 때와 강하게 칠 때 소프트 페달의 효과가 다르게 나타남.

Hall Simulator는 12가지 공간과 4가지 청취 위치를 지원함. Chorus 4종, Brilliance, 일부 음색용 DSP, Headphone Mode, Volume Sync EQ도 들어감.

스피커는 16cm 우퍼 2개, 10cm 미드레인지 2개, 5cm 트위터 2개로 구성한 3웨이 6스피커 시스템임. 출력은 30W x 2 + 20W x 2, 총 100W임.

상단 스피커는 열린 상판 쪽으로 소리를 보내고, 하단 우퍼는 바닥 방향으로 저음을 확산함. 좌우 스테레오만 넓히는 방식보다 연주자 위쪽과 피아노 아래쪽에서 함께 소리가 퍼짐. 실제 향판을 울리는 CA901과는 구조가 다르지만, 작은 콘솔형 스피커보다 소리의 높이와 깊이가 잘 느껴지는 편임.

본체 상판은 실제로 열 수 있으며, 상판을 열면 상단 스피커의 확산 방향도 달라짐. Lid Simulator 설정까지 함께 바꿔야 음원 속 상판 상태와 실제 상판 위치를 맞출 수 있음.

디자인 / 기능

GP-510의 크기는 1,434 x 489 x 963mm이고, 무게는 78.5kg임. GP-310과 크기와 무게가 같지만 GP-510은 블랙 폴리시 유광 마감만 제공함.

전면에는 Berlin Grand, Hamburg Grand, Vienna Grand 전용 버튼과 백라이트 LCD, 설정 버튼을 배치함. AP 시리즈처럼 앱을 열어야 세부 설정을 확인하는 구조가 아니며, 음색과 공명, 홀, 녹음, Scene 설정을 본체 화면에서 직접 바꿀 수 있음.

Scene은 음색, Layer와 Split, 홀, 효과와 각종 연주 설정을 묶어서 저장하는 기능임. 프리셋 Scene 15개와 사용자 Scene 10개를 지원함. 곡이나 작곡가별로 음색과 공간 설정을 만들어 두고 한 번에 불러올 수 있음.

Layer와 Split, Duet Mode를 지원함. 두 음색을 겹치거나 건반 좌우에 다른 음색을 배치할 수 있으며, Duet Mode에서는 좌우 영역을 같은 음역으로 맞출 수 있음.

Concert Play는 오케스트라 녹음 15곡을 제공함. 감상 모드와 연주 모드가 있으며, 원래 템포의 80%로 낮춰 연습할 수 있음. 피아노 파트와 반주 음량도 따로 조절 가능함.

Music Library는 60곡이고 사용자 MIDI 곡은 10곡까지 저장할 수 있음. MIDI 녹음은 1곡, 2트랙, 약 5,000음까지 지원함. USB 메모리를 연결하면 44.1kHz 스테레오 WAV로 최대 99곡, 곡당 약 25분까지 오디오 녹음할 수 있음.

USB Type B로 컴퓨터와 MIDI 연결이 가능하고, USB Type A에는 USB 메모리를 연결함. 표준 MIDI IN과 OUT 단자도 따로 있음.

LINE IN과 LINE OUT은 각각 L/MONO와 R 표준 단자로 제공함. 헤드폰 단자는 스테레오 표준 단자 2개임. 스피커를 끄고 Line Out만 사용하거나, 스피커 보정 EQ를 출력 단자에도 적용할지 선택할 수 있어서 녹음과 교육용 헤드폰 시스템에 연결하기 편함.

Bluetooth Audio와 Bluetooth MIDI는 지원하지 않으며 WU-BT10도 사용할 수 없음.

3페달은 댐퍼, 소프트, 소스테누토로 구성됨. 댐퍼 페달은 연속 감지 방식이고 하프페달 기준 위치를 5단계로 조절할 수 있음. 소프트 페달은 타건 세기에 따라 음량과 음색을 함께 바꿈.

높낮이 조절 벤치, 보면대, 악보집, 헤드폰 걸이와 전원 어댑터가 기본 구성품에 포함됨.


### 타 브랜드 비교 모델

GP-510은 구조적으로는 풀사이즈 목재 건반과 실제로 움직이는 해머를 쓰기 때문에 Yamaha AvantGrand N1X / N3X, Kawai NOVUS NV12 같은 하이브리드 피아노와 비교할 수 있음. 다만 AvantGrand와 NOVUS는 실제 어쿠스틱 그랜드 액션을 사용하고, GP-510은 디지털 피아노용으로 만든 Natural Grand Hammer Action이라 구조는 다름.
