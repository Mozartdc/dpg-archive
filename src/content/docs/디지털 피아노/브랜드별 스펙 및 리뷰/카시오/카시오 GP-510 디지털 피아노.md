GP-510은 2019년에 나온 CELVIANO Grand Hybrid 플래그십 모델임. 풀사이즈 목재 건반과 실제 해머를 사용한 Natural Grand Hammer Action, AiR Grand 음원, 256음 동시발음, 4채널 6스피커 시스템을 갖춤.


### 건반 / 사운드

Natural Grand Hammer Action은 오스트리아산 가문비나무 건반을 그랜드 피아노와 같은 길이와 피벗 위치로 배치함. 건반을 누르면 실제 해머가 그랜드 피아노처럼 위로 움직이고, 삼중 센서가 타건을 읽음. 흰 건반은 아크릴, 검은 건반은 페놀 표면을 사용함.



<img src="/images/카시오-GP-510-디지털-피아노-2.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

AiR Grand 음원에는 Berlin Grand, Hamburg Grand, Vienna Grand가 들어감. Berlin Grand는 C. Bechstein D282를 연구하고 C. Bechstein의 감수를 받아 개발했음. 맑고 균형 잡힌 Berlin, 화려하고 폭넓은 Hamburg, 따뜻한 저음이 두드러지는 Vienna를 곡에 맞춰 고를 수 있음.

음색은 35개이고 최대 동시발음은 256음임. <a href="/디지털-피아노/브랜드별-스펙-및-리뷰/카시오/카시오-gp-310-디지털-피아노/" style="color: inherit; text-decoration: underline;">GP-310</a>보다 음색이 9개 많고, 오픈 스트링 공명과 앨리쿼트 공명, 페달 동작음도 추가됨. 스트링 공명과 댐퍼 공명, 해머 반응, 키오프 반응, 댐퍼 노이즈, 건반 동작음까지 각각 조절할 수 있음.

장면(Scene)은 음색과 효과, 홀 시뮬레이터 설정을 한 번에 묶어 불러오는 기능임. 작곡가나 장르에 맞춘 프리셋 15개가 들어 있고, 사용자가 만든 설정도 10개까지 저장할 수 있음.


### 스피커 / 디자인



<img src="/images/카시오-GP-510-디지털-피아노-3.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

Grand Acoustic System은 4채널 3웨이 6스피커 구조임. 16cm 스피커 2개가 저음을 맡고 10cm와 5cm 스피커가 중·고역을 위와 아래로 퍼뜨림. 출력은 30W x 2와 20W x 2로 총 100W임.

상판을 열면 위쪽 스피커의 소리가 직접 퍼지고, 닫으면 소리가 본체 안에서 반사됨. 리드 시뮬레이터도 네 단계로 조절하지만 실제 상판 위치와 자동으로 연동되지는 않음. Volume Sync EQ와 헤드폰 모드도 지원함.



<img src="/images/카시오-GP-510-디지털-피아노-4.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

크기는 1,434 x 489 x 963mm, 무게는 78.5kg임. GP-310과 본체 규격은 같지만 유광 블랙과 금색 장식으로 마감했음. 슬라이드식 건반 덮개, 백라이트 풀 도트 LCD, 세 그랜드 음색 전용 버튼을 갖춤.


### 연주 / 녹음 기능

그랜드 페달 시스템은 댐퍼 위치를 연속으로 감지하고 하프페달 시작점을 다섯 단계로 조절함. GP-510은 여기에 페달 동작음까지 더해 페달을 밟을 때 나는 기계음도 재현함.

뮤직 라이브러리 60곡과 Concert Play 15곡을 제공함. MIDI는 1곡 2트랙, 약 5,000음까지 녹음함. USB 메모리에는 연주를 44.1kHz 16bit 스테레오 WAV로 녹음하며 최대 99곡, 곡당 약 25분까지 저장할 수 있음.

Layer, Split, Duet Mode를 지원함. Line In과 Line Out, USB Type A와 Type B, MIDI, 스테레오 표준 헤드폰 단자 2개를 갖췄음. Bluetooth 오디오나 전용 앱 연결은 지원하지 않음.


### 카시오 내부 비교 모델

GP-310은 건반과 음원 계열, 스피커, 크기와 무게가 같음. GP-510을 고를 이유는 35개 음색, 추가 공명과 페달 동작음, 장면 저장, 유광 외장에 있음. <a href="/디지털-피아노/브랜드별-스펙-및-리뷰/카시오/카시오-ap-750-디지털-피아노/" style="color: inherit; text-decoration: underline;">AP-750</a>은 더 작고 가벼운 콘솔형 본체와 8스피커를 쓰지만, 건반은 풀사이즈 그랜드 액션이 아닌 Smart Hybrid Hammer Action임.
