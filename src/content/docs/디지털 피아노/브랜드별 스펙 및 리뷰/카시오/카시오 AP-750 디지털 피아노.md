AP-750은 <a href="/디지털-피아노/브랜드별-스펙-및-리뷰/카시오/카시오-ap-s450--550-디지털-피아노/" style="color: inherit; text-decoration: underline;">AP-S450</a> / <a href="/디지털-피아노/브랜드별-스펙-및-리뷰/카시오/카시오-ap-s450--550-디지털-피아노/" style="color: inherit; text-decoration: underline;">AP-550</a>과 같은 2024년형 CELVIANO 라인업의 최상위 모델임.

Smart Hybrid Hammer Action Keyboard CELVIANO Edition은 AP-S450 / AP-550과 같지만, 음원이 Multi-Dimensional Morphing AiR에서 AiR Grand로 바뀌고 4채널 8스피커 Grandphonic Sound System이 들어감.

AP-S450 / AP-550과 같은 건반을 사용하고, GP 시리즈의 음원과 상위 스피커 시스템을 적용한 모델임.


### 건반 / 사운드

AP-750은 Smart Hybrid Hammer Action Keyboard CELVIANO Edition을 사용함. AP-S450 / AP-550과 같은 건반이고, <a href="/디지털-피아노/브랜드별-스펙-및-리뷰/카시오/카시오-px-s5000-디지털-피아노/" style="color: inherit; text-decoration: underline;">PX-S5000</a> / <a href="/디지털-피아노/브랜드별-스펙-및-리뷰/카시오/카시오-px-s6000-디지털-피아노/" style="color: inherit; text-decoration: underline;">PX-S6000</a> / <a href="/디지털-피아노/브랜드별-스펙-및-리뷰/카시오/카시오-px-s7000-디지털-피아노/" style="color: inherit; text-decoration: underline;">PX-S7000</a>에 사용하는 Smart Hybrid Hammer Action 계열을 CELVIANO에 맞게 조정한 모델임.



<img src="/images/카시오-AP-750-디지털-피아노-2.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

PX-S7000의 Smart Hybrid Hammer Action을 콘솔형 캐비닛에 넣으면서 그에 맞게 조정했다고 하지만, 피벗 길이가 늘어나거나 센서 등의 조정을 한 건 아니라 타건감은 포터블과 동일함.

특히 건반 안쪽을 누를 때 느껴지는 불편함도 그대로임.

다만 콘솔로 조립하면서 키베드의 차이가 있어, 안정감과 바닥감이 더 단단함.

해머 액션은 저음으로 갈수록 무겁고 고음으로 갈수록 가벼워지는 스케일드 방식임. 88-Key Digital Scaling으로 건반마다 다른 발음 특성과 음량을 디지털로 보정함.

Hammer Response는 건반을 누른 시점부터 실제 소리가 시작되는 시간을 해머 무게에 맞춰 조절하는 기능임. 4단계와 Tone, Off를 지원함. Key Off Response는 건반을 뗄 때 음이 줄어드는 반응을 보정함.

흰 건반은 아이보리 느낌의 표면으로 마감하고 검은 건반은 에보니 느낌의 질감 처리가 들어감. 터치 감도는 5단계와 Off로 조절 가능함.

사운드는 AiR Grand 음원을 사용함.

AP-S450 / AP-550의 Multi-Dimensional Morphing AiR보다 상위 음원이고, Grand Hybrid GP 시리즈에 사용하는 세 종류의 유럽 그랜드 피아노 음색을 가져온 구성임.

Berlin Grand (C. Bechstein과 공동으로 만든 음색)

Hamburg Grand

Vienna Grand

세 음색은 단순히 EQ와 밝기만 바꾼 음색이 아니라 서로 다른 피아노를 샘플링한 별도의 그랜드 피아노 음색임. 건반을 약하게 칠 때와 강하게 칠 때의 음색 변화, 감쇠 길이, 공명 성향도 각각 다름.

최대 동시발음은 256음이고 음색은 총 39개임. 그랜드 피아노 외에 업라이트 피아노, 전자피아노, 오르간, 하프시코드, 비브라폰, 스트링, 베이스 계열 음색이 들어감.



<img src="/images/카시오-AP-750-디지털-피아노-3.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

Piano Tone은 음색 자체뿐 아니라 레조넌스와 기계음 설정을 포함한 하나의 피아노 캐릭터로 구성됨. Berlin, Hamburg, Vienna를 고른 뒤 레조넌스와 밝기, 상판 상태를 따로 조절할 수 있음.

Piano Position 기능이 있어 피아노를 벽에 붙였을 때, 벽에서 떨어뜨렸을 때, 방 가운데 두었을 때처럼 설치 위치에 따라 저음과 반사음이 달라지는 현상을 보정할 수 있음.

스피커는 12cm 스피커 4개와 3.5cm 스피커 4개를 사용하는 4채널 8스피커 Grandphonic Sound System임.

출력은 10W + 10W + 10W + 10W로 총 40W임.

AP-550도 최대 출력은 20W + 20W라 합계 출력은 같지만, AP-750은 4개의 독립 채널과 8개의 스피커로 음역과 소리 방향을 나눠서 재생함.



<img src="/images/카시오-AP-750-디지털-피아노-4.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

저음과 중저음은 캐비닛 하단과 내부의 12cm 스피커가 담당하고, 중고음과 직접음은 3.5cm 스피커가 여러 방향으로 내보냄. 단순히 음량을 크게 만드는 구성보다 그랜드 피아노에서 저음과 고음이 서로 다른 위치와 방향으로 퍼지는 현상을 구현함.


### 디자인 및 조작부

AP-750의 크기는 1401 x 440 x 929mm이고 무게는 53.6kg임. AP-550과 폭과 깊이는 같지만 높이가 조금 더 높고, 8스피커 시스템이 들어가면서 무게도 4.1kg 늘어남.

색상은 블랙, 화이트, 브라운 계열이 있음.

슬라이드형 키 커버를 사용하고, 높낮이 조절 벤치와 헤드폰 걸이가 기본 구성품에 포함됨.

조작부는 건반 왼쪽과 전면에 배치한 터치 센서 버튼을 사용함. 전원을 켜면 버튼에 불이 들어오고 사용하지 않을 때는 표시를 끌 수 있음.



<img src="/images/카시오-AP-750-디지털-피아노-5.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

화면이 따로 없어서 본체만으로 세부 기능을 조작할 때는 터치 버튼과 건반을 같이 사용함. 음색이나 레조넌스, 이펙트 등은 CASIO MUSIC SPACE 앱을 통해 설정하는 것이 편함.

건반 앞쪽에는 Visual Information Bar가 들어감. 긴 LED 바를 이용해서 메트로놈 박자, 타건 세기, 댐퍼 페달을 밟은 깊이와 Instant RePlayer의 재생 위치를 표시함.

타건 세기 표시를 사용하면 건반을 약하게 칠 때와 강하게 칠 때 LED가 다르게 반응해서 다이내믹을 눈으로 확인할 수 있음. 페달 표시를 사용하면 연속 감지되는 댐퍼 페달의 깊이도 확인할 수 있어서 하프 페달 연습에 활용할 수 있음.

Instant RePlayer는 녹음 버튼을 미리 누르지 않아도 최근 연주를 계속 임시 저장하는 기능임. 방금 연주한 부분을 다시 듣거나 Visual Information Bar를 이용해 원하는 위치로 이동할 수 있음.

Scenes 기능도 들어감. 음색과 레조넌스, 홀과 리버브 같은 설정을 하나로 묶어 불러오는 프리셋임. 작곡가와 시대, 연주 장소를 기준으로 만든 기본 Scene 10개가 들어가고 사용자 설정도 10개까지 저장할 수 있음.

조작부 잠금 기능도 있어서 연주 중 터치 버튼을 잘못 눌러 설정이 바뀌는 것을 막을 수 있음.
