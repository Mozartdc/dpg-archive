GP-310은 2019년에 나온 CELVIANO Grand Hybrid 모델로,  GP-510과 같은 Natural Grand Hammer Action, AiR Grand 음원, 256음 동시발음, 4채널 6스피커 Grand Acoustic System을 사용하고 음색과 공명 기능, Scene, 외장 마감 등에서 비용을 절감한 모델임.

GP-510보다 하위 모델이지만 건반과 세 가지 그랜드 피아노 음색, 스피커 시스템은 같음. 35가지 음색과 추가 공명, 설정 저장, 유광 마감이 필요하지 않다면 GP-310에서도 연주와 직접 관련된 기본 구조는 그대로 얻을 수 있음.


### 건반 / 음원

Natural Grand Hammer Action에는 오스트리아산 가문비나무로 만든 풀사이즈 목재 건반과 별도의 해머 기구가 들어감. 건반 길이는 약 16인치이고, 피벗 위치와 해머가 올라가는 방향도 중형 그랜드 피아노에 가깝게 설계했음. 타건은 삼중 센서로 읽음. 흰 건반 표면은 아크릴, 검은 건반은 페놀로 마감했음.

AP 시리즈는 건반 뒤쪽의 웨이트로 무게감을 만들지만, GP-310은 건반을 누르면 별도의 해머가 실제로 위로 움직임. 해머의 질량과 움직임에서 관성과 반작용이 생기고, 긴 피벗 덕분에 건반 안쪽을 눌러도 무게가 크게 늘지 않음.

해머는 목재 샹크와 펠트 헤드 대신 ABS 성형 부품으로 만들었음. 실제 현을 때리지 않으므로 펠트의 탄성이나 목재 샹크의 변형까지 재현할 필요가 없음. 카시오는 타건에 필요한 질량과 관성만 남기고 부품 수와 조정 지점을 줄였음.

어쿠스틱 그랜드 액션의 잭과 레피티션 레버도 생략했음. 현을 때리기 직전에 잭이 빠지면서 손끝에 걸리는 렛오프 노치는 없음. 삼중 센서가 건반 위치를 읽고 단순한 해머 기구가 바로 복귀해서 반복 타건은 빠른 편임.

눌리는 과정은 매끄럽고 반복 타건도 빠름. 그 대신 잭이 빠질 때의 저항 변화와 레피티션 레버의 움직임은 손끝에 전달되지 않음. 어쿠스틱 그랜드 액션을 통째로 넣은 Yamaha AvantGrand N1X, Kawai NOVUS NV10S와 갈리는 지점임.

AiR Grand 음원에는 Berlin Grand, Hamburg Grand, Vienna Grand가 들어감. Berlin Grand는 C. Bechstein D282를 바탕으로 C. Bechstein과 공동 개발한 음색임.

Berlin Grand는 중심이 또렷하고 음역 간 균형이 잘 잡힌 편임. Hamburg Grand는 음역이 넓고 고음이 화려하며, Vienna Grand는 저음이 두껍고 둥글게 퍼짐. 세 음색은 밝기만 달리한 프리셋이 아니며 어택, 감쇠, 저음의 성격까지 서로 다름.

이전 GP-300과 비교하면 약하게 눌렀을 때의 다이내믹 표현이 넓어졌고 음의 감쇠도 길어졌음. 최대 동시발음은 256음이고 음색은 26개임.

스트링 공명, 댐퍼 공명, 해머 반응, 키오프 반응, 댐퍼 노이즈, 건반을 누르고 뗄 때의 동작음, 리드 시뮬레이터를 조절할 수 있음. GP-510에 들어간 오픈 스트링 공명, 앨리쿼트 공명, 페달 동작음과 Scene 저장은 빠졌음.


### 디자인 / 기능



<img src="/images/카시오-GP-310-디지털-피아노-5.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

Grand Acoustic System은 4채널 앰프와 3웨이 6스피커로 구성됨. 16cm 스피커 2개가 저음을 내고, 10cm와 5cm 스피커가 중·고음을 위아래로 나눠 내보냄. 출력은 30W x 2와 20W x 2로 총 100W임.

상판을 열면 위쪽 스피커의 직접음이 늘고, 닫으면 본체 안에서 반사된 소리가 더 많이 섞임. 상판을 직접 열고 닫아도 리드 시뮬레이터 설정은 바뀌지 않으므로 둘은 따로 조절해야 함.

저음은 캐비닛 아래에서 올라오고 중·고음은 상판 쪽으로 퍼져 일반 콘솔형보다 소리가 나는 높이와 방향이 분명함. 상판을 닫으면 고음이 한층 얌전해지고, 열면 중·고음이 직접적으로 들림. 작은 음량에서는 Volume Sync EQ가 저음과 고음의 손실을 보완함.



<img src="/images/카시오-GP-310-디지털-피아노-6.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

크기는 1,434 x 489 x 963mm이고 무게는 78.5kg임. 본체 규격은 GP-510과 같음. GP-310BK는 유광 도장과 금색 장식을 빼고 반사가 적은 새틴 블랙으로 마감했음.

슬라이드식 건반 덮개와 백라이트 풀 도트 LCD가 들어감. Berlin, Hamburg, Vienna Grand는 전용 버튼으로 바로 고를 수 있고, 나머지 설정은 화면과 방향 버튼으로 조작함.

그랜드 페달 시스템은 댐퍼 페달의 위치를 연속으로 읽음. 하프페달이 시작되는 지점은 다섯 단계로 조절할 수 있음. 소프트 페달을 밟으면 음량과 음색이 함께 달라짐.

뮤직 라이브러리 60곡과 오케스트라 반주가 붙은 Concert Play 15곡이 들어감. 본체 MIDI 레코더는 1곡 2트랙, 약 5,000음까지 저장함. USB 메모리에는 44.1kHz 16bit 스테레오 WAV로 최대 99곡을 저장할 수 있고, 곡당 녹음 시간은 약 25분임.

Layer, Split, Duet Mode를 지원함. 단자는 Line In과 Line Out, USB Type A와 Type B, MIDI IN / OUT, 스테레오 표준 헤드폰 단자 2개가 있음. Bluetooth Audio와 Bluetooth MIDI는 지원하지 않으며 WU-BT10도 사용할 수 없음.


### 타 브랜드 비교 모델

Yamaha <a href="/디지털-피아노/브랜드별-스펙-및-리뷰/야마하/야마하-n1x-하이브리드-디지털-피아노/" style="color: inherit; text-decoration: underline;">AvantGrand N1X</a>, Kawai NOVUS NV10S

N1X와 NV10S에는 어쿠스틱 그랜드 피아노의 잭, 위펜, 레피티션 레버와 해머 기구가 그대로 들어감. GP-310은 풀사이즈 목재 건반과 별도 해머만 남기고 액션을 단순화해 본체 크기와 가격을 낮췄음.

Roland <a href="/디지털-피아노/브랜드별-스펙-및-리뷰/롤랜드/롤랜드-lx9-디지털-피아노/" style="color: inherit; text-decoration: underline;">LX9</a>은 가격대가 비슷한 상위 디지털 피아노임. 어쿠스틱 해머 기구는 없으며, Roland 제품군에는 GP-310과 액션 구조가 직접 대응하는 모델이 없음.

<a href="/디지털-피아노/브랜드별-스펙-및-리뷰/카시오/카시오-gp-510-디지털-피아노/" style="color: inherit; text-decoration: underline;">GP-510</a>은 건반과 스피커가 같지만 음색이 35개로 늘고 공명 기능과 장면 저장 기능이 추가됨. <a href="/디지털-피아노/브랜드별-스펙-및-리뷰/카시오/카시오-ap-750-디지털-피아노/" style="color: inherit; text-decoration: underline;">AP-750</a>은 AiR Grand 음원과 256음 동시발음을 공유하지만, 짧은 Smart Hybrid Hammer Action을 쓰는 일반 콘솔형 모델임. 풀사이즈 피벗과 실제 해머 구조를 우선하면 GP-310 쪽이 분명한 상위 구조임.
