AP-S450과 AP-550은 2024년에 함께 발표된 Casio CELVIANO AP 시리즈 중상급 디지털 피아노임. 두 모델은 Smart Hybrid Hammer Action Keyboard CELVIANO Edition, Multi-Dimensional Morphing AiR 음원, 256음 동시발음, 26음색, 12cm 스피커 2개와 3.5cm 스피커 2개, 20W + 20W 출력, 고정 3페달, WU-BT10 무선 MIDI 오디오 어댑터를 공유함.



<img src="/images/카시오-AP-S450-550-디지털-피아노-1.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

가장 큰 차이는 AP-S450은 깊이 299mm의 슬림형 모델이고, AP-550은 깊이 440mm의 일반 콘솔형 모델임.

또, 상판 개폐 기능과 Lid Simulator는 AP-550에만 적용하고, 높낮이 조절 벤치도 550에만 기본 포함임.

그 외, 건반과 음원, 출력은 같고 캐비닛 구조와 상판, 페달 구성에서 차이가 있음.


### 건반 / 사운드

AP-S450과 AP-550은 Smart Hybrid Hammer Action Keyboard CELVIANO Edition을 사용함.

<a href="/디지털-피아노/브랜드별-스펙-및-리뷰/카시오/카시오-ap-s200--ap-300-디지털-피아노/" style="color: inherit; text-decoration: underline;">AP-S200</a> / <a href="/디지털-피아노/브랜드별-스펙-및-리뷰/카시오/카시오-ap-s200--ap-300-디지털-피아노/" style="color: inherit; text-decoration: underline;">AP-300</a>에 들어가는 Smart Scaled Hammer Action보다 상위 건반이고, <a href="/디지털-피아노/브랜드별-스펙-및-리뷰/카시오/카시오-px-s5000-디지털-피아노/" style="color: inherit; text-decoration: underline;">PX-S5000</a> / <a href="/디지털-피아노/브랜드별-스펙-및-리뷰/카시오/카시오-px-s6000-디지털-피아노/" style="color: inherit; text-decoration: underline;">PX-S6000</a> / <a href="/디지털-피아노/브랜드별-스펙-및-리뷰/카시오/카시오-px-s7000-디지털-피아노/" style="color: inherit; text-decoration: underline;">PX-S7000</a>에 사용하는 Smart Hybrid Hammer Action을 CELVIANO에 맞게 조정한 모델임.



<img src="/images/카시오-AP-S450-550-디지털-피아노-2.png" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />



<img src="/images/카시오-AP-S450-550-디지털-피아노-3.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

약하게 누를 때 건반 움직임이 더 자연스럽고 연속 타건을 안정적으로 만들기 위해 카운터웨이트를 적용하고, 흰 건반 내부에 스프루스 목재와 수지를 결합한 하이브리드 구조를 사용함.

건반마다 다른 무게감과 발음 타이밍은 88-Key Digital Scaling으로 보정함. Hammer Response와 Key Off Response도 지원해서 타건과 릴리즈 반응을 세밀하게 조절할 수 있음.

흰 건반은 아이보리 느낌의 표면, 검은 건반은 에보니 느낌의 질감 처리가 들어감. 터치 감도는 5단계와 Off를 지원함.

이전 Smart Scaled Hammer Action보다 건반 반응이 좋아졌고 기계적인 소음도 줄었다는 평도 많고, 이 가격대에서 목재를 사용한 하이브리드 건반이라는 점도 장점임.

다만 피벗이 짧은 포터블 액션을 조정한 구조라 건반 안쪽으로 갈수록 무게가 조금 더 느껴지는 특성은 그대로 있음.

사운드는 Multi-Dimensional Morphing AiR 음원을 사용하고, 최대 동시발음은 256음, 음색은 총 26개임.

피아노 음색은 그랜드 피아노 계열이 중심이고, String Resonance, Damper Resonance, Damper Noise, Key On Action Noise, Key Off Action Noise 같은 어쿠스틱 시뮬레이션을 지원함.

Hall Simulator, Reverb, Surround, Chorus, Brilliance도 지원하고 Headphone Mode도 들어감.

두 모델 모두 12cm 스피커 2개와 3.5cm 스피커 2개를 사용하는 4스피커 구성이며 출력은 20W + 20W임.

AP-550은 스피커 자체는 AP-S450과 같지만 캐비닛이 더 크고 상판 개폐 기능이 있어서 저음 울림과 소리 확산이 조금 더 자연스러움.

AP-S450도 슬림형 캐비닛치고는 스피커 성능이 좋은 편이라는 평가가 많고, AP-550은 같은 출력에서도 공간감이 조금 더 크게 느껴지는 편임.


### 디자인 및 조작부

AP-S450의 크기는 1393 x 299 x 866mm이고 무게는 37.6kg임.



<img src="/images/카시오-AP-S450-550-디지털-피아노-4.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

AP-550의 크기는 1401 x 440 x 891mm이고 무게는 49.5kg임.



<img src="/images/카시오-AP-S450-550-디지털-피아노-5.png" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

색상은 블랙 우드, 화이트 우드, 브라운 세 종류이고, 모델 모두 슬라이드형 키 커버를 사용함.

AP-550은 상판을 열 수 있고 Lid Simulator도 지원해서 상판 개방 상태에 맞춰 소리의 밝기를 조절할 수 있음.

조작부는 터치 버튼을 사용함. 사용하지 않을 때는 버튼 표시가 꺼져서 외형이 깔끔한 편임.

세부 설정은 CASIO MUSIC SPACE 앱을 같이 사용하는 편이 편함. 음색, 터치 감도, 레조넌스, 메트로놈, 내장곡 등을 화면에서 쉽게 바꿀 수 있음.

Visual Information Bar도 새롭게 들어감. 건반 앞쪽 LED를 이용해서 타건 세기, 페달 움직임, 메트로놈 등을 표시하는 기능임.

Instant RePlayer도 지원함. 최근 연주를 자동으로 저장해서 방금 연주한 내용을 바로 다시 들어볼 수 있음.

AP-S450과 AP-550은 Layer와 Split을 지원함. 왼손 영역에는 Bass 음색을 배치할 수 있고 Duet Mode도 지원해서 레슨용으로 같은 음역처럼 나눠 사용할 수 있음.

USB Type B로 유선 MIDI 연결이 가능하고 USB Type A에는 WU-BT10 무선 MIDI 오디오 어댑터를 연결해서 Bluetooth Audio와 Bluetooth MIDI를 사용할 수 있음.

스마트폰 음악을 본체 스피커로 재생하거나 CASIO MUSIC SPACE 앱으로 본체 설정을 조작할 수 있음.

헤드폰 / 출력 단자는 스테레오 표준 단자 2개임. 별도 Line Out은 없고 PHONES / OUTPUT 단자를 같이 사용하는 방식임.

AP-S450과 AP-550은 고정 3페달이 기본 포함되고, 댐퍼 페달은 연속 감지를 지원함.

AP-S450은 슬림형 페달 유닛을 사용하고 AP-550은 더 큰 금속 페달 유닛을 사용함. AP-550은 소프트 페달도 3단계 조절을 지원함.

AP-550은 높낮이 조절 벤치가 기본 구성품에 포함되고 AP-S450은 별매임.
