2026년 새로 출시한 YDP-166 / YDP-S56은 ARIUS라는 보급형 라인인데도 전작 GH3를 그대로 쓰지 않고 GrandTouch-E를 새로 개발해서 넣었고, escapement까지 추가했음. 음원과 기본 사운드 사양은 큰 변화가 없지만 건반 액션을 새로 만든 셈이라 꽤 의미가 큼.

YDP-166은 일반 콘솔형이고 YDP-S56은 본체 깊이를 줄인 슬림형임.



<img src="/images/야마하-YDP-166-YDP-S56-디지털-피아노-2.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />



<img src="/images/야마하-YDP-166-YDP-S56-디지털-피아노-3.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />


### 건반 / 사운드

이번 세대에서 가장 크게 바뀐 부분은 건반임. YDP-165와 YDP-S55의 GH3 대신 새 GrandTouch-E가 들어감.

88건반 그레이드 웨이티드 해머 액션이며 흰 건반은 인조상아, 검은 건반은 합성 흑단 질감으로 마감함. 렛오프도 들어감.



<img src="/images/야마하-YDP-166-YDP-S56-디지털-피아노-4.gif" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

스트로크는 10mm이고 저음에서 고음으로 갈수록 건반 무게가 가벼워짐. 터치 감도는 Hard, Medium, Soft, Fixed 네 단계임.

빠른 반복 타건에서는 건반이 완전히 올라오기 전에 다시 눌러야 할 때가 있음. GrandTouch-E는 트리플 센서라 이런 타건에서 2센서 GHS보다 여유가 있음. 전작 GH3도 이미 트리플 센서였으므로 이번 변화는 센서 수보다 액션 자체에 있음.

피아노 음원은 Yamaha CFX 콘서트 그랜드 샘플임. 최대 동시발음은 192음이고 전체 음색은 10개임.

VRM Lite에는 Key-Off Effect, Smooth Release, Damper Resonance, Sympathetic Resonance가 들어감. 하위 YDP-146 / YDP-S36보다 공명 항목이 많고, 리버브는 4종임.

전작에서 볼륨을 낮추면 저음과 고음이 먼저 약해지는 문제를 Intelligent Acoustic Control이 그 균형을 보정함. 헤드폰에서는 Stereophonic Optimizer가 소리가 귀 바로 옆에 붙는 느낌을 줄여 줌.

스피커는 두 모델 모두 12cm 두 개, 출력은 20W + 20W임.

이번 세대에는 스피커 앞에 디퓨저 그릴을 넣었음. 고역이 한쪽으로 바로 뻗지 않고 연주자 주변으로 더 넓게 퍼짐. Piano는 캐비닛 크기에 비해 소리 규모가 크게 느껴지고, 건반 위쪽으로 퍼지는 폭도 전보다 넓어짐.



<img src="/images/야마하-YDP-166-YDP-S56-디지털-피아노-5.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

YDP-S56도 12cm 스피커 두 개와 20W + 20W 출력을 그대로 씀. 캐비닛만 얇아졌고 스피커 사양은 동일함.


### 디자인 및 조작부

YDP-166은 그동안 써오던 ARIUS 콘솔형 캐비닛으로, 크기는 1357 x 422 x 849mm이고 무게는 42kg임. 보면대를 세우면 높이는 1003mm임.

키 커버는 본체 안쪽에서 앞으로 당겨 닫는 슬라이드형이고, 별도 보면대에는 악보 고정 브레이스가 달려 있음.

YDP-S56은 166보다 깊이가 309mm까지 줄였고, 키 커버를 세우면 깊이 317mm, 높이 976mm, 전도 방지 브래킷까지 포함한 바닥 깊이는 382mm임. 무게는 40kg임.

접이식 덮개를 세워 보면대로 쓰고 닫으면 건반 위까지 평평해짐.

방이 좁으면 일반 콘솔형보다 자리 잡기가 편함.

두 모델은 캐비닛만 다르고 나머지 기능이나 디자인은 그대로임. 페달도 댐퍼, 소스테누토, 소프트의 고정 3페달로 같고, 댐퍼에는 하프페달이 들어감.

둘 다 디스플레이가 없고 왼쪽 버튼과 건반 조합으로 설정함. 음색 선택 정도는 본체에서 바로 할 수 있지만, 세부 설정은 설명서를 찾아봐야 할 만큼 조작부가 단순해서 설정을 자주 바꾼다면 Smart Pianist를 같이 쓰는 편이 편함.



<img src="/images/야마하-YDP-166-YDP-S56-디지털-피아노-6.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

두 음색을 겹치는 Dual과 건반을 같은 음역 두 구역으로 나누는 Duo가 들어감. 왼손과 오른손에 서로 다른 음색을 놓는 Split은 없음.

내장곡은 음색 데모 10곡, 클래식 50곡, 레슨곡 303곡임. 레슨곡에는 바이엘, 부르크뮐러, 체르니, 하농이 들어가고, Smart Pianist에서는 클래식과 레슨곡을 합친 353곡의 악보를 볼 수 있음.

내장 MIDI 레코더에는 1곡을 2트랙으로 녹음할 수 있고, 한 곡에 약 150KB 또는 11,000음까지 들어감. SMF Format 0과 Format 1을 재생하고 녹음 파일은 Format 0으로 저장함.

USB TO HOST는 Type B 단자이고, 한 단자로 USB MIDI와 44.1kHz / 24bit 스테레오 오디오를 함께 주고받음. 컴퓨터나 스마트 기기와 USB 케이블 하나로 MIDI와 오디오가 함께 오가므로 DAW에서 건반 입력을 받으면서 본체 음원도 디지털로 녹음할 수 있음.

Bluetooth Audio와 Bluetooth MIDI도 둘 다 들어감. 스마트폰 음악은 피아노 스피커로 틀 수 있고 Smart Pianist도 무선으로 연결됨.

헤드폰 단자는 스테레오 표준 단자 2개임. 별도 Line Out, Line In, USB TO DEVICE, 5핀 MIDI 단자는 없음.

한국어 매뉴얼 기준 YDP-166은 벤치 포함, YDP-S56은 벤치 제외임. (하지만 판매처마다 다를 수 있음)
