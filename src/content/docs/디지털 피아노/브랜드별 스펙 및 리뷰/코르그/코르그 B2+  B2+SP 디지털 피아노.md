기존 B2는 NH 건반과 12음색, 15W + 15W 스피커를 갖춘 코르그의 엔트리 디지털 피아노였음. 2025년 후속으로 나온 B2+도 이 기본 구조를 거의 그대로 이어감. B2+SP는 같은 본체에 전용 스탠드와 3페달을 붙인 구성임.

전작과 비교해 건반이나 음원, 스피커는 달라지지 않았음. NH 건반, 12음색, 최대 120음 동시발음, 15W + 15W 출력, 10 x 5cm 타원형 스피커 2개, 11.4kg의 본체 무게까지 같음. USB 단자가 Type B에서 Type C로 바뀐 것이 가장 눈에 큰 변화임.

전작 B2도 USB Audio와 MIDI를 지원했기 때문에 USB 기능이 새로 추가된 것은 아님. 스마트폰과 태블릿에서 USB-C가 보편화된 흐름에 맞춰 단자 규격을 바꾼 마이너체인지에 가까움.

B2+ : 본체형, 11.4kg, 단일 댐퍼 페달 포함

B2+SP : 전용 스탠드 + 3페달, 21kg

B2+도 STB1 스탠드와 PU-2 3페달을 따로 구입하면 B2+SP와 비슷하게 구성할 수 있음. 건반과 음원, 스피커, 연결 기능은 두 모델이 같음.

### 건반 / 사운드

전작 B2에서 쓰던 NH, Natural Weighted Hammer Action을 B2+에서도 그대로 이어감. 저음은 무겁고 고음으로 갈수록 가벼워지며, 터치 감도는 Light, Normal, Heavy 세 단계로 바꿀 수 있음.

NH는 B1부터 이어진 코르그 보급형 해머 액션이고 B2+에서 구조를 손봤다는 자료는 없음. 타건감은 Yamaha GHS(P-125)와 비슷한 급으로 보는 경우가 많고, 누를 때 무게감이 GHS보다 조금 가볍고, 그만큼 복귀도 빠른 편임. 타건 소음도 가와이와 비교할 만큼 기계음이 비교적 조용함.



<img src="/images/코르그-B2+-B2+SP-디지털-피아노-2.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

건반 표면에는 인조상아나 합성 흑단 같은 질감 처리가 없음. 흰 건반과 검은 건반 모두 일반적인 플라스틱 표면임. 표면 재질보다는 건반 무게와 움직임이 자연스럽다는 쪽으로 평가가 모임.

상위 RH3처럼 정교한 액션은 아님. 동급에서 더 좋은 액션이 있다는 평가도 있지만, 처음 피아노를 배우기에는 부드럽고 반응이 빠르며 지나치게 무겁지 않다는 평도 많음. 무거운 액션보다는 편하게 눌리는 보급형 해머 액션이라는 점에서는 대체로 평가가 비슷함.

피아노 음색은

Italian Concert Piano

Italian Ballad Piano

Italian Jazz Piano

German Concert Piano

German Classic Piano

이탈리아 계열 3개와 독일 계열 2개가 들어감.

이탈리아 피아노 세 음색은 같은 계열 안에서도 성향을 나누어 Concert는 저음의 힘과 선명한 고역이 특징이고, Ballad는 밝기를 줄여 조금 부드럽게 만들었으며, Jazz는 고역을 더 밝게 잡았음. 독일 피아노는 Concert와 Classic 두 가지이고 Classic 쪽이 더 단정하고 부드러움. 현의 공명과 댐퍼 공명도 샘플에 반영함.

다섯 피아노 가운데서는 이탈리아 계열의 평가가 특히 좋은 편임. Italian Concert는 저음이 크고 고역이 선명하고, Ballad는 밝기를 줄인 부드러운 음색, Jazz는 팝과 재즈에 잘 맞는 밝은 음색이라는 평임. 독일 피아노 두 개는 이탈리아 계열보다 스테레오 폭이 좁고 조금 더 모노에 가깝게 들린다는 평가가 있음.

나머지 7음색은 빈티지 전자피아노 3개, 파이프 오르간, 재즈 오르간, 하프시코드, 스트링으로 채웠음. 전자피아노와 오르간도 가격대를 생각하면 잘 만든 편이라는 평이고, 전자피아노는 타건 세기에 따라 어택이 달라지고 건반을 뗄 때의 소리도 바뀜.

최대 동시발음은 모든 음색에서 같지 않음. 음색에 따라 120음, 60음, 40음으로 달라지고 피아노 음색에서는 최대 120음까지 쓸 수 있음. 일반적인 페달 연주에서는 동시발음 부족으로 음이 잘리는 문제가 거의 없다는 평임.

리버브와 코러스는 각각 On / Off만 가능함. 두 음색을 겹치는 Layer와 건반 좌우에 서로 다른 음색을 놓는 Split은 없음.

대신 레슨에서는 Partner Mode를 쓸 수 있음. 건반을 같은 음역의 좌우 두 구역으로 나눠 교사와 학생이 나란히 연주하는 기능임.



<img src="/images/코르그-B2+-B2+SP-디지털-피아노-3.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

스피커는 건반 위쪽에 10 x 5cm 타원형 두 개를 배치했고 출력은 15W + 15W임. 소리가 위쪽으로 바로 올라오기 때문에 연주자가 듣기 편함. 본체 크기에 비해 저음과 최대 음량이 크고, 볼륨을 높여도 두드러지는 왜곡이 적다는 평임. 전작 B2 때부터 피아노 음색과 스피커는 장점으로 자주 꼽혔음.


### 디자인 및 조작부

본체를 스탠드 없이 놓으면 B2+의 크기는 1312 x 336 x 117mm, 무게는 11.4kg임. 검정과 흰색 두 가지가 있고 건반 뒤쪽을 긴 스피커 그릴이 가로지르는 단순한 포터블 피아노 형태임.



<img src="/images/코르그-B2+-B2+SP-디지털-피아노-4.jpg" alt="" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

조작부에는 Power, Piano Play, Sound, Metronome 버튼과 볼륨 노브만 있음. 음색을 순서대로 바꾸는 정도는 Sound 버튼만으로 가능하지만 특정 음색이나 세부 설정을 바로 고르려면 버튼과 건반을 같이 눌러야 함.

디스플레이가 없어서 터치 감도, 트랜스포즈, 미세 조율, 리버브, 코러스, MIDI 채널처럼 자주 쓰지 않는 설정은 건반 위치를 외워 두지 않으면 설명서를 보게 됨. 기능 수에 비해 세부 조작은 직관적이지 않다는 평임.

메트로놈에서는 템포와 박자, 음량을 조절할 수 있고 음색마다 데모곡이 하나씩 들어가 총 12곡임.

B2+SP는 B2+ 본체 아래에 전용 스탠드와 3페달을 붙임. 크기는 1312 x 336 x 750mm, 무게는 21kg임. 건반과 음원, 스피커, 조작 기능은 그대로이고 페달과 설치 형태만 달라짐.

B2+ 기본 구성에는 피아노형 단일 댐퍼 페달이 들어감. 흔히 보급형에 따라오는 작은 사각 스위치보다 피아노 페달에 가까운 모양과 저항감을 갖췄지만 On / Off 방식이라 하프페달은 안 됨. 대체로 크기와 저항감은 일반적인 보급형 번들 페달보다 낫다는 평임.

하프페달과 소프트, 소스테누토까지 필요하면 PU-2 3페달을 추가해야 함. B2+SP에는 이 3페달이 처음부터 들어감.

연결 단자에서는 USB Type C가 전작과 가장 쉽게 구분되는 부분임.

USB 한 가닥으로 MIDI와 오디오를 같이 주고받음. 소프트웨어 피아노를 B2+ 건반으로 연주하면 컴퓨터나 스마트폰에서 나온 소리를 다시 B2+ 스피커로 들을 수 있고, 반대로 B2+의 연주 신호와 오디오도 연결 기기로 보낼 수 있음.

전작 B2도 USB Audio와 MIDI가 가능했으므로 연결 기능 자체가 추가된 것은 아님. 기존 Type B 단자를 Type C로 바꿔 최근 스마트폰과 태블릿에 연결하기 편해졌음.

USB와 별도로 AUDIO IN도 남겨둠. 스마트폰이나 플레이어의 아날로그 출력을 B2+ 스피커로 들을 때 씀.

USB Audio/MIDI와 외장 가상악기 활용은 좋지만, 피아노 자체를 앱에서 관리하는 기능은 거의 없음.

PHONES 단자는 3.5mm 스테레오 미니 하나이고 Line Out을 겸함. 별도의 L/R Line Out은 없음. 연결 기능 자체는 좋은 편이지만 헤드폰 단자가 본체 뒤쪽에 있고 3.5mm 하나뿐인 점은 아쉽다는 평임.

Bluetooth Audio와 Bluetooth MIDI는 없음.
