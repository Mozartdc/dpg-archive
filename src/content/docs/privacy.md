dpinside.org는 사이트 이용 현황을 파악하고 콘텐츠와 운영 품질을 개선하기 위해 쿠키와 유사한 기술을 사용할 수 있음.

## Google Analytics

방문 페이지, 접속 경로, 기기 및 브라우저 유형, 대략적인 지역, 사이트 이용 시간과 같은 이용 정보를 Google Analytics로 측정할 수 있음. 사이트 운영자는 개인을 직접 식별하는 이름, 이메일 주소나 전화번호를 Google Analytics에 전송하지 않음.

Google이 데이터를 처리하는 방식은 [Google 서비스를 사용하는 사이트 또는 앱의 정보 사용 안내](https://policies.google.com/technologies/partner-sites)에서 확인할 수 있음. 브라우저용 [Google Analytics 차단 부가기능](https://tools.google.com/dlpage/gaoptout)을 사용하면 Analytics 측정을 차단할 수 있음.

## Google AdSense

Google AdSense 승인 후 광고를 제공하는 과정에서 Google과 광고 파트너가 쿠키 또는 유사한 기술을 사용할 수 있음. 지역과 동의 상태에 따라 개인 맞춤 광고 또는 개인 맞춤이 아닌 광고가 표시될 수 있음. 광고 설정은 [Google 광고 설정](https://adssettings.google.com/)에서 관리할 수 있음.

## 쿠팡 파트너스

일부 페이지에는 쿠팡 파트너스 배너와 제휴 링크가 포함됨. 해당 링크를 통해 상품을 구매하면 사이트 운영자가 일정액의 수수료를 받을 수 있음. 배너를 불러오는 과정에서 쿠팡이 접속 정보와 쿠키 또는 브라우저 기술을 사용할 수 있음.

## 외부 사이트

외부 링크를 선택하면 각 서비스의 개인정보처리방침과 이용약관이 적용됨. 이 안내는 사이트에서 사용하는 서비스가 바뀌면 함께 갱신함.
