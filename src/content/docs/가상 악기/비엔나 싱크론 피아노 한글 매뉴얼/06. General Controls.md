싱크론 피아노 화면 상단 메뉴 바에서 기본 제어와 상태를 확인하고 화면을 전환함.

<strong>1. Velocity Histogram</strong>

건반을 눌렀을 때 들어오는 각 음의 벨로시티를 표시함. 히스토그램을 두 번 클릭하면 표시를 고정하거나 푼다.

<strong>2. Volume Meter</strong>

스테레오 출력 음량을 표시함. 클리핑이 생기면 빨간색으로 뜸.

<strong>3. Volume Knob</strong>

전체 음량을 조절함. 메인 GUI 왼쪽의 Volume Knob와 연동됨. 클릭한 채 끌거나 두 번 클릭해 값을 고침. <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Command</code> 또는 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Ctrl</code>을 누른 채 클릭하면 초기화됨.

<strong>4. Tuning</strong>

12평균율 외에도 아프리카 음계부터 서양 전통 음률까지 다양한 조율 방식을 고름. 자세한 내용은 Tuning System 장에서 다룸.

<strong>5. Online Manual</strong>

Knowledge Base의 온라인 매뉴얼로 연결됨.

<strong>6. Piano Selection</strong>

싱크론 피아노 라이선스가 두 개 이상 있을 때만 뜸. 피아노 선택 창을 엶.

<strong>7. Scale Button</strong>

GUI 크기를 75%부터 200%까지 단계적으로 조절함.

<strong>8. CPU Real-Time Display</strong>

현재 CPU 사용량을 표시함. 지연(latency)이 낮고 발음 수가 많을수록 부하가 올라감.

<strong>9. Settings</strong>

Interface와 Engine 설정을 조절함. Database 탭에서 샘플 콘텐츠 경로를 지정함.

<strong>10. Preset Button</strong>

폴더 아이콘을 눌러 Preset Browser를 숨기거나 표시함.

<strong>11. Current Preset Display</strong>

지금 불러온 프리셋을 표시함. PLAY 뷰에서 프리셋을 불러오면 연주에 맞춘 Room-Mix Preset이 함께 로드됨.

<strong>12. Play View</strong>

싱크론 피아노의 주요 파라미터를 조절함.

<strong>13. Mix View</strong>

모든 채널과 리버브 설정을 다루는 믹서임.

<strong>14. Edit View</strong>

EQ와 다이내믹 레인지를 음 하나 단위까지 세밀하게 조정함.

<strong>15. Information Window</strong>

Preset Browser가 열려 있을 때 추가 정보와 마우스오버 설명을 표시함.

<strong>16. Progress Bar</strong>

샘플 로딩 진행 상황을 표시함.

<strong>17. Loading Indicator</strong>

샘플 로딩이 진행 중인지 보여 줌.

<strong>18. Voices</strong>

활성화된 모든 마이크 채널에서 지금 울리고 있는 발음 수를 표시함.

<strong>19. RAM Load / Overall Loaded Samples</strong>

현재 쓰고 있는 RAM 용량과 불러온 전체 샘플 수를 표시함.
