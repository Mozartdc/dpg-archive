## 4.1. Keyboard range

### 4.1.2. Original / Extended range

KIViR, Kremsegg, Karsten 컬렉션 같은 고증 악기는 현대 피아노보다 음역이 좁음. 이 중 일부는 가상으로 음역을 좀 늘릴 수 있음.

악기 목록 맨 앞의 Reference preset을 뺀 모든 프리셋은 Extended range가 기본값임.

해당 악기 고유의 공명 범위를 그대로 얻고 싶은 식으로 Original range가 필요하면, 가상 키보드 왼쪽의 빼기(−) 아이콘을 누르면 됨.



<img src="/images/4.-Keyboard-Components-2.png" alt="Original / Extended range 전환" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

더하기(+) 아이콘을 누르면 다시 Extended range로 돌아옴.


## 4.2. 반음계 모드와 온음계 모드 (하프)

키보드는 기본적으로 Chromatic mode임. Diatonic harp 프리셋만 예외임.



<img src="/images/4.-Keyboard-Components-3.png" alt="반음계 모드의 가상 키보드" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />


### Diatonic mode



<img src="/images/4.-Keyboard-Components-4.png" alt="온음계 모드의 가상 키보드" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

가상 키보드 왼쪽의 작은 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">D</code> 버튼을 누르면 온음계 모드로 들어감. 이 모드에서는 흰 건반에서만 소리가 남.

검은 건반은 하프의 페달 컨트롤러 역할을 맡음. 콘서트 하프처럼 페달 일곱 개(왼쪽부터 D, C, B, E, F, G, A)로 조표를 지정함.

예를 들어 E 아래 검은 건반 그룹에서 왼쪽을 누르면 E♭이 되고, 오른쪽을 누르면 E♯으로 바뀜.


### Chromatic mode

가상 키보드 왼쪽의 작은 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">C</code> 버튼을 누르면 반음계 모드로 돌아옴.



<img src="/images/4.-Keyboard-Components-5.png" alt="반음계 모드의 가상 키보드" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

## 4.3. Guitar mode

Guitar 악기 팩을 불러오면 키보드가 기본적으로 Guitar mode로 잡힘. 반음계나 온음계 모드로 돌아가려면 키보드 왼쪽의 작은 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">G</code> 아이콘을 누르면 됨.

화면에 뜨는 기타 넥을 누르면 해당 음이 연주되며 흰 원반으로 표시됨. 이 모드에서는 여러 기타 주법이 살아나며, 키보드 왼쪽의 노란 키스위치로 조작함.


### 연주 기법

<strong>Legato</strong>

왼손만으로 줄을 누르거나(Hammer-on) 뜯어(Pull-off) 소리 내는 주법임. 키보드 오른쪽 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Leg. On</code> 버튼으로 켬. 켜진 상태에서 첫 음을 누른 채 단3도 이내의 음을 연주하면 레가토로 처리되고, 넥에는 원 대신 작은 삼각형이 뜸.

<strong>Glissando</strong>

줄 위에서 손가락을 미끄러뜨릴 때 나는 소리임. 시작 음이 끝나기 전에 종료 음을 넣으면 발동하며, 넥에는 흰 가로 타원형으로 표시됨. 종료 음의 벨로시티가 글리산도 속도를 결정함. 화음에도 적용되고, 키스위치나 페달로 켜기도 함.

<strong>Pinch harmonics</strong>

줄의 특정 지점을 순간적으로 건드려 기본음을 억누르고 배음을 강조하는 주법임. 키스위치나 페달로 켜며, 넥에는 흰 기호로 표시됨. 페달을 연속으로 조작하면 톤을 다양하게 바꿀 수 있음.

<strong>Thumb</strong>

오른손 엄지로 줄을 튕길 때 나오는 부드러운 톤을 내는 키스위치임. Plucking brightness를 낮추는 것과 비슷한 효과를 냄.


### 현 선택과 연주 스타일

기타는 같은 음이라도 어느 줄에서 연주하느냐에 따라 음색이 달라짐. 더 부드럽거나 더 단단한 톤이 나옴.


| 방식 | 동작 |
| --- | --- |
| Easy mode | 연주된 음에 따라 왼손 위치를 자동으로 정함 |
| Advanced mode (Adv.) | 키보드 오른쪽 키스위치로 왼손 위치를 직접 옮김 |
| 강제 지정 | 키보드 왼쪽 키스위치로 특정 현을 강제로 고르거나 개방현만 쓰도록 설정함 |
| 자동 배분 | 같은 줄로는 동시에 낼 수 없는 음정(2도, 단3도 등)이 들어오면 자동으로 다른 줄에 나눠 배치함 |


### 그 밖 기능

<strong>Repetition</strong>

키보드 왼쪽의 반복용 키스위치 두 개로 방금 연주한 화음을 위아래로 다시 스트러밍하거나, 단음을 빠르게 반복함.

<strong>Additional noises</strong>

손가락이 줄 위를 미끄러질 때 나는 삑 소리나, 넥을 오갈 때 나는 소음을 구현함. <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Casual to Pro</code> 슬라이더로 양을 조절하며, Pro 쪽으로 밀면 소음이 붙지 않음.

<strong>Advanced Settings</strong>

키보드 오른쪽 삼각형 아이콘을 누르면 열림.

- 여러 종류의 기타 튜닝 선택

- 기타 바디를 Hollow 또는 Solid로 변경

- 키스위치의 Gate / Toggle 모드 설정

- 각 현을 서로 다른 MIDI 채널에 배정
