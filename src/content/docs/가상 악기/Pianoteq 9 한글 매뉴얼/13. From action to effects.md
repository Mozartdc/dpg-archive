## 13.1. Action

피아노 액션의 물리적 동작과 그에 따른 소리를 설정함.



<img src="/images/13.-From-action-to-effects-2.png" alt="Action 설정" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

<strong>Damper position</strong>

건반에서 손을 뗐을 때 댐퍼가 현에 닿는 위치와 깊이를 정함. 배음이 사라지는 방식에 영향을 줌. 저음부에서 하프 페달을 쓸 때나 노트 오프 벨로시티를 인식하는 마스터 건반을 쓸 때 차이가 뚜렷하게 느껴짐.

<strong>Damping duration</strong>

댐퍼가 현의 진동을 얼마나 효과적으로 멈추는지 정함. 값을 낮추면 소리가 빠르게 끊기고, 높이면 댐퍼가 마모된 것처럼 서서히 사라짐.

<strong>Last damper</strong>

댐퍼가 적용되는 마지막 건반 위치를 지정함. 이 값보다 높은 음역에는 댐퍼가 없어서, 실제 피아노의 최고음역처럼 손을 떼도 소리가 계속 울림.

<strong>Mute</strong>

댐퍼가 현을 누르는 압력을 조절함. 댐퍼가 현을 계속 누르는 상태를 만들어 기타의 팜 뮤트처럼 소리가 짧고 둔해짐.

<strong>Key release noise</strong>

건반에서 손을 뗄 때 해머 액션이 원위치로 돌아가며 나는 기계적 소음의 크기를 조절함.

<strong>Sustain pedal noise</strong>

서스테인 페달을 밟거나 놓을 때 댐퍼 여러 개가 동시에 움직이며 나는 공기 소리와 기계적 잡음의 크기를 조절함.


## 13.2. Mallet bounce

침발롬 같은 유율 타악기를 칠 때 말렛이 바나 현에 맞고 튕기는 물리적 반응을 조절함.



<img src="/images/13.-From-action-to-effects-3.png" alt="Mallet bounce 설정" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

한 번 친 뒤 말렛이 몇 번, 어떤 속도와 크기로 튀는지를 세밀하게 정함.

<strong>초기 지연 시간</strong>

건반을 누른 뒤 첫 바운스가 시작되기까지의 시간을 정함.

<strong>벨로시티 민감도</strong>

타건 세기에 따라 바운스 타이밍이 얼마나 달라질지 정함. 값이 높을수록 세게 칠 때 첫 바운스가 늦게 시작하는데, 세게 칠수록 채가 더 높이 튀었다가 떨어진다는 물리 동작을 반영한 것임.

<strong>지연 시간 감소율</strong>

바운스가 반복될수록 간격이 얼마나 빨리 줄어드는지 정함. 처음엔 느리다가 점점 빨라지는 정도를 조절함.

<strong>벨로시티 감소율</strong>

바운스가 반복되면서 소리가 얼마나 빨리 작아질지 정함. 값이 크면 금방 멈추고, 작으면 오래 튐.

<strong>휴머나이즈</strong>

모든 바운스에 약간의 랜덤 변화를 줘서 매번 똑같이 튀지 않게 함. 기계적인 느낌이 줄어듦.

<strong>어택 엔벨로프</strong>

바운스로 생기는 소리만의 어택감을 조절함. 처음 타건으로 나는 소리의 어택은 여기가 아니라 Note Effects에서 설정함.


## 13.3. Equalizer



<img src="/images/13.-From-action-to-effects-4.png" alt="Equalizer 패널" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

피아노텍의 EQ는 일반적인 오디오 EQ처럼 소리를 깎고 키우는 방식이 아님. 소리가 난 뒤를 손대는 게 아니라, 소리가 만들어지는 단계에서 음색 자체를 조정함.

Main 설정에서도 전체 음량 균형은 그대로 두고 각 음이 가진 음색만 바뀜. 그래서 중음을 강조해도 중간 건반만 튀는 현상이 생기지 않음.

조절 방식도 일반 3밴드 EQ와 다름. 그래프 위에 직접 점을 찍어 원하는 곡선을 만들고, 필요 없으면 지움.

공명음만 따로 다루는 설정도 있음.

- <strong>Res EQ</strong> — 건반을 눌렀을 때 따라 울리는 공명 소리의 톤만 바꿈.

- <strong>Res Dur</strong> — 그 울림이 얼마나 오래 남을지를 음역대별로 조절함.


## 13.4. Note Effects



<img src="/images/13.-From-action-to-effects-5.png" alt="Note Effects 패널" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

Note Effects는 소리가 만들어진 뒤에 처리하는 이펙트가 아니라, 물리 모델 단계에서 각 음에 직접 변화를 주는 기능임. 비브라토로 음정을 흔들거나 트레몰로로 음량을 주기적으로 바꾸고, 어택 엔벨로프나 모노 연주 모드도 여기서 설정함.

<strong>비브라토</strong>

음정이 흔들리는 폭을 센트 단위로 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Depth</code>에서 정함. 흔들림의 기준점을 위나 아래로 치우치게 하려면 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Offset</code>을 씀.

<strong>트레몰로</strong>

음량 변화의 폭을 데시벨 단위로 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Depth</code>에서 설정함. 비브라토와 트레몰로를 함께 쓸 때 두 효과의 타이밍을 맞추는 기능이 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Relative Phase</code>임.

<strong>공통 설정</strong>

왼쪽 패널에서 변조 속도를 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Rate</code>로 정하고, 건반을 누른 뒤 효과가 시작되기까지의 지연은 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Onset Duration</code>으로 조절함. 변조의 움직임 형태는 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Shape</code>에서 고르고, 시작 위치는 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Phase</code>로 맞춤.

<strong>Mono 모드</strong>

켜면 한 번에 한 음만 울림. 이 상태에서 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Legato</code>를 쓰면 이어지는 음의 타격감이 줄어 부드럽게 연결됨. <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Portamento</code>를 쓰면 음과 음 사이를 정해진 속도로 부드럽게 이동함.


## 13.5. Effects

이펙트 패널에서는 최대 세 가지 이펙트를 차례로 연결해 씀. 각 슬롯은 필요할 때만 켜 두고 쓰지 않으면 꺼서 정리함.

슬롯마다 Tremolo, Wah, Chorus, Flanger, Phaser, Fuzz, Delay, Amp, Comp, EQ 중에서 골라 넣음. 모든 처리가 끝난 뒤에는 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Gain</code>으로 전체 출력 레벨을 한 번 더 조절함. 메인 화면의 Volume과 같은 기능이지만, 작업 흐름이 끊기지 않도록 이펙트 패널에도 따로 뒀음.


### 공통 파라미터


| 파라미터 | 기능 |
| --- | --- |
| Delay | 딜레이가 걸리는 시간을 밀리초 단위로 정함 |
| Depth | 이펙트로 변하는 음량의 폭을 dB 기준으로 조절함 |
| Feedback | 딜레이된 소리가 다시 입력으로 돌아가 반복되는 정도를 정함 |
| Mix | 이펙트가 걸린 소리와 원음을 얼마나 섞을지 조절함 |
| Mono switch | 이펙트를 모노로 처리할지 스테레오로 처리할지 고름 |
| Rate | 변조 계열 이펙트가 움직이는 속도를 정함 |
| Stereo | 좌우 발진기 사이의 위상 차이를 조절해 스테레오감을 바꿈 |
| Sync switch | 이펙트 속도를 곡 템포에 맞춰 동기화함 |
| Tone | 딜레이나 이펙트 처리된 신호의 음색을 다듬음 |


### 개별 이펙트

<strong>Tremolo</strong>

<code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Shape</code> 곡선 위에서 마우스를 가로나 세로로 끌어 LFO 파형 모양을 바꿈.

<strong>Wah</strong>

슬라이더로 와와 효과를 직접 조절함. 슬라이더를 우클릭해 MIDI를 고르면 외부 컨트롤러에 할당함.

<code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Auto-Wah</code> 모드를 켜면 연주하는 소리의 크기에 따라 효과가 자동으로 반응함.

- <strong>Sensitivity</strong> — 왼쪽 끝에서는 Auto-Wah가 꺼지고, 오른쪽으로 갈수록 작은 소리에도 반응함.

- <strong>Depth</strong> — Wah 필터가 움직이는 강도를 직접 조절함.

- <strong>Intensity</strong> — 주파수 스윕의 범위를 0%에서 100%까지 설정함.

<strong>Amp</strong>

앰프 사운드를 흉내 냄. <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Mix</code>로 원음과의 비율을, <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Drive</code>로 신호를 얼마나 강하게 몰아 왜곡할지 정하고, <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Bass</code> / <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Midrange</code> / <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Treble</code>로 대역을 조절함.

<strong>Comp</strong>

일반적인 컴프레서로 신호의 다이내믹을 조절함.

- <strong>Ratio</strong> — 기준 레벨을 넘은 신호를 얼마나 눌러 줄지 비율로 정함.

- <strong>Attack</strong> — 신호가 기준 레벨을 넘은 뒤 압축이 시작되기까지 걸리는 시간임.

- <strong>Release</strong> — 신호가 기준 레벨 아래로 내려간 뒤 압축이 풀리기까지의 시간임.

- <strong>Threshold</strong> — 이 레벨을 넘으면 압축이 걸림.

- <strong>Gain</strong> — 압축으로 줄어든 전체 음량을 다시 보정함.



<img src="/images/13.-From-action-to-effects-6.png" alt="Comp" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

<strong>EQ</strong>



<img src="/images/13.-From-action-to-effects-7.png" alt="EQ 이펙트" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

5밴드 파라메트릭 이퀄라이저임. 화면의 제어점을 끌어 각 밴드의 중심 주파수와 게인을 조절하고, <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Shift</code>를 누른 채 끌면 Q 값을 바꿈. 밴드 번호를 누르면 해당 밴드를 켜고 끄며, 제어점이나 번호를 우클릭하면 로우패스나 밴드패스 같은 필터 타입을 바꿈.


## 13.6. Reverberation



<img src="/images/13.-From-action-to-effects-8.png" alt="Reverb 설정" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

컨볼루션 리버브로 실제 공간의 잔향을 재현함. 스튜디오처럼 작은 공간부터 성당이나 타지마할처럼 잔향이 아주 긴 공간까지 고름. Plate, Spring, Speakers, Broceliande 같은 특수한 성격의 타입도 함께 들어 있음.

STANDARD와 PRO에서는 리버브 메뉴의 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Load WAV impulse</code>로 직접 만든 임펄스 파일을 불러옴.


| 파라미터 | 기능 |
| --- | --- |
| Mix | 원음과 잔향음의 비율을 dB 단위로 조절함 |
| Duration | 잔향이 얼마나 오래 남는지 정함 |
| Room size | 공간 크기를 5m에서 50m 범위로 설정함 |
| Pre-delay | 원음이 난 뒤 잔향이 들리기 시작하기까지의 지연을 조절함 |
| Tone | 반사음에만 걸리는 틸트 EQ임. 낮추면 어두워지고 높이면 밝아짐 |
| Tail / Early reflections | 벽에 부딪혀 바로 돌아오는 초기 반사음과 이후 잔향 사이의 레벨 균형을 dB 단위로 맞춤 |
| Low cut | 잔향이 걸린 신호의 저음을 줄이는 하이패스 필터임. 소리를 더 또렷하게 만들 때 씀 |
