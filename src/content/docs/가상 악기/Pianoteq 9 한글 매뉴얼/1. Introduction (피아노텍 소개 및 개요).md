## 1.1. 물리 모델링에 기반한 4세대 피아노

1698년 크리스토포리의 피아노포르테에서 시작된 1세대는 어쿠스틱 그랜드 콘서트 피아노로 완성됨. 20세기에 들어와 Fender Rhodes, Wurlitzer, Yamaha CP 80 같은 2세대 일렉트릭-어쿠스틱 피아노가 나왔고, 이어서 어쿠스틱 피아노를 녹음해 쓰는 3세대 디지털 샘플 피아노가 등장함.

피아노텍은 물리 모델링에 기반한 4세대 피아노임. 실제 어쿠스틱 피아노의 동작을 물리 파라미터로 모델링해서, 피아노의 모든 영역을 직접 제어할 수 있음. 덕분에 취향에 맞게 음색을 조절하면서도 실제 악기에서만 느낄 수 있던 반응을 구현함.

피아노텍은 32비트 내부 연산으로 소리를 계산하므로 샘플 음원과 달리 양자화 노이즈가 생기지 않음. 표준 MIDI 벨로시티 127단계 전 구간에서(고해상도 MIDI를 쓰면 그 이상) 가장 약한 피아니시모부터 가장 강한 포르티시모까지 음색이 실제로 달라짐.

물리 모델을 쓰기 때문에 기계적 소음, 페달과 현의 상호작용, 스타카토 연주의 타격감까지 재현함. 하프시코드나 피아노포르테 같은 역사적 악기부터 현대 그랜드, 전기-음향 피아노까지 복각할 수 있고, 아예 존재하지 않는 악기를 새로 만들 수도 있는 최초의 가상 피아노 엔진임.



<details>

<summary>역주: 양자화와 양자화 노이즈</summary>

  - <strong>양자화</strong> — 연속적인 아날로그 신호를 딱딱 끊어지는 디지털 값으로 바꾸는 과정임.

  - <strong>양자화 노이즈</strong> — 실제 피아노를 녹음해 디지털로 저장(샘플링)하고 재생하는 방식에서, 소리를 숫자로 바꿀 때 생기는 노이즈임.



</details>


## 1.2. 피아노텍의 강점

물리 모델링 방식이라 실제 사용에서 이런 차이가 생김.

- <strong>소리가 고정돼 있지 않음.</strong> 녹음을 꺼내 쓰는 게 아니라 칠 때마다 새로 계산하므로, 터치의 차이가 그대로 소리에 반영됨.

- <strong>용량이 가벼움.</strong> 샘플 데이터를 쌓아 두지 않아 설치가 금방 끝나고 RAM도 적게 씀. 대신 CPU가 계산을 전담하므로 CPU 성능이 곧 성능임. 노트북에서도 무리 없이 돌아감.

- <strong>지연(latency)을 낮출 수 있음.</strong> 오디오 드라이버가 받쳐 주고 CPU가 최신이면 상당히 낮은 수준까지 내려감.

- <strong>악기 폭이 넓음.</strong> 그랜드와 업라이트는 물론 포르테피아노, 하프시코드, 클라비코드, 하프, 침발롬 같은 피아노 이전 악기와 일렉트릭 피아노, 비브라폰·마림바 같은 체명악기까지 들어 있음.

개발은 프랑스 툴루즈 국립응용과학원(INSA Toulouse) 수학연구소에서 이뤄짐. 물리 모델 설계는 조율사이자 수학자인 Philippe Guillaume, 실시간 구현은 공학자 Julien Pommier가 맡음.


## 1.3. Pianoteq 버전별 차이

피아노텍은 세 가지 버전으로 나옴. 사운드와 악기, 연주감은 세 버전이 모두 같고, 조절할 수 있는 기능의 범위에서 차이가 남.

1. <strong>STAGE</strong> — 벨로시티 커브, 다이내믹스, 액션 설정, EQ, 트레몰로, wah-wah, 코러스, 플랜저, 페이저, 컴프레서 등 일반적인 조절 기능과 이펙트를 제공함.

1. <strong>STANDARD</strong> — STAGE의 기능에 더해 물리 모델과 마이크 위치를 조절하는 옵션이 추가됨.

1. <strong>PRO</strong> — 노트 편집(<code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Note Edit</code>)으로 음 하나하나의 파라미터를 편집해 새로운 음색을 만들 수 있음.


| 항목 | STAGE | STANDARD | PRO |
| --- | --- | --- | --- |
| 내부 샘플 레이트 | 최대 48 kHz | 최대 48 kHz | 최대 192 kHz |
| 물리 모델 · 마이크 위치 조절 | 없음 | 있음 | 있음 |
| 노트별 파라미터 편집 | 없음 | 튜닝 · 볼륨만 | 전체 파라미터 |

STAGE는 프리셋을 불러올 때 인터페이스에 실제로 있는 파라미터까지만 반영함. 그래서 PRO에서 만든 프리셋을 STAGE에서 열면 STAGE에 없는 파라미터는 무시하고 로딩함. 반면 STANDARD는 PRO로 만든 프리셋을 제한 없이 불러올 수 있음.

악기 팩은 모두 정식 버전으로 제공되고, 포함되지 않은 악기 팩도 데모 모드로 소리를 확인해 볼 수 있음. 추가 구매는 언제든 가능함.


## 1.4. 피아노텍 9 주요 기능 요약

실제 피아노의 반응을 세밀하게 살린 기능들임.


### 다이내믹과 공명

- <strong>연속적인 벨로시티 표현</strong> — 피아니시모부터 포르티시모까지 다이내믹과 음색이 끊김 없이 이어짐. 샘플 방식으로 같은 수준을 구현하려면 수백 GB가 필요한 부분을 실시간 계산으로 처리함.

- <strong>모든 현의 공명(sympathetic resonance)</strong> — 서스테인 페달을 밟았을 때와 밟지 않았을 때를 모두 반영함.

- <strong>듀플렉스 스케일</strong> — 댐퍼에 닿지 않고 남은 짧은 구간이 함께 울리는 현상을 재현함.

- <strong>댐퍼 위치에 따른 잔향 변화</strong> — 건반을 뗄 때 배음이 어떻게 줄어드는지가 달라짐.

- <strong>리페달링과 스타카토 잔향</strong> — 실제 페달 동작에 가까운 반응을 냄.

- <strong>반복음의 음색 변화</strong> — 이미 진동 중인 현을 해머가 다시 칠 때의 변화를 재현함.


### 음색 설계

- <strong>악기 모핑</strong> — 서로 다른 악기를 물리 모델 수준에서 섞어 새로운 음색을 만듦.

- <strong>악기 레이어링</strong> — 예를 들어 낮은 음역은 하프, 높은 음역은 비브라폰, 중간은 둘을 섞는 식으로 배치할 수 있음.

- <strong>확장된 음역대</strong> — Steinway D나 K2 같은 일부 그랜드는 최대 105건반까지 지원함.

- <strong>악기 상태 조정</strong> — 완벽히 조율된 상태부터 낡은 상태까지 설정할 수 있음.


### 연주 제어

- <strong>폴리포닉 애프터터치</strong> — 특히 클라비코드 연주에서 쓸모가 있음.

- <strong>물리적 4페달 시스템</strong> — 총 12가지 기능을 할당할 수 있음.
  - 서스테인 페달 (부분 페달 지원)

  - 소스테누토 페달 (일부 음만 유지)

  - 하모닉 페달 (스타카토 연주 중에도 공명을 유지함. 실제 피아노에는 없는 기능임)

  - 우나 코르다 (una corda, 소프트 페달. 타격 위치를 옮겨 음색을 바꿈)


- <strong>건반 · 페달 · 노트 릴리스 속도 설정</strong>

- <strong>해머 반동 시뮬레이션</strong> — 마림바, 실로폰, 침발롬 같은 타악기의 반발을 구현함.


### 음향과 출력

- <strong>뚜껑 개방 각도 조절</strong>

- <strong>자연스러운 기계음</strong> — 키 릴리스 소리, 댐퍼 소리, 서스테인 페달의 공기 소리 등을 재현함.

- <strong>마이크 위치 설정</strong> — 최대 8채널 믹싱을 지원함.

- <strong>마이크로 튜닝</strong> — SCALA 포맷 파일을 지원함.

- <strong>EQ 및 다이내믹스 조절</strong>

- <strong>컨볼루션 리버브</strong> — WAV 임펄스 파일을 불러와 실제 공간의 잔향을 구현함.

- <strong>표준 이펙트</strong> — 딜레이, 코러스, 플랜저, 페이저, 퍼즈, 트레몰로, wah-wah, 앰프, 컴프레서, 5밴드 EQ.

- <strong>노트 이펙트</strong> — Attack, Vibrato, Tremolo, 단음 모드 등 물리 모델에 직접 작용하는 효과임.
