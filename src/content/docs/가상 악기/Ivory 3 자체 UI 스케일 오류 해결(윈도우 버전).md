Ivory 3를 사용할 때 모니터 해상도나 배율에 따라 설정창이 너무 작게 보이거나, 4K 모니터에서 인터페이스가 커져 일부 컨트롤이 보이지 않을 수 있음.


## 해결 방법


### 1. VST 창을 별도 창으로 열기

Cantabile에서 VST 창을 <strong>Separate Window</strong>로 열면 운영체제의 DPI 처리가 적용되기 쉬움.

Ivory 3를 불러온 뒤 상단 탭을 우클릭하고 <strong>Undock from main window</strong> 또는 <strong>Open in separate window</strong>를 선택함.


### 2. Windows 디스플레이 배율 조정

Windows <strong>설정 → 디스플레이 → 배율 및 레이아웃</strong>에서 125~150%로 바꾸고 Cantabile를 재시작함.


### 3. Ivory 3 UI Scaling 재시도

DAW에서 창을 완전히 닫았다가 다시 열거나, 다른 DAW에서 Ivory 3를 실행한 뒤 Cantabile로 돌아오면 UI Scaling이 다시 활성화되는 경우가 있음.


### 4. 해상도를 낮춰 원인 확인

4K나 QHD에서 문제가 계속되면 잠시 1920×1080으로 바꿔 UI 크기를 확인함. 그래도 해결되지 않으면 Synthogy의 패치를 기다려야 함.
