## 설치 및 기본 설정

- SoundPaint 공식 웹사이트에서 계정을 만듦.

- 운영체제에 맞는 SoundPaint 엔진 설치 파일을 내려받음.

- 가입한 이메일로 받은 액세스 키(Access Key)를 확인함.


### Windows

- .exe 설치 파일을 실행함. 설치 중 VST3 플러그인 경로를 지정할 수 있음.

- SoundPaint를 실행해 로그인한 뒤 액세스 키를 입력해 활성화함.

- <strong>Library Management</strong> 또는 <strong>My Products</strong>에서 1928 Vintage Grand Steinway를 내려받음.

- 빠른 로딩을 원하면 라이브러리를 SSD에 설치함.

- 스탠드얼론으로 실행하거나 DAW에서 VST3 플러그인으로 불러올 수 있음.


### macOS

- .dmg 파일을 열고 <a href="http://soundpaint.app/" target="_blank" style="color: inherit; text-decoration: underline;">SoundPaint.app</a>을 응용 프로그램 폴더로 옮김.

- 로그인과 액세스 키 입력으로 활성화함.

- 제품 라이브러리를 내려받음.

- 스탠드얼론 또는 DAW의 AU 플러그인으로 사용할 수 있음.


## 기본 설정 변경


### 오디오 설정

오른쪽 위 톱니바퀴 아이콘 → <strong>Audio Settings</strong>에서 장치, 샘플레이트, 버퍼 사이즈를 고름. Windows에서는 ASIO 드라이버를 쓰면 지연을 줄일 수 있음. macOS는 기본 <strong>Core Audio</strong>를 사용함.


### MIDI 설정

<strong>MIDI Settings</strong>에서 연결된 디지털 피아노가 인식됐는지 확인하고, 여러 키보드 중 사용할 장치와 MIDI 채널을 선택함. 기본 채널은 Omni임.


### 라이브러리 경로

<strong>Library Management</strong>에서 라이브러리 저장 위치를 바꿀 수 있음. 저장 공간이 넉넉하고 속도가 빠른 SSD를 권장함.
