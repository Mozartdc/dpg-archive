직접 Preset을 만들려면 Synchron Player Video Tutorials를 먼저 확인하는 것이 좋음. 몇 가지 간단한 예시를 통해 만드는 과정과 활용 방법을 가장 쉽게 이해할 수 있음.


## Preset Cloning

Preset을 완성한 뒤에는 구조가 같은 다른 Instrument에도 그대로 적용할 수 있음. 예를 들어 Synchron Elite Strings의 각 Section처럼 동일한 구조를 가진 Instrument 사이에서 Preset을 복제할 수 있음.

먼저 Preset을 활성화한 뒤 Instrument의 모든 Slot을 포함하는 Root Slot을 Copy하고, 그 내용을 Text Editor에 붙여넣음. 붙여넣은 내용에는 각 Slot의 데이터가 목록으로 표시됨.

한 Instrument의 구조를 다른 Instrument에 적용하려면 문서 전체에 있는 Abbreviation / ID / Folder 정보를 대상 Instrument의 값으로 바꿔야 함. Root Slot 또는 그 안에 포함된 다른 Slot에서도 구조는 동일함.

Synchron Duality Strings - Regular을 예로 든 Instrument Abbreviation / ID / Folder:


| Instrument | Abbreviation | ID | Folder |
| --- | --- | --- | --- |
| 1st Violins | VI-22 | vi1 | 01 1st Violins |
| 2nd Violins | VI-18 | vi2 | 02 2nd Violins |
| Violas | VA-15 | va | 03 Violas |
| Cellos | VC-15 | vc | 04 Violoncellos |
| Double Basses | DB-9 | db | 05 Double basses |

Abbreviation, ID, Folder 정보는 위 Screenshot에서 표시한 위치에서 확인할 수 있음.

<strong>macOS (Sublime)</strong>

- <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Command+F</code>를 누르고 "Replace"를 활성화함.

- 기존 Instrument Abbreviation을 새 Instrument의 값으로 변경함. 예: <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">VI-14</code> → <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">VC-8</code>

<strong>Windows (Notepad)</strong>

- <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Ctrl+H</code>를 누르면 같은 Replace 기능을 사용할 수 있음.

Instrument ID와 Folder도 같은 방법으로 모두 변경함.


## Adapting the range

이렇게 수정한 Preset 정보에는 아직 원래 Instrument의 Range 정보가 남아 있음. Range를 초기화하려면 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">rangeFrom</code> 또는 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">rangeTo</code>가 포함된 모든 줄을 삭제해야 함.

이 작업은 Regular Expression을 사용하면 쉽게 처리할 수 있음. Regular Expression은 일정한 규칙과 Placeholder를 사용해 특정 형태의 Text를 찾아 한꺼번에 변경하거나 삭제하는 기능임.

Notepad++를 비롯한 여러 Text Editor에서는 Search/Replace 기능에서 Regular Expression을 사용할 수 있음.

이 예에서는 Search/Replace를 다음과 같이 설정함.

1. Regular Expression을 선택함.

1. Search: <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">\n.range[^\n]</code>

1. Replace: 비워 둠.

1. "Replace all"을 실행함.

수정한 Text 전체를 Copy한 뒤 새 Synchron Player Instance에서 비어 있는 Root Node에 Paste함. 이제 동일한 기능과 구조를 가진 Preset을 새로운 Section에서 사용할 수 있음.
