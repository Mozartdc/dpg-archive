Synchron Player의 기본 튜닝 시스템은 서양 음악의 표준인 12평균율(12 Tone Equal Temperament, 12TET)이며, 국제 표준 피치에 따라 콘서트 A(MIDI 노트 69)를 440 Hz로 사용함. 이외에도 Scala 파일과 함께 제공되는 Keyboard Mapping 파일을 이용한 다른 튜닝 시스템, 개별 음의 피치 조정, MIDI Tuning Standard(MTS), MTS-ESP Master Plugin, VST/VST3의 음별 Detune 정보를 이용한 외부 튜닝 소스를 지원함.


## Basic information

이 섹션에서는 Player와 이 매뉴얼에서 사용하는 용어, 개념, 표준을 설명함. 미분음과 튜닝 시스템에 이미 익숙하다면 다음 섹션으로 넘어가도 됨.

<strong>Pitch</strong>: 소리를 높거나 낮다고 인식할 수 있게 하는 청각적 특성임. 대부분의 경우 음의 기본 주파수에 대응하지만 항상 일치하는 것은 아님.

<strong>Tuning System</strong>: MIDI 전체 음역에 있는 각 음의 피치를 정하는 주파수 체계임. 일반적으로 다음 두 요소로 구성됨.

1. 흔히 Scale이라고 부르는 여러 개의 상대적 피치 간격. 여기서 Scale은 장음계의 선법 같은 일반적인 음악적 음계와는 다른 의미이며, 대부분 한 옥타브에 도달하면 같은 패턴이 반복됨.

1. Scale의 Start Note와 Scale에 포함된 한 음의 주파수. Tuning Note와 Start Note는 서로 다른 음일 수 있음.

- 많은 튜닝 시스템은 옥타브마다 같은 구조를 반복하지만 모든 튜닝 시스템이 그런 것은 아님. 주파수 비율이 2:1인 옥타브를 포함하지 않는 Scale도 있으며, 이런 경우 옥타브 단위로 반복되지 않음.

- 많은 튜닝 시스템이 한 옥타브를 12단계로 나누지만 이것 역시 필수 조건은 아님. 원칙적으로 한 옥타브를 몇 단계로든 나눌 수 있음.

<strong>Concert A</strong>: Middle C 위에 있는 A음으로 MIDI 노트 번호는 69임. 오케스트라 튜닝의 기준음으로 가장 널리 사용됨.

<strong>Middle C</strong>: 표준 88건반 피아노에서 왼쪽부터 네 번째 C음임. Scientific Pitch Notation에서는 C4, Helmholtz Pitch Notation에서는 c′, MIDI 표준에서는 노트 번호 60으로 표기함. Player는 Scientific Pitch Notation을 사용하며 Middle C의 기준을 변경할 수 있으므로 설정에 따라 C3 또는 C5로 표시될 수도 있음.

<strong>Tuning</strong>: Concert A의 주파수이며 Standard Pitch라고도 함. 이 용어는 이전 버전의 Synchron Player와 다른 VSL Player에서 사용해 온 명칭을 따름. 일반적으로 Tuning이라는 용어가 다른 의미로 사용되는 경우도 있음.

<strong>Temperament</strong>: 다음 조건을 만족하는 Tuning System의 한 종류임.

- 주파수 비율 2:1의 순정 옥타브 사용

- 옥타브를 12단계로 분할

- 순정 음정에서 발생하는 자연적인 편차를 여러 방식으로 분산시키는 것을 목적으로 함

<strong>12 Tone Equal Temperament</strong>: 현재 서양 음악에서 가장 널리 사용되는 튜닝 시스템임. 현대 서양 음악에서는 사실상 기본 전제로 사용될 만큼 일반적임. 12TET 또는 12EDO(12 Equal Divisions of the Octave)라고 줄여서 표기함.

<strong>Intonation</strong>: 개별 음의 실제 피치. 주파수 또는 기준 피치와의 편차로 표시함.

<strong>Scale</strong>: 튜닝 시스템에서 Scale은 상대적인 피치 간격의 집합을 의미함. 예를 들어 한 옥타브 안에 있는 각 반음 간격을 정의할 수 있음.

<strong>Start Note</strong>: Scale의 첫 번째 음. Concert A를 사용하는 경우가 많지만 Middle C나 Middle C 위의 E도 자주 사용함. 어떤 음이든 Scale의 Start Note가 될 수 있음. Start Note는 Scala와 Keyboard Mapping을 사용하는 튜닝 시스템에서만 명확하게 정의됨.

<strong>Tuning Note</strong>: 절대 주파수를 지정한 음. 서양 음악에서는 일반적으로 Concert A를 440 Hz로 지정함.

<strong>Cent</strong>: 음정을 나타내는 로그 단위. 12TET에서는 한 옥타브를 100 Cent씩 12개의 반음으로 나눔. Synchron Player에서는 현재 튜닝 시스템의 각 음이 12TET의 피치에서 얼마나 벗어나는지 Cent 단위로 표시함.

<strong>Scala</strong>: 튜닝 시스템을 정의하기 위한 표준. 확장자가 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">.scl</code>인 Scala 파일에는 상대적인 Scale Step의 수, Start Note를 기준으로 한 각 Step의 피치, 패턴의 반복 방식을 저장함. 일반적으로 Keyboard Mapping 파일과 함께 사용함. 자세한 내용은 Scala 웹사이트를 참고.

<strong>Keyboard Mapping</strong>: Scala 파일과 함께 사용할 Start Note와 Tuning Note를 지정함. Player에 내장된 튜닝 시스템도 Scala 파일과 Keyboard Mapping 파일의 조합으로 정의되어 있음.

<strong>MTS</strong>: MIDI Tuning Standard. MIDI SysEx Bulk Message를 사용해 Intonation 정보를 전달하는 방식임. Player는 이 메시지를 해석하고 전달된 튜닝 정보에 따라 동작할 수 있음.

<strong>MTS-ESP</strong>: Master Plugin을 이용해 튜닝 시스템을 Client Plugin에 전달하는 비교적 새로운 표준임. Player는 Client로 동작할 수 있음. 자세한 내용은 Oddsound 웹사이트를 참고.

<strong>VST/VST3 Detune</strong>: Host는 VST와 VST3 Plugin에 Note-On Event를 보낼 때 각 Event에 개별 Detune 정보를 추가할 수 있음. Player는 이 정보를 해석해 해당 피치로 재생함. VST 또는 VST3 Plugin으로 사용할 때만 이용할 수 있음.


## The Tuning System window



<img src="/images/14.-Tuning-System-3b426dfbcd79-1.jpg" alt="Tuning System 창" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

Menu Bar의 Flow 아이콘 옆에 소리굽쇠 모양의 Tuning System 버튼이 있음. 이 버튼을 누르면 Tuning System 창이 열리며 Player에서 사용할 튜닝 시스템을 선택하거나 직접 만들 수 있음. 서양 표준 12평균율(12TET)이 아닌 다른 튜닝 시스템이 활성화되어 있으면 Tuning System 버튼이 파란색으로 바뀜.

<strong>1. Current tuning source</strong>: Tuning System 창 왼쪽 위에 현재 선택된 Scale과 해당 Keyboard Mapping이 표시됨. Player가 외부 Tuning Source를 사용하고 있다면 해당 소스가 여기에 표시됨.

<strong>2. Tuning note and frequency</strong>: 현재 Tuning Note의 주파수를 표시하며 필요에 따라 변경할 수 있음. 기본값은 Concert A 440 Hz임. 현재 불러온 Keyboard Mapping에서 Concert A가 아닌 다른 음을 Tuning Note로 지정했다면 해당 음의 이름과 주파수가 표시됨.

- Player의 일반 설정에 있는 Middle C 설정에 따라 표시되는 옥타브 번호가 달라질 수 있음.

- Player는 Host에 "Tuning"이라는 Audio Parameter를 제공하며 이를 이용해 Concert A의 Tuning을 Automation할 수 있음. Concert A 이외의 음이 Tuning Note로 선택되어 있으면 이 Audio Parameter는 적용되지 않음. 일부 내장 Tuning System에서는 실제로 다른 음을 Tuning Note로 사용함.

<strong>3. Reset to 12TET</strong>: Scale Browser에서 기본 설정을 직접 찾을 필요 없이 버튼을 눌러 기본 튜닝으로 돌아감. 기본 Scale은 "12 Tone Equal Temperament", Keyboard Mapping은 "on A69, A69 = 440 Hz"임.

<strong>4. Scale browser</strong>: 내장 Tuning System을 종류별 Folder로 분류해 표시함. Search Bar를 이용해 항목을 필터링할 수 있음.

<strong>5. Show / hide advanced settings</strong>: 내장 Tuning System만 사용할 때는 기본 화면으로 충분함. Advanced Settings를 열면 외부 Tuning Source, 사용자 정의 Tuning System과 추가 Tuning 설정을 사용할 수 있음.



<img src="/images/14.-Tuning-System-3b426dfbcd79-2.jpg" alt="Tuning System 고급 설정" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

<strong>6. Keyboard mapping</strong>: 다른 Keyboard Mapping을 불러와 Scale의 Start Note와 Tuning Note를 변경할 수 있음. Search Bar를 이용해 항목을 필터링할 수 있음.

Scale을 불러오면 Player는 같은 기본 파일명을 가진 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">.kbm</code> 확장자의 Keyboard Mapping을 찾아 자동으로 불러옴. 내장 Tuning System에 대응하는 Keyboard Mapping은 "Corresponding" Folder에 있음. 일치하는 Keyboard Mapping을 찾지 못하면 12개의 Key와 A = 440 Hz로 설정된 기본 Keyboard Mapping을 불러옴.

다른 Keyboard Mapping을 선택하면 현재 Tuning System의 Start Note를 옮길 수 있음. "Key Centers (tuned to A4)" Folder에는 Middle Octave의 각 음을 Start Note로 지정할 수 있는 12개의 Mapping이 들어 있으며, Tuning Note는 Concert A로 유지함.

"Key Centers (tuned to start note)" Folder의 12개 Mapping은 Start Note 자체를 Tuning Note로 지정하고 해당 음에 12TET에서 사용하는 것과 같은 주파수를 할당함.

<strong>7. Follow MIDI Tuning Standard (MTS)</strong>: 활성화하면 Player가 MIDI Tuning Standard(MTS)를 따름. 예를 들어 Logic Pro의 Hermode Tuning을 사용하려면 이 설정을 켜야 함. 기본값은 Off.

<strong>8. Follow MTS-ESP master plugin</strong>: 활성화하면 Player가 MTS-ESP Master Plugin에서 전달하는 Intonation을 따름. 자세한 내용은 Oddsound 웹사이트를 참고. 기본값은 Off.

<strong>9. Keep tuning when loading preset</strong>: 활성화하면 Player에서 Preset을 불러와도 현재 선택한 Tuning System을 그대로 유지함. 미리 정해진 Tuning System으로 미분음 작품을 시작한 뒤 적합한 Instrument와 Sound를 찾을 때 유용함.

<strong>10. Update intonation while sustaining notes</strong>: Player가 모든 Key의 Intonation을 계속 갱신함. 비활성화하면 새로운 Note가 Trigger될 때만 Intonation이 갱신됨. Hermode Tuning 또는 Scale Morphing을 사용할 때 활성화함.

<strong>12. Show key intonation relative to tuning note</strong>: Virtual Keyboard에 표시되는 Intonation 값을 Tuning Note를 기준으로 표시함. Tuning Note는 Concert A 또는 Keyboard Mapping에서 지정한 다른 음이 될 수 있음. 이 옵션을 활성화하면 Tuning Note의 주파수를 변경해도 표시되는 상대 Intonation 값은 그대로 유지됨. Tuning Note를 표준 주파수와 다르게 조율한 경우에도 선택한 Tuning System의 Scale Step을 쉽게 확인할 수 있음.

<strong>13. Load from .scl/.kbm file</strong>: 로컬 파일 시스템에서 개별 Scala 또는 Keyboard Mapping 파일을 직접 불러옴.

<strong>14. Link to folder</strong>: 개인 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">.scl</code>/<code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">.kbm</code> 파일이 들어 있는 로컬 Folder를 지정함. 해당 파일은 Browser의 "User" 섹션에 표시됨.

## Keyboard display

Tuning System 창이 열려 있는 동안 Player의 Keyboard에는 모든 MIDI Note의 Intonation이 440 Hz 기준 12TET에서 얼마나 벗어나는지 Cent 단위로 표시됨.

빨간색 영역은 양수로, 해당 12TET 음보다 피치가 높다는 의미임. 파란색 영역은 음수로 더 낮은 피치를 의미하고, 룰렛처럼 녹색으로 표시되는 값은 0임.

Tuning System의 Start Note가 정의되어 있다면 해당 음에는 검은색 Spin이 표시됨. Tuning System 창을 닫으면 검은색 점으로 표시됨.

- 값을 변경하려면 마우스로 위아래로 Drag함.

- Shift-Drag하면 값을 세밀하게 조절함.

- Ctrl/Cmd-Click하면 값을 Reset함.

- Double-click하면 값을 직접 입력할 수 있는 Text Field가 열리며 Enter를 눌러 확정함.

- 모든 Octave에서 같은 음을 동시에 변경하려면 Alt/Option-Drag를 사용함. Text Field에 값을 입력할 때는 Alt/Option-Enter를 사용함.

예를 들어 바로크 음악에서 자주 사용되는 Just Intonation을 살펴보면 Start Note와 Tuning Note 모두 Concert A이며, 해당 음의 편차는 0 Cent로 표시됨.



<img src="/images/14.-Tuning-System-3b426dfbcd79-3.jpg" alt="건반의 음정 편차 표시" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

Intonation은 −700에서 +700 Equal-Tempered Cent 범위에서 직접 조절할 수 있음. 12평균율 기준으로 아래쪽 또는 위쪽 완전5도까지 조절할 수 있는 범위임.

일부 Tuning System은 이보다 더 큰 편차를 사용함. 이런 경우 Spin에 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">></code> 또는 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;"><</code> 기호가 표시됨. Spin 위에 마우스 포인터를 올리면 왼쪽 아래 Status Bar에서 정확한 값을 확인할 수 있음.

24 Tone Equal Temperament처럼 한 Octave에 12개보다 많은 Step을 사용하는 Tuning System은 Keyboard에서 더 넓은 Play Range가 필요함.

이를 위해 Player의 Play Range를 원래 범위보다 위아래 각각 최대 3 Octave까지 확장할 수 있음. 오른쪽의 Double-arrow 버튼을 누른 뒤 Play Range Handle을 Drag해 필요한 범위로 조절함.

## Sequencing of manual adjustments

Scale Browser에서 Tuning System을 불러오면 그에 대응하는 Keyboard Mapping도 자동으로 불러옴. 이 과정에서 직접 조정한 Intonation과 Tuning Note Frequency가 덮어써짐.

Tuning System을 불러온 뒤 직접 값을 조정하려면 다음 순서를 권장함.

1. 원하는 Scale을 불러옴.

1. 필요한 경우 원하는 Keyboard Mapping을 불러옴.

1. Tuning Note의 Frequency를 조절함.

1. 개별 Note의 Intonation을 직접 조절함.

1. 필요한 경우 수정한 Tuning System을 Preset으로 저장함.


## Saving and loading presets

Synchron Libraries에 포함된 모든 Factory Preset은 기본적으로 Concert A 440 Hz의 12TET를 사용함.

User Preset을 저장하면 Tuning System과 관련 설정도 함께 저장되며 Preset을 다시 불러올 때 복원됨.

Preset을 불러올 때 현재 Tuning System을 유지하려면 Tuning System의 Advanced Settings에서 해당 옵션을 활성화함.

<strong>Preset에 저장되는 설정</strong>

- 현재 Scale과 Keyboard Mapping

- Tuning Note의 Frequency

- 모든 Intonation 설정

- External Tuning Source 사용 여부

<strong>다음 항목은 Preset이 아니라 Player 자체의 Preference로 저장됨</strong>

- "Keep tuning when loading presets"

- "Update intonation for sustaining notes"

- "Show key intonation relative to tuning note"


## Handling of external tuning sources

Player가 MTS, MTS-ESP 또는 VST/VST3 Detune 같은 External Tuning Source를 사용하도록 설정되어 있으면 다음 GUI 항목을 조작할 수 없음.

- Tuning Note Frequency (2)

- Reset to 12TET (3)

- Scale Browser (4)

- Keyboard Mapping Browser (6)

- Show key intonation relative to tuning note Checkbox (12)

- Load from .scl/.kbm file Button (13)

- Link to folder Button (14)

현재 External Tuning Source를 비활성화하면 Player는 기본 설정인 440 Hz의 12TET로 돌아가며, 위의 GUI 항목을 다시 사용할 수 있음.


### Legato

Legato Transition에는 서로 다른 두 음인 Source Note와 Target Note가 사용됨. 따라서 Transition Sample이 재생되는 동안 Player가 Intonation을 변경해야 할 수 있음.

Source Note와 Target Note 자체의 Intonation은 정확하지만 Transition Sample 안에서 실제 음이 전환되는 정확한 시점은 Sample마다 다르므로 Intonation이 변경되는 시점과 실제 Transition 시점이 어긋날 수 있음.

### Microtonal playback in Dorico

악보 제작 Software인 Dorico는 "Tonality Systems"와 Microtonal Accidentals를 폭넓게 지원하기 때문에 미분음 작곡가들이 많이 사용함.

기본적으로 Dorico는 두 가지 방식으로 Playback Intonation 정보를 전달함.

- VST2 Plugin에서는 VST NoteOn Event의 "Detune" 값을 사용함. Player는 이 방식을 지원함.

- VST3 Plugin에서는 VST Note Expressions를 사용함. Synchron Player는 현재 이 방식을 지원하지 않음.

대신 Dorico에서 VST3 Plugin에도 Detune 값을 보내도록 설정할 수 있음.

Dorico의 Plugin으로 Player를 불러오면 VST/VST3 Detune 정보를 받도록 자동으로 설정됨.

Dorico에서는 일반적으로 이 기능만으로 충분하기 때문에 Top Bar의 Tuning System 버튼은 기본적으로 숨겨져 있음.

전체 Tuning System 기능이 필요한 경우 Synchron Player의 Settings에서 Interface Tab으로 이동해 이 기본 설정을 비활성화할 수 있음.



<img src="/images/14.-Tuning-System-3b426dfbcd79-5.jpg" alt="Dorico 미분음 재생 설정" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

Player의 VST2 Plugin을 사용하면 별도의 설정 없이 Dorico의 Microtonal Playback이 동작함.

VST3 Plugin을 사용할 때는 Dorico에서 한 가지 설정을 변경해야 함.

1. <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">Library → Expression Maps</code>를 선택해 "Expression Maps" Dialog를 엶.

1. 왼쪽에서 사용할 Expression Map을 선택함. 어떤 것을 선택해야 할지 모르면 "Default"를 선택함.

1. "Expression Map Data" Tab을 엶.

1. "Microtonality playback" Dropdown Menu에서 "Detune"을 선택함.

1. 설정을 저장함.
