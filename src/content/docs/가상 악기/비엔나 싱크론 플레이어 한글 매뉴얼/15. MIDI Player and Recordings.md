MIDI Player에서는 일부 Percussion 제품에 포함된 Drum Pattern을 재생하거나, 직접 연주한 MIDI를 녹음하고 재생하거나 Loop할 수 있음.

Loop 파일은 다음과 같은 제품에 포함되어 있음.

- Synchron Percussion

- Synchron World Percussion

- Synchron Power Drums

- Big Bang Orchestra Percussion

- Studio Jazz Drums

그 외 제품에도 계속 추가될 예정임.

MIDI Player는 Sequencer의 현재 Song Position에 설정된 Tempo를 따름. MIDI 파일의 Velocity나 Tempo 등을 조절할 수 있으며, Drag & Drop으로 Sequencer에 가져올 수 있음.

Synchron Power Drums의 "3 drum sets in 1 MIDI file" Folder와 Synchron World Percussion의 "Full ensemble for DAW" Folder에는 여러 Instrument가 서로 다른 MIDI Channel에 할당된 파일이 들어 있음. 이를 이용하면 여러 Instrument를 동시에 사용할 수 있음.

Factory Folder의 MIDI 파일에는 Instrument별로 분류된 Groove 요소도 포함되어 있어 필요한 Pattern을 조합해 직접 Groove를 만들 수 있음.


## MIDI Player



<img src="/images/15.-MIDI-Player-and-Recordings-1.webp" alt="MIDI Player" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

<strong>MIDI Recorder/Player Icon</strong>: MIDI Recorder/Player를 엶.

<strong>Standalone only</strong>: 빨간 점은 Recording 중임을 나타냄. Recording을 생성하려면 최소 5개의 Note를 연주해야 함.

<strong>File Selection Menu</strong>: Factory에서는 기본 제공 MIDI Performance를 표시함. User에서는 직접 Import한 MIDI File을 표시함. Recordings에서는 Standalone Mode에서 녹음한 파일을 표시함. Favorites에서는 Favorite으로 지정한 모든 파일을 표시함.

<strong>Enable/Disable Box</strong>: 자동 MIDI Recording 기능을 켜거나 끔.

<strong>Browser</strong>: Finder 또는 Explorer처럼 Folder 구조를 이동하며 파일을 탐색함.

<strong>Loops</strong>: 현재 선택한 위치에 있는 파일 목록을 표시함.

<strong>Piano Roll Preview</strong>: MIDI 내용을 간단히 미리 보여줌. 원하는 Region을 선택할 수 있음.

<strong>File Details</strong>: File Name, Tempo, Bar 수를 표시함.

<strong>Play/Pause Button</strong>: Spacebar 또는 Mouse Click으로 재생과 일시정지를 전환함.

<strong>Loop On/Off</strong>: Loop 재생을 켜거나 끔. 선택한 Region에도 적용됨.

<strong>Velocity</strong>: Performance의 Velocity를 조절해 Dynamics를 세밀하게 보정함.

<strong>Tempo Multiplier</strong>: Half Speed, Normal Speed, Double Speed 중 하나를 선택함.

<strong>Metronome</strong>: [Standalone only] Metronome을 켬. Mouse를 위아래로 움직여 Tempo를 조절하고 Slider로 Volume을 조절함.

<strong>Host Sync</strong>: [Plug-in only] 활성화하면 Play/Pause Button을 사용할 수 없으며 Sequencer가 재생될 때 MIDI Player도 함께 재생됨.


## MIDI Recording — Standalone only



<img src="/images/15.-MIDI-Player-and-Recordings-2.jpg" alt="Standalone MIDI Recording" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

<strong>Recordings Tab</strong>: Standalone Synchron Player에서 연주한 Pattern이 여기에 표시됨. 최소 5개의 Note를 연주해야 Recording이 생성되며, 5초 동안 아무 Note도 연주하지 않으면 Recording이 종료됨.

<strong>Recording Folder</strong>: Recording이 저장되는 위치를 표시함.

<strong>Recording Location</strong>: Recording 저장 위치를 변경함.

<strong>List of Recordings</strong>: 녹음된 모든 Performance를 표시함. 각 항목에는 Time Stamp와 사용한 Library/Patch 정보가 함께 표시됨.

<strong>Context Menu</strong>: Performance를 Favorite으로 지정하거나 Rename, Copy, Delete할 수 있음. WAV File로 Audio를 Export할 수도 있음.

<strong>Favorite</strong>: 별표가 표시된 파일은 Favorite으로 지정된 파일임.

<strong>Playhead</strong>: 현재 Playback Position을 표시하며 Mouse로 위치를 이동할 수 있음.

<strong>Region</strong>: 원하는 구간을 지정할 수 있음. Mouse로 Drag해 Region을 만듦.

<strong>CC Controller Lane</strong>: Recording에 포함된 CC Controller 데이터를 표시하며 사용된 CC 번호도 함께 표시함.
