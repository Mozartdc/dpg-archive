<p style="margin: 0 0 1em 0;">이 책에서 설명한 피아노 연습법을 스무 항목으로 정리하면 다음과 같음.</p>


## 1. 실제로 연주할 음악을 배움

<p style="margin: 0 0 1em 0;">음악성이 있고 무대에서 연주할 수 있는 작품을 중심으로 배움. 하농, 체르니처럼 기계적인 연습을 위한 곡은 피함.</p>

<p style="margin: 0 0 1em 0;">음계, 아르페지오, 반음계는 필요함. 쇼팽과 리스트의 연습곡처럼 실제 작품으로 연주할 수 있는 에튀드도 도움이 됨. 상급자에게는 특정 문제를 해결하는 별도의 운동이 필요할 수 있음.</p>


## 2. 좋은 연주를 들음

<p style="margin: 0 0 1em 0;">다른 연주자의 공연과 녹음을 들으며 음악성을 키움.</p>


## 3. 한손씩 짧은 구간을 연습함

<p style="margin: 0 0 1em 0;">양손을 나눠 짧은 구간으로 연습함. 구간과 구간은 서로 조금씩 겹쳐 연결이 끊기지 않게 함. 한 손이 피곤해지기 전에 반대 손으로 바꿈.</p>

<p style="margin: 0 0 1em 0;">가능한 한 빨리 목표 속도에 도달함. 테크닉을 새로 만드는 과정은 모두 한손 연습으로 해결함.</p>


## 4. 가장 어려운 곳부터 시작함

<p style="margin: 0 0 1em 0;">곡의 처음부터 순서대로 연습하지 말고, 가장 어려운 구간을 먼저 다룸.</p>


## 5. 먼저 외움

<p style="margin: 0 0 1em 0;">처음부터 한손씩 외우고, 이후에는 기억에 의지해 연습함.</p>


## 6. 음악을 머릿속과 귀로 다루는 능력을 익힘

<p style="margin: 0 0 1em 0;">머릿속 연주, 암보, 상대음감·절대음감, 청음 연주를 익힘. 저자는 이런 능력이 지능 발달에도 도움이 된다고 봄.</p>


## 7. 병렬 세트로 약점을 찾음

<p style="margin: 0 0 1em 0;">병렬 세트(Parallel Sets, PS)를 이용해 테크닉의 약한 지점을 진단하고 바로잡음.</p>


## 8. 작고 또렷하게 연습함

<p style="margin: 0 0 1em 0;">작은 소리로 연습하고, 페달 없이도 소리가 분명한지 확인함. 스타카토 연습도 활용함.</p>


## 9. 이완을 배움

<p style="margin: 0 0 1em 0;">필요하지 않은 힘을 빼고 긴장 없이 움직이는 법을 익힘.</p>


## 10. 빠른 반복은 느리게 끝냄

<p style="margin: 0 0 1em 0;">같은 구간을 빠르게 여러 번 반복했다면 마지막 한 번은 반드시 느리게 연주함.</p>


## 11. 실수해도 흐름을 이어 감

<p style="margin: 0 0 1em 0;">실수할 때마다 멈추는 습관을 만들지 않음. 더듬거리지 않도록 음악의 흐름을 유지하며 실수를 통과함.</p>


## 12. 메트로놈은 확인할 때만 씀

<p style="margin: 0 0 1em 0;">리듬과 속도를 짧게 확인하는 용도로 메트로놈을 사용함. 메트로놈에 맞춰 속도를 단계적으로 계속 올리거나 연습 내내 켜 두지는 않음.</p>


## 13. 연습 후 향상을 이용함

<p style="margin: 0 0 1em 0;">잠을 자는 동안 일어나는 연습 후 향상(Post Practice Improvement, PPI)을 고려해 연습량과 휴식을 배치함.</p>


## 14. 여러 손동작을 익힘

<p style="margin: 0 0 1em 0;">다음과 같은 동작과 자세를 익혀 상황에 맞게 사용함.</p>

- 아래팔 회전
- 손가락을 굽힌 자세와 편 자세
- 엄지 넘기기
- 파워 엄지
- 도약 원칙
- 글리산도 동작
- 조용한 손과 손가락
- 수레바퀴 동작
- 손가락 벌리기
- 손가락·손목·손을 이용한 여러 스타카토

## 15. 양손 연습에도 같은 원칙을 적용함

<p style="margin: 0 0 1em 0;">양손 연습에서도 4~14번의 원칙을 그대로 씀. 윤곽 연습도 활용함.</p>


## 16. 초견의 기본을 지킴

<p style="margin: 0 0 1em 0;">손이 아니라 악보를 봄. 음표를 하나씩 읽지 말고 악구 단위로 읽으며, 한 마디 이상 앞을 살핌.</p>

<p style="margin: 0 0 1em 0;">자주 나오는 음형과 구조를 외움. 피아노 없이 머릿속 연주만으로 연습하는 법도 익힘.</p>


## 17. 완성한 곡으로 고급 테크닉을 기름

<p style="margin: 0 0 1em 0;">완성한 곡을 손풀이나 사전 준비 없이 바로 연주해 봄. 이미 완성한 작품을 충분히 다루면서 고급 테크닉을 발전시킴.</p>


## 18. 공연 당일에는 연습량을 제한함

<p style="margin: 0 0 1em 0;">공연 당일에는 공연곡만 다음 순서로 연주함.</p>

1. 공연 속도에 가깝게 한 번
1. 중간 속도로 한 번
1. 느리게 한 번
<p style="margin: 0 0 1em 0;">불안한 곳은 짧게 나누고 공연 속도보다 느리게 연습함. 지나치게 연습하지 않으며, 끝내기 전에는 적어도 한 번 느리게 연주함. 무대 불안이 커졌다면 호흡 순서를 이용해 가라앉힘.</p>


## 19. 수준에 맞는 피아노를 선택함

<p style="margin: 0 0 1em 0;">저자는 대부분의 어쿠스틱 업라이트가 이제 낡은 선택이라고 봄. 초보자에게는 디지털피아노를 권하며, 중급 이상에서는 고급 디지털피아노나 어쿠스틱 그랜드피아노가 필요하다고 설명함.</p>


## 20. 어린 나이에 시작함

<p style="margin: 0 0 1em 0;">저자는 네 살 이전에 피아노를 시작하면 절대음감, 머릿속 연주, 암보, 청음 연주를 힘들이지 않고 익히기 좋은 시기를 활용할 수 있다고 봄.</p>
