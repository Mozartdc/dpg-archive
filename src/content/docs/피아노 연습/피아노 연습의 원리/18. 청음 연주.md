<p style="margin: 0 0 1em 0;">피아노 교사 중에는 청음 연주(Play by Ear, PBE)를 가르치는 방법을 모르는 경우가 많음. 그래서 절대음감이 있는 학생마저도 청음 연주를 배울 곳을 찾기 어려움.</p>

<p style="margin: 0 0 1em 0;">아기가 읽기와 쓰기보다 말을 먼저 배우듯, 음악가도 악보에 앞서 들은 음악을 연주하는 능력을 배워야 함. 청음 연주는 멘탈 플레이(MP)의 일부임. 이를 배우지 않으면 MP로 할 수 있는 일 가운데 큰 부분을 버리는 셈임.</p>

<p style="margin: 0 0 1em 0;">어린아이는 절대음감과 MP를 익히듯 청음 연주도 빠르고 힘들이지 않고 배움. 나이가 들수록 배우는 데 더 오래 걸림.</p>


### 익숙한 멜로디부터 시작함

<p style="margin: 0 0 1em 0;">학생이 이미 알고 있는 노래를 피아노에서 찾게 함.</p>

- ABC 노래
- 반짝반짝 작은 별
- Baa Baa Black Sheep
- 생일 축하 노래
- 올드 랭 사인
<p style="margin: 0 0 1em 0;">ABC 노래, 반짝반짝 작은 별, Baa Baa Black Sheep은 같은 멜로디를 씀.</p>

<p style="margin: 0 0 1em 0;">수업마다 다른 조로 옮겨 연주하게 함. 멜로디를 찾은 뒤에는 스스로 반주도 붙여 봄. 나중에 화음, 화성 진행, 받아쓰기 같은 음악 이론을 배울 때 자연스럽게 이어짐.</p>

<p style="margin: 0 0 1em 0;">이 연습을 해 두면 피아노가 있는 생일 파티에서 어떤 조로든 생일 축하 노래를 칠 수 있음.</p>


### 작곡과 즉흥연주로 이어짐

<p style="margin: 0 0 1em 0;">청음 연주를 배우면 작곡도 자연히 시작하게 됨. 머릿속에서 들은 음악을 건반으로 옮기고, 거기에 화음과 반주를 붙이는 과정 자체가 작곡의 출발점임.</p>

<p style="margin: 0 0 1em 0;">MP, 절대음감, 청음 연주, 작곡, 즉흥연주는 따로 떨어진 기술이 아님. 서로 맞물려 함께 발전하는 하나의 능력 묶음임. 이 책에서는 이를 음악가가 갖춰야 할 ‘천재의 기술’로 봄.</p>

<p style="margin: 0 0 1em 0;">알려진 위대한 피아니스트는 모두 청음 연주를 할 수 있었음. 음악가가 되는 데 필요한 능력인데도 가르치지 않을 이유가 없음.</p>

<p style="margin: 0 0 1em 0;">즉흥연주를 배우는 사람은 사실상 청음 연주도 계속 연습하고 있음. 따라서 페이크북, 재즈, 즉흥연주를 가르치는 방법도 청음 연주 교육에 활용할 수 있음.</p>
