# 건반의 움직임이 해머까지 전달되는 길

건반 앞쪽을 누르면 밸런스 레일을 축으로 뒤쪽이 올라감. 캡스턴이 위펜을 밀고, 위펜에 달린 잭과 반복 레버가 롤러를 받쳐 해머를 현 쪽으로 보냄.

해머가 현에 닿기 직전에는 잭이 롤러 아래에서 빠져나감. 이 이탈 동작 덕분에 건반을 누른 채 있어도 해머가 현에 붙어 있지 않음. 타건 뒤에는 백체크가 해머를 받아 튀어 오르는 동작을 막고, 반복 레버가 해머를 다시 칠 수 있는 위치로 빠르게 돌려놓음.

PDF의 도해는 액션 한 종류를 단순화한 그림임. 제조사와 시대에 따라 부품의 모양, 명칭과 조정 나사는 달라질 수 있음.

| --- | --- | --- |
| 1 | Jack | 잭. 롤러를 밀어 해머를 올림 |
| 2 | Key lever button | 건반 레버 버튼 |
| 3 | Balance rail | 밸런스 레일. 건반의 지지축 |
| 4 | Key lever center pin | 건반 중심핀 |

| 7 | Jack adjustment screw | 잭 조정 나사 |
| 8 | Action metal frame | 액션 금속 프레임 |
| 9 | Hammer butt rail | 해머 버트 레일 |

| 11 | Hammer butt top screw | 해머 버트 윗나사 |

| 15 | Repetition lever spring | 반복 레버 스프링 |
| 16 | Repetition stop hook | 반복 정지 훅 |
| 17 | Repetition lever adjust. screw | 반복 레버 조정 나사 |
| 18 | Spoon – jack control | 잭의 움직임을 제어하는 스푼 |
| 19 | Jack spring | 잭 스프링 |
| 20 | Wippen flange | 위펜 플랜지 |
| 21 | Hammer rest rail | 해머 레스트 레일 |
| 22 | Hammer rest rail cushion | 해머 레스트 레일 쿠션 |
| 23 | Repetition lever flange | 반복 레버 플랜지 |
| 24 | Capstan | 캡스턴. 건반과 위펜을 연결함 |
| 25 | Hammer | 해머 |
| 26 | Back check | 백체크. 돌아오는 해머를 받음 |
| 27 | Back check wire | 백체크 와이어 |
| 28 | Damper felt contact point | 댐퍼 펠트 접촉점 |

| 31 | Jack button to adjust jack | 잭 위치를 맞추는 버튼 |
| 32 | Wippen rail | 위펜 레일 |


# 조정 나사를 함부로 돌리지 않음

도해에 조정 나사가 여러 개 보이지만 한 부품만 따로 맞출 수 있는 구조가 아님. 잭 위치, 렛오프, 드롭, 반복 스프링, 백체크와 해머 높이는 서로 영향을 줌. 한 음을 고친다고 나사를 돌리면 빠른 반복이 끊기거나 해머가 현에 붙고, 건반마다 감촉이 달라질 수 있음.

구조를 이해하는 용도로 도해를 보고 레귤레이션은 기술자에게 맡김. 더 자세한 현대식 도해와 모델별 차이는 <a href="https://www.pianoparts.com/grand/" target="_blank" style="color: inherit; text-decoration: underline;">Piano Parts의 그랜드 액션 자료</a>에서 확인할 수 있음.
