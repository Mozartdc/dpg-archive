<p style="margin: 0 0 1em 0;">엄지는 가장 쓰임이 많은 손가락임. 음계와 아르페지오를 연결하고, 넓은 화음을 잡게 해 줌.</p>

<p style="margin: 0 0 1em 0;">엄지로 건반을 누르는 방법은 크게 네 가지임.</p>

1. <strong>손가락 동작</strong>: 손은 움직이지 않고 엄지만 움직임. 다른 손가락이 손허리 관절에서 움직이듯, 엄지는 손목에 있는 관절을 축으로 움직임.
1. <strong>손목 동작</strong>: 전완은 고정하고 손가락을 단단히 둔 채 손목만 움직여 엄지를 누름.
1. <strong>팔 동작</strong>: 손가락과 손목을 고정하고 전완 전체를 아래로 흔듦. 힘은 어깨에서 시작함.
1. <strong>전완 회전</strong>: 전완을 돌려 엄지를 누름.

### 네 동작을 따로 연습함

<p style="margin: 0 0 1em 0;">먼저 긴장을 모두 없애고 각 동작을 하나씩 떼어 연습함.</p>

<p style="margin: 0 0 1em 0;">처음에는 느린 속도로 크게 과장해서 움직임. 동작이 분리되면 움직이는 거리를 줄이면서 속도를 높임. 네 가지 가운데 자신에게 가장 빠른 동작도 확인할 수 있음.</p>

<p style="margin: 0 0 1em 0;">실제 연주에서는 여러 동작을 섞음. 각각의 움직임이 작아져도 합쳐진 결과는 같은 건반 깊이를 만들므로 더 빠르게 칠 수 있음.</p>

<p style="margin: 0 0 1em 0;">평소에는 이미 여러 동작을 함께 쓰므로 하나만 떼어 내기가 처음에는 어려움. 그래서 분리 연습이 필요함.</p>


### 엄지 끝으로 침

<p style="margin: 0 0 1em 0;">손톱이 있는 끝마디 관절이 아니라 엄지 끝으로 건반을 침.</p>

<p style="margin: 0 0 1em 0;">손끝을 쓰면 엄지가 건반 위에서 미끄러질 수 있고 손목도 올리기 쉬움. 다른 손가락이 엉뚱한 음을 건드릴 가능성이 줄어듦.</p>

<p style="margin: 0 0 1em 0;">가장 짧은 손가락인 엄지를 최대한 길게 쓰는 방법이기도 함. 같은 엄지 동작에서도 손끝은 관절보다 더 멀리, 더 빠르게 움직임.</p>


## 약한 엄지와 파워 엄지

<p style="margin: 0 0 1em 0;">엄지에는 약한 자세와 힘을 쓰는 자세가 있음.</p>


### 약한 엄지 자세

<p style="margin: 0 0 1em 0;">두 손을 몸 앞의 건반에 곧게 놓고 엄지손톱이 서로 마주 보게 함. 엄지손톱은 건반에 거의 수직으로 서고, 엄지 끝은 다른 손가락 쪽으로 조금 굽어 손가락과 거의 나란히 놓임.</p>

<p style="margin: 0 0 1em 0;">느리거나 쉬운 패시지에 알맞음.</p>

<p style="margin: 0 0 1em 0;">손목을 낮춰 손과 전완을 같은 높이에 두면 이 자세가 나옴. 엄지 옆면에 가까운 곳으로 건반을 치게 됨.</p>


### 파워 엄지 자세

<p style="margin: 0 0 1em 0;">어려운 패시지나 힘이 필요한 곳에서는 파워 엄지 자세를 씀.</p>

<p style="margin: 0 0 1em 0;">두 손을 건반에 놓고 엄지를 옆으로 곧게 폄. 손톱이 얼굴 쪽 위를 향함. 이 자세에서는 빠른 연주와 전완 회전을 쓰기 쉽고, 몸도 완전히 이완할 수 있음.</p>

<p style="margin: 0 0 1em 0;">벽에 압정을 누를 때 쓰는 엄지의 강한 근육이 동원됨. 약한 자세에서 억지로 힘을 쓰면 엄지뿐 아니라 다른 부위에도 통증과 부상이 생길 수 있음.</p>

<p style="margin: 0 0 1em 0;">손목을 올리면 엄지의 손바닥 쪽 끝으로 치게 되고, 엄지가 자연히 아래를 향하면서 강한 근육이 작동함.</p>


### 두 자세 사이를 조절함

<p style="margin: 0 0 1em 0;">처음에는 약한 엄지 자세를 써 봄. 힘이나 속도가 부족할 때 파워 자세를 조금씩 더함.</p>

<p style="margin: 0 0 1em 0;">TU와 TO 사이에 여러 중간 동작이 있듯, 약한 엄지와 파워 엄지도 극단적인 두 자세만 쓰는 것이 아님. 패시지에 맞춰 그 사이에서 조절함.</p>

<p style="margin: 0 0 1em 0;">엄지를 가장 강한 손가락이라고 생각하기 쉽지만, 약한 자세에서는 빠른 속도의 새끼손가락보다 힘이 떨어질 수도 있음.</p>

<p style="margin: 0 0 1em 0;">옥타브 트레몰로처럼 엄지와 새끼손가락의 균형이 필요한 곳에서는 엄지 자세를 조절해 두 손가락의 힘을 맞춤.</p>
