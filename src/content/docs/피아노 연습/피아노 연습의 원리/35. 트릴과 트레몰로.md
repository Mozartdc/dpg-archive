<p style="margin: 0 0 1em 0;">오른손 2-3-2-3 트릴을 예로 듦.</p>

<p style="margin: 0 0 1em 0;">먼저 2-3 병렬 세트를 연습함. 네 음 묶음과 순환 연습 등 앞에서 배운 병렬 세트 절차를 그대로 적용함.</p>

<p style="margin: 0 0 1em 0;">속도를 빨리 얻고 싶다면 2번과 3번을 화음처럼 동시에 누르는 병렬 세트 1번을 이용함. 2-3을 차례로 치는 연습과 두 음을 동시에 반복하는 연습을 번갈아 하면서 속도를 올리고 힘을 뺌.</p>

<p style="margin: 0 0 1em 0;">2-3이 충분히 빨라지면 3-2, 2-3-2, 2-3-2-3 순서로 늘림.</p>

<p style="margin: 0 0 1em 0;">첫 두 음부터 빠르게 시작하는 것이 빠른 트릴의 핵심임. 트릴에 익숙해진 뒤에도 2-3 병렬 세트가 가장 효과적인 출발 연습임. 다른 손가락 조합도 같은 방식으로 익힘.</p>


## 빠른 트릴은 느린 트릴과 동작이 다름

<p style="margin: 0 0 1em 0;">속도가 붙으면 운동량의 영향이 커짐. 따라서 트릴이 빨라지는 중간에 손의 감각이 달라지는 순간이 옴.</p>

<p style="margin: 0 0 1em 0;">빠른 트릴은 특정한 공명 속도에서 특히 잘 움직임. 어떤 속도는 편하고 그 사이 속도는 오히려 어려울 수 있음. 이상한 일이 아님.</p>

<p style="margin: 0 0 1em 0;">처음에는 잘되는 속도에서 연습함. 테크닉이 자라면 속도를 더 자유롭게 바꿀 수 있음.</p>


### 이완과 전완 회전

<p style="margin: 0 0 1em 0;">트릴은 다른 테크닉보다 이완이 더 중요함. 연결이 너무 많아서 병렬 세트만으로 속도를 만들 수 없음.</p>

<p style="margin: 0 0 1em 0;">손가락이 움직이며 만든 운동량을 전완 회전으로 반대쪽에서 받아 줘야 함.</p>

<p style="margin: 0 0 1em 0;">긴장하면 손가락이 손과 팔에 묶여 함께 움직임. 움직여야 할 질량이 커지므로 속도는 느려짐.</p>

<p style="margin: 0 0 1em 0;">벌새가 콘도르보다 날개를 빠르게 움직이고, 작은 곤충이 벌새보다 더 빠르게 날갯짓하는 것과 같음. 벌새는 낮은 웅웅 소리를 내지만 모기는 더 높은 소리를 냄.</p>

<p style="margin: 0 0 1em 0;">처음부터 완전히 힘을 빼 손가락을 손과 팔에서 자유롭게 만들어야 함.</p>


## 트릴은 계속 관리함

<p style="margin: 0 0 1em 0;">트릴을 잘 치려면 자주, 가능하면 매일 연습해야 함. 트릴이 많이 나오는 곡을 하나 배워 자주 연주하는 방법이 좋음.</p>

<p style="margin: 0 0 1em 0;">오른손 빠른 트릴에는 베토벤 「발트슈타인 소나타」 Op. 53 3악장 176마디 이후가 좋은 연습곡임.</p>

<p style="margin: 0 0 1em 0;">바흐 인벤션 4·7·9·10·12번은 느린 트릴을 익히기 좋음.</p>

<p style="margin: 0 0 1em 0;">예전 교재에서는 트릴을 느리게 치면서 다른 손의 음과 하나씩 맞추라고 가르치기도 했음. 빠른 트릴을 먼저 익힌 뒤, 다른 손과 관계없이 원하는 속도로 이어 가는 능력을 배우는 편이 좋음.</p>


### 트릴은 스타카토의 연속이 아님

<p style="margin: 0 0 1em 0;">각 음 사이에도 손끝을 건반 바닥 가까이에 둠. 음을 칠 때마다 백체크가 해머를 잡아 흔들리지 않게 해야 함.</p>

<p style="margin: 0 0 1em 0;">해머가 제멋대로 흔들리면 통제를 잃어 음이 고르지 않거나 빠질 수 있음.</p>

<p style="margin: 0 0 1em 0;">건반 바닥을 세게 누르지는 않음. 트릴이 느려짐. 팔 무게만으로 충분함.</p>

<p style="margin: 0 0 1em 0;">반복 장치가 다시 작동하는 데 필요한 최소 상승 거리도 확인함. 업라이트는 그랜드보다 거의 두 배 높이 들어야 할 수 있음.</p>

<p style="margin: 0 0 1em 0;">빠른 트릴일수록 손가락이 올라가는 거리를 줄여야 함. 업라이트에서는 그만큼 속도를 낮춰야 할 수도 있음.</p>

<p style="margin: 0 0 1em 0;">값싼 디지털 피아노도 액션 반응이 부족해 빠른 트릴이 어려울 수 있음. 디지털 피아노의 액션을 시험할 때 트릴을 쳐 보면 차이를 알기 좋음.</p>

<p style="margin: 0 0 1em 0;">병렬 세트를 비롯한 다른 테크닉 연습처럼 마지막에는 스타카토 연습을 더해 동작을 완성함. 트릴도 예외가 아님.</p>


## 트레몰로

<p style="margin: 0 0 1em 0;">트레몰로도 트릴과 같은 방식으로 연습함.</p>
