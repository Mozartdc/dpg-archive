<p style="margin: 0 0 1em 0;">전완에는 자뼈(ulna)와 노뼈(radius)가 있음. 새끼손가락 쪽의 가는 자뼈를 중심으로, 엄지 쪽의 굵은 노뼈가 돌아가는 움직임이 전완 회전임.</p>

<p style="margin: 0 0 1em 0;">빠른 병렬 세트, 트레몰로, 알베르티 베이스, 음계, 아르페지오 등 여러 테크닉에 쓰임.</p>


### 엄지를 손 전체와 함께 움직임

<p style="margin: 0 0 1em 0;">전완 회전을 쓸 때 엄지는 손에 단단히 붙어 있고, 손 전체가 회전하면서 엄지를 움직임. 엄지 자체의 작은 움직임을 섞을 수도 있음. 엄지 근육은 느리지만 움직이는 거리를 줄이면 충분히 빨라짐.</p>

<p style="margin: 0 0 1em 0;">알렉산더 테크닉을 비롯한 전통적인 피아노 교육 체계도 전완 회전을 가르침.</p>

<p style="margin: 0 0 1em 0;">손목과 팔은 나무 오르기, 싸움과 방어, 물건 던지기와 받기처럼 빠른 움직임이 필요한 활동에 맞춰 발달했음. 그래서 전완 회전은 원래부터 빠른 동작임. 빠른 악절을 연습할 때는 전완 회전을 넣으면 쉬워지는지 늘 확인해 봄.</p>


### 조용한 손과 비교해서 익힘

<p style="margin: 0 0 1em 0;">전완 회전은 ‘조용한 손’과 대비해서 연습하면 차이를 알기 쉬움. 바흐의 인벤션 8번에는 두 동작이 모두 필요하므로 좋은 연습곡이 됨.</p>

<p style="margin: 0 0 1em 0;">속도가 빨라질수록 손을 언제나 움직이지 않아야 한다는 생각은 잘못임. 어떤 악절은 조용한 손이 필요하지만, 어떤 악절은 전완 회전을 써야 빠르고 편하게 칠 수 있음.</p>

<p style="margin: 0 0 1em 0;">베토벤 비창 소나타 Op. 13 1악장의 트레몰로와 알베르티 베이스 동작도 전완 회전이 필요한 예임. 이 동작을 배우지 못한 학생은 속도를 올리려다 긴장을 쌓고, 때로는 부상까지 입음.</p>

<p style="margin: 0 0 1em 0;">전완 회전을 제대로 넣으면 속도, 힘, 지구력 문제가 크게 줄어듦. 힘으로 버티지 않고 몸을 푼 상태에서 빠르게 연주할 수 있음.</p>
