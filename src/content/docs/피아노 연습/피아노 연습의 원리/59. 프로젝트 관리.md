<strong>피아노 연습의 원리 한글판 </strong>
<span class="notion-text-gray">(dcinside digital piano gallery)</span>

새 곡을 배울 때마다 하나의 프로젝트를 운영하게 됨. 곡을 고르고 연습법을 정한 뒤 처음부터 무대 연주까지 완성하는 일을 계속 반복하기 때문임.

여러 곡을 이런 방식으로 마치다 보면 프로젝트 관리(Project Management, PM)에도 익숙해짐. 피아노에서 배운 관리 원칙은 기타·바이올린·플루트 같은 다른 악기뿐 아니라 건축, 조각, 목공, 정원 관리, 군사 작전 등에도 적용할 수 있음. 저자는 알렉산더 대왕이 제국을 세운 과정도 프로젝트 관리의 사례로 들고 있음.

프로젝트 관리의 기본 규칙 자체는 단순함. 어려운 점은 각 단계에서 필요한 지식을 충분히 갖추는 데 있음. 무엇을 알아야 하는지에 따라 계획과 결과가 달라지므로 성공은 결국 지식 기반에 달려 있음.


# 1. 준비

프로젝트를 시작하기 전에 출발부터 실행, 마무리, 완성 뒤의 유지보수까지 계획함. 목표와 일정도 미리 정하고, 완성에 필요한 정보를 먼저 모음.

새 곡을 고를 때는 다음 질문부터 확인함.

- 재미로 칠 곡인가?

- 무대에서 연주할 곡인가?

- 다른 사람을 가르칠 때 사용할 곡인가?

- 특정 테크닉을 익히려는 곡인가?

- 어려운 구간마다 필요한 연습법을 알고 있는가?

- 곡을 배우는 데 얼마나 걸릴 것인가?

목적이 다르면 완성의 기준과 연습에 들일 시간도 달라짐. 어려운 구간과 필요한 테크닉을 미리 살펴보면 시작한 뒤에 방법을 찾느라 시간을 잃지 않음.


# 2. 시작

어떻게 시작할지는 뒤의 실행·마무리·유지보수 방식에 따라 결정됨. 첫 단계는 전체 계획을 실제 행동으로 옮기는 출발점임. 나중에 무엇을 어떻게 할지 모른 채 일단 시작하면 연습 방향이 자주 바뀜.

피아노에서는 다음 항목을 출발 단계에 포함함.

- 전곡 <a href="/피아노-연습/피아노-연습의-원리/14-암보의-요령과-원칙/" style="color: inherit; text-decoration: underline;">암보</a>

- 머릿속 연주(<a href="/피아노-연습/피아노-연습의-원리/15-멘탈-플레이mp/" style="color: inherit; text-decoration: underline;">Mental Play</a>, MP)

- 악보 읽기

- 음악 이론으로 곡의 구조 이해하기

건반에서 처음부터 끝까지 반복하기 전에 곡 전체를 어떻게 배우고 기억할지 먼저 정함.


# 3. 실행


## 불가능한 일을 한꺼번에 붙잡지 않기

당장 처리할 수 있는 작은 단위로 나눔. 쉬운 단위일수록 좋으며, 필요하면 더 단순하게 만듦. 이웃한 구간은 일부가 서로 겹치게 잡아야 나중에 자연스럽게 연결할 수 있음.

피아노에서는 <a href="/피아노-연습/피아노-연습의-원리/6-양손-분리-연습/" style="color: inherit; text-decoration: underline;">한손 연습</a>, 구간 연습, 병렬 세트와 <a href="/피아노-연습/피아노-연습의-원리/7-어려운-부분-먼저-구간별-연습-연속성-규칙/" style="color: inherit; text-decoration: underline;">연속성 규칙</a>을 적용함.


## 한 구간을 마친 뒤 다음으로 넘어가기

각 구간을 충분히 익힌 뒤 다음 구간으로 감. 프로젝트의 여러 부분은 서로 받쳐 주므로 순서대로 이어서 처리하는 편이 좋음. 정원의 잡초를 뽑거나 군사 작전을 수행할 때도 작업 구역이 이어져야 빈틈이 생기지 않음. 피아노의 연속성 규칙도 같은 원리임.

한손으로 최종 속도보다 빠르게 칠 수 있을 때까지 연습함. 한손 연습을 충분히 끝낸 뒤 <a href="/피아노-연습/피아노-연습의-원리/37-양손-연습/" style="color: inherit; text-decoration: underline;">양손 연습</a>으로 넘어가며, 건반 연습을 본격적으로 진행하기 전에 암보도 완성함.


## 효과가 검증된 방법과 함정 알아두기

어떤 분야든 지식과 경험에서 나온 요령이 있음. 교육은 정보만 전달하지 않고 필요한 지식을 찾는 법도 가르쳐 줌. 잘해야 할 일을 아는 것만큼 피해야 할 일을 아는 것도 중요함.

피아노에서는 한손·구간 연습, <a href="/피아노-연습/피아노-연습의-원리/9-병렬-세트-연습/" style="color: inherit; text-decoration: underline;">병렬 세트</a>, 손동작, 느린 연주, <a href="/피아노-연습/피아노-연습의-원리/25-스타카토-연습과-여리게-연습하기/" style="color: inherit; text-decoration: underline;">스타카토 연습</a>, <a href="/피아노-연습/피아노-연습의-원리/8-이완과-중력/" style="color: inherit; text-decoration: underline;">이완</a>처럼 효율이 검증된 방법을 사용함.

연습곡을 기계적으로 반복하거나 ‘재능이 있어야 된다’는 함정에 빠지지 않음. 직관에는 그럴듯해 보여도 실제로는 발전을 막는 연습법이 있으므로 결과를 확인하면서 선택함.


## 중간 점검과 계획 수정

계획대로 진행되는지 정기적으로 시험함. 처음 세운 계획이 아무리 좋아도 실제 연습 결과에 따라 고치거나 보완해야 할 수 있음.

피아노에서는 다음 방법으로 점검함.

- 머릿속 연주

- 자신의 연주 녹음

- 교사에게 받는 레슨

- 비공식 연주나 예비 무대

- 곡의 어느 지점에서든 바로 시작해 보기

틀린 부분을 찾는 데서 끝내지 말고, 결과를 바탕으로 구간과 연습법과 일정을 다시 조정함.


# 4. 마무리

프로젝트가 실패하는 원인에는 잘못된 가정, 달성할 수 없는 목표, 부족하거나 틀린 지식이 많음. 충분히 배워야 자신이 세운 가정과 지식 기반을 제대로 평가할 수 있음.

무엇을 완성으로 볼지 정확히 정해야 프로젝트를 끝낼 수 있음. 피아노에서는 단순히 끝까지 치는 것을 완성으로 보지 않음. 처음 정한 목적에 맞는 수준에 도달해야 함.

연주회가 목표라면 무대에서 연주하는 것으로 마무리함. 완성한 곡은 테크닉과 음악성을 더 발전시키는 교재로 계속 활용함. 저자는 <a href="/피아노-연습/피아노-연습의-원리/17-절대음감과-상대음감/" style="color: inherit; text-decoration: underline;">절대음감</a>과 천재성도 교육으로 기를 수 있다는 관점을 함께 제시함.


# 5. 유지보수

가치 있는 프로젝트는 완성 뒤에도 오래 사용함. 유지보수에 드는 시간과 자원이 처음 완성할 때보다 더 많아질 수도 있음.

완성한 곡은 레퍼토리로 유지하면서 계속 개선함. 음, 리듬, 표현이 정확한지 정기적으로 확인하고, 워밍업 없이 바로 연주하는 콜드 플레이(Playing Cold)도 점검에 활용함.

예전에 완성한 곡은 보관만 하는 결과물이 아님. 이미 익숙한 곡에서 손동작과 표현을 더 세밀하게 다듬으면 새로운 곡을 배울 때 놓치기 쉬운 테크닉까지 발전시킬 수 있음.
