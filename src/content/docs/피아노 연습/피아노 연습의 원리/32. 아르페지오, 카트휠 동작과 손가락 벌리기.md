<p style="margin: 0 0 1em 0;">아르페지오는 화음의 음을 한꺼번에 누르지 않고 차례로 펼쳐 연주한 것임. 단순해 보여도 여러 손동작을 함께 써야 해서 테크닉은 복잡함.</p>

<p style="margin: 0 0 1em 0;">편 손가락 자세, 밀기와 당기기, 카트휠 동작, 글리산도 동작, 손가락 벌리기, TU와 TO 등이 서로 맞물림. 굽힌 손가락 자세만 배운 사람에게 아르페지오가 유난히 어렵게 느껴지는 이유임. 음 사이가 멀어서 각 건반을 정확히 찾기도 쉽지 않음.</p>


### 아르페지오도 TO로 침

<p style="margin: 0 0 1em 0;">아르페지오는 음계와 마찬가지로 TO를 사용함. 음 사이가 넓어 엄지를 손바닥 아래로 넣어 다음 위치까지 보내기 어려우므로 음계보다 TO가 더 중요함.</p>

<p style="margin: 0 0 1em 0;">다장조 도-미-솔-도-미-솔 아르페지오의 기본 상행 운지는 다음과 같음.</p>

- 오른손: 1-2-3-1-2-3 … 5
- 왼손: 5-4-2-1-4-2-1 … 1
- 하행: 상행의 반대
<p style="margin: 0 0 1em 0;">모든 음계와 아르페지오 운지는 Michael Aaron의 《Adult Piano Course, Book Two》에서도 확인할 수 있음.</p>

<p style="margin: 0 0 1em 0;">음 사이가 넓다고 손가락부터 벌리는 사람이 많음. 빠른 아르페지오에서는 손가락이 느려지고 긴장과 피로가 쌓임. 손가락을 계속 벌리기보다 카트휠 동작과 손가락 벌리기를 써서 손 전체를 이동함.</p>


## 카트휠 동작

<p style="margin: 0 0 1em 0;">손을 수레바퀴처럼 굴리면 작은 손도 훨씬 넓은 범위를 끊김 없이 지나갈 수 있음.</p>


### 수평 카트휠

<p style="margin: 0 0 1em 0;">왼손 손바닥을 건반 위에 평평하게 놓고 손가락을 바퀴살처럼 펼침. 새끼손가락부터 엄지까지의 손끝은 대략 반원을 그림.</p>

1. 새끼손가락을 C3 위에 놓고 건반과 나란히 맞춤.
1. 엄지가 몸 쪽에 가까워지도록 손을 돌림.
1. 손가락을 펼친 상태에서 손을 건반 안쪽으로 밀어 새끼손가락이 건반 덮개 앞쪽에 닿게 함.
1. 4번 손가락이 먼저 닿으면 새끼손가락이 닿을 때까지 손을 더 돌림. 새끼손가락은 가능한 한 C3와 나란히 유지함.
1. 위에서 보았을 때 반시계 방향으로 바퀴를 굴리듯 손을 돌림.
1. 손가락이 미끄러지지 않게 차례로 건반 덮개 앞쪽에 닿게 하여 엄지까지 이동함.
<p style="margin: 0 0 1em 0;">손목이 유연해야 함.</p>

<p style="margin: 0 0 1em 0;">평소 한 옥타브를 잡는 손도 이 동작으로는 거의 두 옥타브를 덮을 수 있음. 가운데 세 손가락이 엄지와 새끼손가락보다 길고, 반원의 둘레가 지름보다 길어서 범위가 늘어남.</p>


### 수직 카트휠

<p style="margin: 0 0 1em 0;">이번에는 손가락이 아래를 향하도록 손을 세움.</p>

1. 새끼손가락을 세운 채 손을 내려 C3을 누름.
1. 손을 C4 쪽으로 굴림.
1. 각 손가락이 닿는 건반을 차례로 누름.
1. 엄지에 도착할 때까지 이어 감.
<p style="margin: 0 0 1em 0;">이 동작도 평소 손을 뻗는 거리의 거의 두 배를 덮음.</p>

<p style="margin: 0 0 1em 0;">카트휠 연습으로 세 가지를 배움.</p>

- 손을 바퀴처럼 굴리는 방법
- 도약하지 않고 손의 범위를 넓히는 방법
- 손가락을 크게 움직이지 않고도 건반을 누르는 방법
<p style="margin: 0 0 1em 0;">실제 연주에서는 수평과 수직의 중간 각도로 씀. 손가락은 피라미드 자세나 조금 굽힌 자세가 됨.</p>

<p style="margin: 0 0 1em 0;">카트휠 자체도 건반을 누르는 움직임을 만들지만, 실제 음은 손가락 동작까지 더해 침.</p>

<p style="margin: 0 0 1em 0;">수평 카트휠은 손목의 느린 좌우 움직임을 주로 씀. 수직에 가까워질수록 훨씬 빠른 전완 회전을 쓸 수 있음.</p>


## 손가락 벌리기

<p style="margin: 0 0 1em 0;">프레이저가 설명한 손가락 벌리기(finger splits)를 더하면 범위가 한층 넓어짐.</p>

<p style="margin: 0 0 1em 0;">오른손 2번과 3번 손가락으로 V자를 만듦. 평평한 탁자 가장자리에 두 손가락만 올리고 나머지 손은 바깥에 둠.</p>

<p style="margin: 0 0 1em 0;">편안한 범위에서 V자를 최대한 벌림. 그 상태에서 팔과 손을 시계 방향으로 90도 회외해 두 손가락의 옆면이 탁자에 닿게 함. 같은 두 손가락을 다시 벌려 보면 처음보다 간격이 더 커짐.</p>

<p style="margin: 0 0 1em 0;">어느 손가락 조합에도 적용할 수 있음.</p>

<p style="margin: 0 0 1em 0;">카트휠만 써도 평소의 거의 두 배까지 범위가 늘고, 손가락 벌리기를 함께 쓰면 두 배를 넘길 수도 있음.</p>


### 편 손가락으로 검은건반을 잡음

<p style="margin: 0 0 1em 0;">아르페지오에는 편 손가락 자세가 가장 잘 맞음. 손가락 앞쪽의 넓은 살로 건반을 누를 수 있어 좁은 검은건반을 빗맞힐 가능성이 크게 줄어듦.</p>

<p style="margin: 0 0 1em 0;">검은건반을 굽힌 손가락으로만 치려 하면 아르페지오가 무섭고 답답하게 느껴질 수 있음.</p>

<p style="margin: 0 0 1em 0;">TO, 편 손가락, 카트휠, 손가락 벌리기를 함께 쓰면 손을 무리하게 늘이지 않고도 넓은 음정을 빠르게 연주할 수 있음. 유연한 손목과 전완 회전이 이 복잡한 조합을 이어 줌.</p>

<p style="margin: 0 0 1em 0;">여러 동작을 처음부터 한꺼번에 연습하지 않음. 각각을 따로 익힌 뒤 하나씩 결합함.</p>
