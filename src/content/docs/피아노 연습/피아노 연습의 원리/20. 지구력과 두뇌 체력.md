<p style="margin: 0 0 1em 0;">피아니스트 마들렌 드 발마레트 콩브(Madeleine de Valmalète Combe)는 손을 쥐는 힘이 보통 사람보다 강하지 않았음. 악수할 때 손힘이 센 저자도 그 힘이 피아노 실력과 관계한다고 보지 않았음.</p>

<p style="margin: 0 0 1em 0;">큰 소리와 웅장한 악절에는 많은 에너지가 듦. 몸집이 크고 힘이 센 사람은 큰 소리를 내거나 힘든 곡을 오래 다루는 데 유리할 수 있음. 그래도 보통 사람은 현재 연주 수준에 필요한 근력을 이미 갖추고 있음. 피아노에서는 손가락 힘을 더 키우는 일보다 정교한 조절과 지구력을 기르는 일이 먼저임.</p>


### 연주는 몸과 두뇌가 함께 하는 운동임

<p style="margin: 0 0 1em 0;">힘든 곡을 연주할 때 쓰는 에너지는 시속 3마일 정도로 천천히 달릴 때와 비슷함. 그중 상당 부분은 두뇌가 씀.</p>

<p style="margin: 0 0 1em 0;">어린 학생은 1마일도 계속 달리기 어려울 수 있음. 힘든 악절을 20분 동안 연습하는 일도 비슷한 부담을 줄 수 있음. 그래서 어린 초보자는 지구력이 붙을 때까지 한 번에 20분을 넘기지 않는 편이 좋음.</p>

<p style="margin: 0 0 1em 0;">두뇌의 지구력도 따로 길러야 함. 생각 없이 반복하는 체력 훈련으로는 두뇌 체력이 늘지 않음.</p>

<p style="margin: 0 0 1em 0;">가장 효과적인 방법은 완성한 곡을 음악적으로 연주하는 것임. 어려운 부분은 한 손씩 이어서 연습함. 쉬운 곡을 연주하는 시간을 강도 높은 연습 사이에 넣어도 좋음.</p>

<p style="margin: 0 0 1em 0;">집중해서 두 시간 연습하면 6마일을 천천히 달리는 것과 비슷한 에너지가 들 수 있음. 상당한 수준에 오르기 전에는 하루 몇 시간을 넘긴 강도 높은 연습이 별 도움이 되지 않음. 제대로 한 어려운 연습은 그 자체로 힘든 운동이며 몸 상태도 좋아지게 함.</p>


### 두뇌 체력이 더 중요함

<p style="margin: 0 0 1em 0;">두뇌는 에너지를 많이 쓰므로 본능적으로 소비를 줄이려 함. 음악과 테크닉을 떼어 놓고 손가락만 반복하면 두뇌를 충분히 쓰지 않게 됨. 음악 없는 습관이 붙고 시간도 낭비함.</p>

<p style="margin: 0 0 1em 0;">두뇌 체력이 부족하면 연주 도중 집중력이 먼저 바닥남. 그러면 손이 자동으로 움직이는 상태에 기대게 되고, 실수에 대처하기 어려워짐.</p>

<p style="margin: 0 0 1em 0;">근육을 무리하게 단련하는 것도 좋지 않음. 몸에 긴장이 쌓이고, 빠른 움직임에 유리한 근육 특성이 느리고 버티는 움직임 쪽으로 바뀔 수 있음.</p>

<p style="margin: 0 0 1em 0;">오래 연습하다가 지친 뒤 갑자기 다시 힘이 나는 ‘세컨드 윈드’가 올 때도 있음. 피곤하다고 해서 지구력이 부족하다고 단정할 수는 없음. 몸이 적응할 시간을 주고 세컨드 윈드가 오는지 살펴봄.</p>


### 산소와 혈액 공급

<p style="margin: 0 0 1em 0;">지구력은 산소 공급, 이산화탄소 배출, 혈액 순환과 밀접함. 폐를 효율적으로 쓰는 방법은 앞의 호흡 연습과 이어짐.</p>

<p style="margin: 0 0 1em 0;">연습할 때 근육과 두뇌를 함께 쓰면 몸은 필요한 혈액량에 적응함. 반대로 두뇌가 충분히 관여하지 않는 반복만 하면 이런 적응을 기대하기 어려움.</p>

<p style="margin: 0 0 1em 0;">책에서는 빈혈이 있는 사람이 생각을 덜 쓰는 반복 연습을 편하게 느낄 수 있다고 설명함. 혈액 공급이 부족하면 두뇌가 에너지 소비를 꺼리기 때문이라는 견해임. 하지만 그런 연습은 음악과 두뇌 체력을 키우지 못함.</p>

<p style="margin: 0 0 1em 0;">또 식사 뒤 곧바로 누워 지내는 습관보다 무리가 없는 범위에서 몸을 움직이는 편이 체력 유지에 낫다고 봄. 처음에는 속이 불편하거나 어지러울 수 있으므로 몸 상태가 허용하는 범위 안에서만 움직여야 함. 평소 운동과 스포츠도 전반적인 건강과 지구력에 도움이 됨.</p>


### 연습 자체를 음악으로 만듦

<p style="margin: 0 0 1em 0;">두뇌는 음악을 만들 때 끊임없이 활동함. 따라서 연습도 공연처럼 음악적으로 해야 함.</p>

<p style="margin: 0 0 1em 0;">초보자의 지구력은 서서히 길러야 함. 아주 어린 학생은 한 번에 20분보다 짧게 시작할 수 있음. 누구나 피아노에 필요한 근력은 이미 충분하므로, 힘을 키우기보다 이완과 조절, 음악적 집중을 연습함.</p>

<p style="margin: 0 0 1em 0;">전문 피아니스트가 하루 여섯 시간씩 연습한다고 해서 근육질 체형이 되는 것은 아님. 리스트, 쇼팽, 파가니니도 체격이 크거나 우람한 연주자가 아니었음. 피아노 연주의 핵심은 근력이 아니라 조절 능력과 몸·두뇌의 지구력임.</p>
