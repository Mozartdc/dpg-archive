<p style="margin: 0 0 1em 0;">피이노 연주에선 흉쇄관절/어깨관절/팔꿈치, 세 군데 회전이 모두 필요함. 그중 전완 회전을 제대로 이해해야 손목과 손가락의 긴장이 줄어듦.</p>

<img src="/images/05.-팔의-세-가지-로테이션-0.png" alt="본문 이미지 1" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

1. 흉쇄관절에서 일어나는 로테이션
<p style="margin: 0 0 1em 0;">쇄골과 견갑골이 흉쇄관절을 축으로 같이 움직이는 회전임. 손을 몸 앞에서 교차하거나 건반 끝까지 크게 뻗을 때 가장 크게 개입함.</p>

<p style="margin: 0 0 1em 0;">이 회전이 있어야 팔 전체가 몸통 기준으로 자연스럽게 움직임.</p>

<p style="margin: 0 0 1em 0;">양 손 중지를 쇄골의 시작점(흉쇄관절)에 올리고 견갑골을 크게 회전해보면 쇄골이 어떻게 로테이션을 만드는지 느낄 수 있음.</p>

1. 어깨관절의 로테이션
<p style="margin: 0 0 1em 0;">상완골이 어깨관절 안에서 돌아가는 회전임. 팔 방향만 바뀌고, 팔꿈치가 굽거나 전완이 도는 건 아님. 건반을 따라 좌우로 이동하거나 넓은 도약에서 쓰임.</p>

1. 팔꿈치에서 시작하는 전완 로테이션
<p style="margin: 0 0 1em 0;">요골이 척골을 축으로 돌면서 손바닥 방향이 바뀌는 움직임임. 손바닥을 아래로 돌려 건반에 올리는 동작(회내)도 이 회전에 속함.</p>

<p style="margin: 0 0 1em 0;">피아노에서 가장 자주 쓰는 로테이션이고, 연주 테크닉에서도 핵심 요소임.</p>

<p style="margin: 0 0 1em 0;">그런데, 많은 사람이 첫 번째와 두 번째 회전을 거의 의식하지 않음.</p>

<p style="margin: 0 0 1em 0;">그러다 보니 쇄골/견갑골과 어깨관절을 충분히 사용하지 못하고, 팔 전체가 굳어 버림.</p>

<p style="margin: 0 0 1em 0;">반면 세 번째 회전은 거의 모든 사람이 쓰지만, 잘못 이해하는 경우가 많음.</p>

<p style="margin: 0 0 1em 0;">엄지 쪽을 축으로 손을 돌린다고 생각해서 손목이 비틀리거나 긴장이 쌓이는데, 새끼손가락 쪽을 축으로 전완이 돈다고 느끼면 손목과 손가락이 훨씬 부드러워짐.</p>
