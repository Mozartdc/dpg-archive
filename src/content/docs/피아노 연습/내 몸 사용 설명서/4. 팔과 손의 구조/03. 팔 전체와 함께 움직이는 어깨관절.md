<p style="margin: 0 0 1em 0;">어깨관절은 팔이 몸통에 붙어 있는 고정점이 아니라, 팔 전체 구조 안에서 함께 움직이는 관절임.</p>

<p style="margin: 0 0 1em 0;">보통 우리는 어깨를 몸통에 박힌 축처럼 생각하지만, 실제 어깨의 움직임은 독립적이라기보다 훨씬 유기적임. 흉쇄관절에서 쇄골과 견갑골, 그리고 어깨관절이 연쇄적으로 움직여야 자연스러운 팔 움직임이 따라옴.</p>

<p style="margin: 0 0 1em 0;">피아노 앞에 바르게 앉아서 손을 건반 안쪽(검은건반 쪽)으로 넣었다 뺄 때, 쇄골부터 어깨관절이 자연스럽게 따라 움직여주지 않으면 손목과 손가락이 이를 보상하기 위해 경직되는 것을 느낄 수 있음.</p>

<img src="/images/03.-팔-전체와-함께-움직이는-어깨관절-0.png" alt="본문 이미지 1" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

<img src="/images/03.-팔-전체와-함께-움직이는-어깨관절-1.png" alt="본문 이미지 2" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

<p style="margin: 0 0 1em 0;">이런 문제는 어깨가 건담처럼 몸통에 끼워진 고정된 소켓으로 생각하는 순간 시작됨.</p>

<p style="margin: 0 0 1em 0;">사실 어깨는 팔은 쇄골과 견갑골로 몸통과 연결된 유연한</p>

<p style="margin: 0 0 1em 0;">구조임. 그런데 어깨를 축으로 인식하는 순간 자연스러운 움직임을 막고, 팔 전체가 부자연스러워짐.</p>

<img src="/images/03.-팔-전체와-함께-움직이는-어깨관절-2.png" alt="본문 이미지 3" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

<p style="margin: 0 0 1em 0;">덩달아 주변 뼈들이 제 역할을 못 하니 어깨관절만 과도하게 움직이면서도, 전체적으로는 움직임이 부자연스러운 이상한 상태가 되며, 어깨의 움직임 부족과 과사용이라는 역설이 나타남.</p>

<p style="margin: 0 0 1em 0;">그래서 피아노를 칠 때는 팔을 좌우로 이동하거나, 손 방향을 전환하거나, 검은건반 안팎으로 미세하게 들어갈 때 쇄골과 견갑골에서 시작되는 움직임이 어깨관절을 통해 손까지 자연스럽게 전달되어야 함.</p>

<p style="margin: 0 0 1em 0;">어깨관절을 고정시켜버리면 이 연쇄가 끊어지기 때문에, 손목과 손가락만으로 과도하게 보상하게 되며 움직임이 경직됨.</p>

<p style="margin: 0 0 1em 0;">마지막으로, 팔을 편안하게 늘어뜨렸을 때 손바닥이 완전히 허벅지를 향한다면, 사실은 어깨에 약간의 회전 긴장이 남아있다는 의미임. 쇄골과 어깨가 완전히 풀리면 손등이 자연스럽게 앞쪽을 향하고, 이 상태에서 건반 위로 손을 올려야 편안한 자세를 만들 수 있음.</p>
