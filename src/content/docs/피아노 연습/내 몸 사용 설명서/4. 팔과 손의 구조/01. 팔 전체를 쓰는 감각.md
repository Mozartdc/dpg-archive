<p style="margin: 0 0 1em 0;">피아노를 칠 때 팔을 손가락과 손목 중심으로만 생각하면 움직임이 제한됨. 실제 팔의 움직임은 손끝에서 끝나는 것도 아니고, 어깨관절에서 시작되는 것도 아님. 쇄골과 견갑골까지 함께 움직여야 팔 전체가 자연스럽게 움직임.</p>

<p style="margin: 0 0 1em 0;">대부분의 문제는 어깨를 낮춰라, 어깨가 올라가면 안 된다라는 말을 어깨를 움직이지 말라는 뜻으로 받아들이는데서 생김.</p>

<p style="margin: 0 0 1em 0;">어깨를 아래로 누르고 고정하는 순간 쇄골과 견갑골까지 같이 굳고, 팔 전체가 자연스럽게 이어지지 못함. 그러면 손목과 손가락이 부족한 움직임을 대신하게 됨. 겉으로는 자세가 안정돼 보여도, 실제로는 팔 전체의 흐름이 끊기고 손목과 손가락만 과하게 움직이는 안좋은 자세임.</p>

<img src="/images/01.-팔-전체를-쓰는-감각-0.png" alt="팔 전체를 쓰는 감각" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

<p style="margin: 0 0 1em 0;">피아노 연주의 질을 높이려면, [팔을 어디서부터 팔로 느끼느냐]가 매우 중요함.</p>

<p style="margin: 0 0 1em 0;">보통 어깨부터 손끝까지를 팔이라고 생각하는데, 그러면 쇄골과 견갑골은 팔이 아니라 몸통 쪽 구조로 생각되어 의식적으로 고정하게됨. 이게 뻣뻣하고 부자연스러운 자세의 원인임.</p>

<p style="margin: 0 0 1em 0;">실제로는 피아노 칠 때 손끝의 움직임이 손목, 팔꿈치, 상완에서만 끝나는 게 아니라 견갑골과 쇄골까지 함께 움직여야함. 그리고 그 전체 구조가 몸통과 직접 만나는 곳이 흉쇄관절임.</p>

<img src="/images/01.-팔-전체를-쓰는-감각-1.png" alt="흉쇄관절에서 손끝까지 이어지는 팔 구조" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

<p style="margin: 0 0 1em 0;">이 전체가 하나의 팔 구조임.</p>

<p style="margin: 0 0 1em 0;">왜 이게 중요하냐면, 쇄골과 견갑골을 팔 움직임에서 빼 버리면 어깨 주변이 고정되고, 팔 전체로 나눠서 해야 할 움직임을 말단부가 대신하면서 팔목과 손가락에 피로가 몰리게 됨.</p>

<p style="margin: 0 0 1em 0;">물론, 피아노에서 견갑골과 쇄골이 크게 움직일 필요는 없음. 하지만 아예 고정되면 문제가 생긴다는 것임. 이 부위가 자기 몫만큼 움직이지 못하면 연결된 팔 어딘가에서는 그 부족한 움직임을 대신 보상하게 됨. 그래서 손이 무거워지고, 팔이 뻣뻣해지고, 어깨와 목에도 긴장이 쌓이는 것임.</p>

<p style="margin: 0 0 1em 0;">팔은 흉쇄관절에서 손끝까지 이어지는 하나의 연결된 구조임. 이 감각을 정확히 인지하고 있어야 팔의 무게와 움직임이 손끝까지 자연스럽게 이어질 수 있음.</p>
