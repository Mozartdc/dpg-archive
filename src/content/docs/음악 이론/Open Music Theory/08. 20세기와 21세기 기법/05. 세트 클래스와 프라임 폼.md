같은 음류 집합을 이조하거나 전위해도 음정 구조는 서로 이어짐. 그렇게 \(T_n\)이나 \(I_n\) 관계로 묶이는 음류 집합들을 <strong>세트 클래스</strong>(set class, 집합류)라고 부름. 프라임 폼은 그 세트 클래스에 붙이는 대표 이름임.

## 음류 집합과 세트 클래스

음류 집합은 분석자가 어떤 이유로 한데 묶은 음류임. 꼭 특별한 친연 관계를 가져야 하는 것은 아님. 반면 세트 클래스는 이조 또는 전위로 서로 옮길 수 있다는 분명한 관계를 가진 음류 집합들의 묶음임.

식물로 비유하면 앞마당에 있는 식물을 한데 부르는 일은 단순한 집합을 만드는 일이고, 꽃을 피우는 식물처럼 생물학적 관계를 따라 부르는 일은 분류를 만드는 일에 가까움. 음악에서도 눈앞의 음들을 한 묶음으로 고른 뒤, 그 묶음이 다른 묶음과 \(T_n\)·\(I_n\)로 이어지는지를 봐야 세트 클래스를 알 수 있음.

앞글의 음고와 음류, 음정과 음정류도 같은 차이를 보여 줌.

| 구체적으로 적는 것 | 관계로 묶은 것 |
| --- | --- |
| 음고: 특정 옥타브와 표기를 가진 음 | 음류: 옥타브와 이명동음을 넘어서 묶은 음 |
| 음정: 특정 반음 거리 | 음정류: 전위·옥타브 관계를 묶은 가장 짧은 거리 |
| 음류 집합: 분석자가 고른 음류 묶음 | 세트 클래스: 이조·전위 관계인 음류 집합의 묶음 |

## 왜 이조와 전위를 보나

Bartók의 〈Subject and Reflection〉 두 구절을 비교하면 오른손의 [10, 0, 2, 3, 5]와 [3, 5, 7, 8, 10]은 \(T_5\) 관계임. 왼손의 두 집합도 같은 방식으로 이어짐. 각 구절 안에서 오른손과 왼손을 비교하면 첫 구절은 \(I_8\), 둘째 구절은 \(I_6\) 관계임. 악보의 높이와 음이름이 달라도 같은 세트 클래스에 속한다는 말로 이 관계를 짧게 설명할 수 있음.

장3화음과 단3화음도 익숙한 예임.

- 같은 성질의 3화음은 이조 관계임. C장3화음 [0, 4, 7]에 \(T_2\)를 적용하면 D장3화음 [2, 6, 9]이 되고, a단3화음 [9, 0, 4]에 \(T_2\)를 적용하면 b단3화음 [11, 2, 6]이 됨.
- 장·단처럼 성질이 다른 3화음은 전위 관계임. C장3화음 [0, 4, 7]에 \(I_0\)을 적용하면 f단3화음 [5, 8, 0], \(I_2\)를 적용하면 g단3화음 [7, 10, 2]가 됨.

그래서 장·단3화음은 증·감3화음이나 음군과는 다른 하나의 세트 클래스로 들림.

## 프라임 폼

<strong>프라임 폼</strong>은 세트 클래스를 부르기 위해 정한 대표 배열임. 노멀 폼을 0에서 시작하도록 옮기고, 그 전위형과 비교해 왼쪽에 더 촘촘하게 모인 쪽을 고름. 프라임 폼은 이름표일 뿐이므로, 작곡가가 우연히 [0, 1, 4]를 썼다고 해서 그 음류들이 특별한 지위를 갖는 것은 아님.

Bartók 예의 [10, 0, 2, 3, 5]를 계산해 보겠음.

| 순서 | 계산 | 결과 |
| ---: | --- | --- |
| 1 | 음류 집합을 노멀 폼으로 정리 | [10, 0, 2, 3, 5] |
| 2 | 첫 수가 0이 되도록 이조 | \(T_2\) → [0, 2, 4, 5, 7] |
| 3 | 2단계 결과를 전위하고 노멀 폼으로 정리 | \(I_0\) → [5, 7, 8, 10, 0] |
| 4 | 3단계의 첫 수도 0으로 이조 | \(T_7\) → [0, 2, 3, 5, 7] |
| 5 | 2단계와 4단계를 비교해 왼쪽에 더 촘촘한 쪽을 고름 | (02357) |

프라임 폼은 대괄호가 아니라 쉼표 없는 괄호로 적음. [0, 2, 3, 5, 7]은 특정한 한 음류 집합이고, (02357)은 그와 이조·전위 관계인 모든 집합을 가리키는 세트 클래스 이름임.

시계판으로도 같은 계산을 할 수 있음. 먼저 가장 큰 빈틈을 찾아 노멀 폼을 만들고, 시작점을 0으로 옮김. 전위한 모양에도 같은 절차를 거친 뒤 두 결과 가운데 왼쪽이 더 조밀한 쪽을 고르면 됨.

## 세트 클래스 표

가능한 세트 클래스와 프라임 폼의 수는 유한함. <a href="https://en.wikipedia.org/wiki/List_of_pitch-class_sets" target="_blank">세트 클래스 표</a>는 보통 집합의 원소 수에 따라 목록을 나누고, 각 세트 클래스에 포트 번호(Forte number)도 붙임. 표에는 원래 집합과 합쳐 열두 음류를 완성하는 <strong>여집합</strong>도 짝지어 놓음. 음정류 벡터처럼 표의 다른 정보는 다음 글에서 다룸.

원문은 세트 클래스를 찾아 변형을 계산하는 준비 과제와, 세트 클래스를 써서 무반주 독주 악기를 위한 24마디 ABA 형식 작품을 쓰고 분석하는 과제도 제안함.
