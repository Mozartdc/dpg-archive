무조 음악과 집합 이론에서는 같은 이름의 음을 어느 옥타브에 놓았는지보다, 그 음들이 어떤 종류에 속하는지가 더 중요할 때가 많음. 그래서 <strong>음고</strong>와 <strong>음류</strong>를 구별하고, 열두 음류를 0부터 11까지의 정수로 적음.

## 음고

<strong>음고</strong>는 각각 고유한 주파수를 가진 개별 음임. C<sub>4</sub>와 C<sub>3</sub>는 이름이 같아도 서로 다른 높이에 있으므로 같은 음고가 아님. 옥타브가 같다고 보는 관념은 음고라는 말에 처음부터 들어 있지 않음.

피아노에서 가온 도 C<sub>4</sub>를 친 뒤 그 아래 C<sub>3</sub>를 치면, 둘은 같은 음이름이지만 분명 다른 높이로 들림. 음고를 다룰 때는 바로 이 차이를 남겨 둠.

## 음류

집합 이론에서 <strong>음류</strong>(pitch class)는 옥타브 등가와 이명동음 관계로 묶이는 음고의 집합임. C<sub>4</sub>, C<sub>3</sub>, C<sub>9</sub>는 모두 C라는 같은 음류에 속함. G♯<sub>2</sub>와 A♭<sub>4</sub>도 평균율에서 같은 소리를 내므로 한 음류로 봄.

<img src="/images/open-music-theory/08-20th-21st-century-techniques/pitch-and-pitch-class/pitch-and-pitch-class.jpg" alt="서로 다른 옥타브의 같은 C가 음고는 다르지만 같은 음류임을 보여 주는 도해" style="max-width:100%;height:auto;display:block;margin:10px auto;" />

<p style="text-align:center;color:#6b7280;font-size:.9em;">예 1. 음고와 음류의 차이</p>

음고는 실제 높이를 남기고, 음류는 옥타브를 지워 같은 이름의 음을 한데 묶음. 이 구별이 있어야 이후의 음류 집합, 전위, 이조를 헷갈리지 않음.

## 정수 표기

일곱 음이름만으로는 이명동음을 포함한 열두 음류를 빠짐없이 적기 어려움. 집합 이론은 C를 0으로 두고 반음 위로 갈수록 1씩 늘리는 <strong>정수 표기</strong>를 씀. B 다음은 다시 C이므로 11 다음에는 0으로 돌아옴.

<img src="/images/open-music-theory/08-20th-21st-century-techniques/pitch-and-pitch-class/pitch-class-clock.jpg" alt="열두 음류를 시계 모양으로 배열한 정수 표기 도해" style="max-width:288px;width:100%;height:auto;display:block;margin:10px auto;" />

<p style="text-align:center;color:#6b7280;font-size:.9em;">예 2. 시계 모양으로 배열한 열두 음류</p>

| 정수 | 대표 음이름 | 같은 음류로 보는 이명동음 예 |
| ---: | --- | --- |
| 0 | C | B♯ |
| 1 | C♯ / D♭ |  |
| 2 | D | C𝄪 |
| 3 | D♯ / E♭ |  |
| 4 | E | F♭ |
| 5 | F | E♯ |
| 6 | F♯ / G♭ |  |
| 7 | G | F𝄪 |
| 8 | G♯ / A♭ |  |
| 9 | A | G𝄪 |
| 10 | A♯ / B♭ |  |
| 11 | B | C♭ |

C<sub>3</sub>, C<sub>4</sub>, B♯<sub>5</sub>는 모두 0으로 적음. 음고의 실제 옥타브와 음이름의 철자는 지우고, 한 옥타브 안에서 어느 반음 위치를 차지하는지만 남긴 결과임. 시계로 보면 11시 다음에 0시가 오듯이 계산할 수 있어 이후 음정류와 음류 집합 분석에 편함.

## 직접 확인하기

아래를 정수 표기로 바꿔 보면 됨.

1. E♭, D♯, E♭<sub>5</sub>는 모두 몇인가?
2. F♯<sub>2</sub>와 G♭<sub>7</sub>은 같은 음고인가, 같은 음류인가?
3. C–E–G를 정수로 적으면 0–4–7이 됨. C<sub>2</sub>–E<sub>5</sub>–G<sub>3</sub>로 옥타브를 바꾸면 어떻게 되는가?

원문은 정수·음이름·오선보를 서로 바꾸는 <a href="https://viva.pressbooks.pub/app/uploads/sites/12/2021/08/WK-Pitch-and-Pitch-Class.mscz" target="_blank">MuseScore 연습 파일(.mscz)</a>도 제공함. 파일을 MuseScore에서 열면 음류와 실제 음고를 따로 적어 보는 연습을 할 수 있음.

후기조성 음악은 한 가지 방식으로 재단하기 어려움. 작곡가마다 음고를 다루는 방법과 미학이 다르며, 드뷔시처럼 준조성 음악은 이명동음을 언제나 같은 것으로 보지 않는 분석이 더 잘 맞을 수도 있음. 분석하다 어긋나면 음류만 고집하지 말고 음이름, 옥타브, 성부 진행을 함께 살펴보는 편이 나음.
