스키마는 선율 한 줄만 보고 찾기 어려움. 윗성부가 같아도 베이스가 다르면 다른 스키마일 수 있고, 같은 음들이라도 강박과 약박의 위치가 바뀌면 쓰임이 달라질 수 있음. 그래서 윗성부·베이스·박을 함께 봐야 함.

아래 표는 스키마 23개를 곡에서 맡는 일에 따라 묶었음. 먼저 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">기능</code> 열에서 도입·연결·종지 가운데 어느 자리에 쓰이는지 확인함. 그다음 선율과 베이스를 함께 부르고, <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">박</code>과 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">숫자저음</code>을 살펴보면 됨. 예를 들어 마이어의 윗성부는 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">도–시–파–미</code>, 베이스는 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">도–레–시–도</code>임. 첫 도는 약박, 다음 시는 강박에 놓이며 네 단계를 지나 으뜸화음으로 돌아옴.

표의 음은 특정 조의 음이 아니라 음계 안의 자리임. C장조의 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">도–시–파–미</code>를 다른 장조로 옮겨도 같은 마이어가 됨. <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">S</code>는 강박, <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">W</code>는 약박, <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">♯4</code>와 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">♭7</code>은 올린 제4음과 내린 제7음임.

## 도입형


### 로마네스카

윗성부는 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">도–솔–도–도</code>, 베이스는 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">도–시–라–미</code>로 움직임. 화음은 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">I–V6–vi–I6</code>로 이어지고 강박과 약박이 번갈아 나옴.


### 도–레–미

윗성부의 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">도–레</code>가 질문처럼 들리고 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">레–미</code>가 그 뒤를 받음. 이때 베이스는 먼저 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">도–시</code>, 다음에는 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">시–도</code>로 움직임. 화음도 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">I–V6</code>에서 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">V6–I</code>로 돌아옴. 세 단계로 쓰면 가운데 레와 시를 두 부분이 함께 사용함. 가운데 단계를 한 번 더 되풀이하면 네 단계로 늘어남.


### 솔–파–미

윗성부의 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">솔–파</code>가 구절을 열고, 이어지는 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">파–미</code>가 으뜸화음으로 돌아옴. 기본 화음은 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">I–ii–V6/5–I</code>임. 둘째 화음을 바꾸면 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">I–vii6–V6/5–I</code>로도 쓸 수 있음.


### 마이어·아프릴레·주피터·파스토렐라

네 스키마 모두 으뜸화음에서 출발하고, 두 단계를 거쳐 다시 으뜸화음으로 돌아옴. 윗성부를 보면 서로 구별하기 쉬움. 마이어는 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">도–시–파–미</code>, 아프릴레는 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">도–시–레–도</code>, 주피터는 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">도–레–파–미</code>, 파스토렐라는 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">미–레–파–미</code>로 움직임.


## 응답·전개·연결형


### 프리너와 전조 프리너

프리너에서는 윗성부와 베이스가 나란히 내려가며 두 성부 사이의 10도를 유지함. 셋째 단계의 7도가 6도로 내려온 뒤, 근음 위치의 딸림화음을 한 번 거쳐 으뜸화음으로 가면 네 단계가 다섯 단계로 늘어남. 전조 프리너도 마지막 딸림화음 앞에 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">V/V</code>를 넣어 같은 방식으로 늘릴 수 있음.


### 폰테(Fonte)

폰테는 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">V6/5–I</code>로 닫히는 짧은 진행을 두 번 되풀이함. 첫 진행은 원래 조의 ii를 잠시 으뜸화해 단조로 들림. 둘째 진행은 한 음 아래에서 시작해 원래 장조의 으뜸화음으로 돌아옴. 두 진행 모두 윗성부는 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">파–미</code>, 베이스는 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">시–도</code>로 움직임. 마이어의 뒤 절반과 닮았고 5도권 진행과도 가까움.


### 몬테(Monte)

몬테도 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">V6/5–I</code>로 닫히는 짧은 진행을 두 번 이어 붙임. 폰테는 두 번째 진행이 아래로 내려가지만, 몬테는 위로 올라감. 한 진행 안에서는 윗성부가 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">솔–파</code>, 베이스가 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">시–도</code>로 움직임.


### 폰테(Ponte)

베이스는 딸림음 솔에 머물고, 그 위에서 선율이 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">솔–시–레</code>로 펼쳐짐. 딸림화음의 긴장을 유지한 채 다음 구절로 넘어가거나 종지를 준비할 때 씀.


## 종지 준비형과 불완전한 종지

- <strong>페나롤리</strong>: 윗성부는 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">파–미–시–도</code>, 베이스는 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">시–도–레–미</code>로 움직임. 처음 두 단계에서는 윗성부가 내려가고 베이스가 올라가며, 뒤의 두 단계에서는 두 성부가 서로 자리를 바꾸듯 이어짐.

- <strong>인두조(Indugio)</strong>: 베이스가 버금딸림음 파에 세 단계 머문 뒤 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">올린 파–솔</code>로 올라감. 딸림음에 도착하는 일을 늦춰 종지 직전의 긴장을 오래 끎.

- <strong>위장종지(허위종지)</strong>: <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">V</code>가 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">vi</code>로 진행해 예상한 으뜸화음을 피함. 김홍인은 ‘위장종지’, 백병동은 ‘허위종지’라는 용어를 사용함.

- <strong>회피종지</strong>: 윗성부는 종지처럼 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">레–도</code>로 내려오지만, 베이스가 으뜸음 도 대신 미로 감. 그래서 근음 위치의 I이 아닌 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">I6</code>에 도착하며 완전히 닫히지 않음.

- <strong>파소 인디에트로(Passo Indietro)</strong>: 프리너의 처음 두 단계를 떼어 낸 형태임. 이름은 ‘뒤로 물러나는 걸음’을 뜻하며 중요한 종지 앞에 자주 놓임.

- <strong>콤마(Comma)</strong>: 선율 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">파–미</code>와 베이스 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">시–도</code>가 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">V6/5–I</code>를 만듦.

- <strong>수렴 반종지</strong>: 윗성부는 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">미–레–도–시</code>로 내려오고 베이스는 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">미–파–올린 파–솔</code>로 올라가 딸림화음에 모임. 베이스의 마지막 세 음을 따서 ‘파–피–솔 반종지’라고도 부름. 인두조와 서로 대응하는 진행임.


## 종지형과 종지 뒤 유형

- <strong>단순종지(Cadenza Semplice)</strong>: 선율 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">도–레–레–도</code>, 베이스 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">미–파–솔–도</code>가 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">I6–ii6/5–V–I</code>를 이룸.

- <strong>복합종지(Cadenza Composta)</strong>: 단순종지의 딸림화음 앞에 종지적 6/4화음을 넣고 딸림화음에는 7음을 더함. 전체 화음은 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">I6–ii6/5–Cad.6/4–V7–I</code>로 이어짐.

- <strong>이중종지(Cadenza Doppia)</strong>: 베이스가 딸림음에 머무는 동안 윗성부가 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">5–6/4–4–3</code>의 음정을 차례로 만듦. 마지막에는 베이스가 으뜸음으로 가며 종지를 맺음.

- <strong>퀴에셴차(Quiescenza)</strong>: 정격종지가 이미 끝난 뒤에 붙이는 음형임. 베이스는 으뜸음에 머물고 윗성부와 화음은 <code style="background: rgba(135,131,120,0.15); color: #EB5757; padding: 2px 5px; border-radius: 3px;">♭7–6/4–7/4/2–5</code>로 움직인 뒤 다시 으뜸화음에 닿음.
