### <span class="notion-text-purple">Open Music Theory</span>

<span class="notion-text-gray">Open Music Theory 한글판 · dcinside digital piano gallery</span>

---

Open Music Theory 원문 용어집은 교재 전 장에서 쓰는 말을 알파벳순으로 모은 생성형 색인임. 기보·리듬·대위법·화성·형식·재즈·대중음악·집합 이론·관현악법·청음까지 한 목록에 들어가므로, 한 용어가 어느 장에서 어떤 뜻으로 쓰였는지 먼저 확인하는 데 쓸 수 있음.

한국어판에서는 같은 말을 따로 떼어 영한 사전식으로 반복하지 않고, 해당 개념을 처음 다루는 글에서 설명함. 이 사이트의 검색으로 한국어 용어를 찾거나 아래 길을 따라가면 됨.

- <strong>기보·음정·스케일·리듬</strong>: <a href="/음악-이론/open-music-theory/01-기초편/">01. 기초편</a>
- <strong>대위법·갈랑 양식·푸가</strong>: <a href="/음악-이론/open-music-theory/02대위법과-갈랑-양식/">02. 대위법과 갈랑 양식</a>
- <strong>2진·3부분 형식과 소나타 형식</strong>: <a href="/음악-이론/open-music-theory/03형식/">03. 형식</a>
- <strong>온음계·반음계 화성, 기능·전위·종지</strong>: <a href="/음악-이론/open-music-theory/04-온음계-화성과-프레이즈-모델/">04. 온음계 화성과 프레이즈 모델</a>, <a href="/음악-이론/open-music-theory/05-반음계-화성/">05. 반음계 화성</a>
- <strong>재즈·대중음악</strong>: <a href="/음악-이론/open-music-theory/06-재즈-이론/">06. 재즈 이론</a>, <a href="/음악-이론/open-music-theory/07-대중음악/">07. 대중음악</a>
- <strong>음고류·노멀 폼·프라임 폼·음정류 벡터·12음 기법</strong>: <a href="/음악-이론/open-music-theory/08-20세기와-21세기-기법/">08. 20세기와 21세기 기법</a>, <a href="/음악-이론/open-music-theory/09-12음-음악/">09. 12음 음악</a>
- <strong>관현악법·상위박자·그래픽 기보</strong>: <a href="/음악-이론/open-music-theory/10-관현악법/">10. 관현악법</a>, <a href="/음악-이론/open-music-theory/11-리듬과-박자/">11. 리듬과 박자</a>, <a href="/음악-이론/open-music-theory/15-개발-중-장/">15. 개발 중 장</a>

원문 용어집은 `ground bass`, `hypermetric reinterpretation`, `set class`처럼 영어 원어가 필요한 논문·강의자료를 읽을 때 함께 열어 두면 좋음. 다만 원문 용어 하나가 한국어 용어 하나와 늘 완전히 맞물리지는 않음. 예를 들어 원문의 `ground bass`는 이 사이트에서 <strong>그라운드 베이스</strong>로 쓰고, `figured bass`는 <strong>숫자저음</strong>으로 구분함. 실제 분석에서는 단어만 맞춰 보지 말고, 해당 글의 예제와 쓰임을 함께 확인해야 함.
