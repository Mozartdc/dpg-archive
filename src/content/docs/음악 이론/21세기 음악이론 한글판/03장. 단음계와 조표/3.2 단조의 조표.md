단조 조표는 자연단음계의 음과 맞음. C자연단음계에는 E♭, A♭, B♭이 들어가므로 C단조의 조표에는 내림표 세 개를 B♭–E♭–A♭ 순서로 적음.



<img src="/images/3.2-단조의-조표-0.svg" alt="C자연단음계의 3·6·7음을 조표에 옮긴 모습" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

단조 조표를 같은 으뜸음의 장조 조표와 비교하면 3·6·7음이 각각 반음 낮음. 으뜸음이 같은 장조와 단조의 관계를 병행조라고 부름. E장조의 병행단조는 E단조이고, F단조의 병행장조는 F장조임.

병행장조의 조표에 내림표 세 개를 더하면 병행단조의 조표를 구할 수 있음. 올림표를 기준으로 보면 세 개를 빼는 것과 같음.



<img src="/images/3.2-단조의-조표-1.svg" alt="병행장조의 조표에서 내림표 세 개를 더해 병행단조의 조표를 구하는 방법" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

오선 아래에 조를 짧게 적을 때는 장조를 대문자 C, 단조를 소문자 c로 구분함. 문장 안에서 조 이름을 쓸 때는 C major와 C minor처럼 둘 다 대문자로 시작함.

장조와 같은 조표를 쓰는 단조는 나란한단조(relative minor)임. E♭장조와 C단조는 모두 내림표 세 개를 쓰므로 서로 나란한조 관계임. C단조에서 보면 E♭장조가 나란한장조가 됨. 나란한장조의 으뜸음은 나란한단조의 으뜸음보다 반음 세 개 위에 있음.



<img src="/images/3.2-단조의-조표-2.svg" alt="E♭장조에서 반음 세 개 내려가면 나란한단조인 C단조가 됨." style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

아래 악보에는 모든 단조 조표가 모여 있음.



<img src="/images/3.2-단조의-조표-3.svg" alt="모든 단조 조표" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

장조와 단조의 5도권을 나란히 비교하면 같은 조표를 쓰는 나란한조를 찾기 쉬움.



<img src="/images/3.2-단조의-조표-4.svg" alt="단조의 5도권" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />



<img src="/images/3.2-단조의-조표-5.svg" alt="장조의 5도권" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

단조 조표는 자연단음계를 기준으로 적음. 화성단음계를 쓰려면 7음을 임시표로 반음 올림. 상행 가락단음계에서는 6음과 7음을 반음 올리고, 하행할 때는 다시 자연단음계로 돌아감.



<img src="/images/3.2-단조의-조표-6.svg" alt="단조 조표로 화성단음계와 가락단음계를 적는 방법" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

실제 단조 작품은 세 가지 단음계 가운데 하나만 고집하지 않음. 자연·화성·가락단음계는 작곡가들이 실제로 써 온 음의 움직임을 세 가지 형태로 추려 놓은 것임.
