주어진 음의 위에 완전음정, 장음정, 단음정을 쓸 때도 음정을 구별할 때 쓴 두 방법을 그대로 적용하면 됨.

A 위에 단6도를 쓴다고 해 보겠음. 먼저 A장음계의 조표를 떠올림. A장음계의 여섯째 음 F♯은 A 위의 장6도임. 단6도는 장6도보다 반음 좁으므로 F♯을 반음 낮춘 F♮을 적으면 됨.



<img src="/images/5.3-음정-쓰는-방법-0.svg" alt="A 위에 단6도 쓰기" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

반음 수를 세어도 됨. 단6도는 반음 여덟 개이므로 A에서 위로 여덟 반음을 세면 F에 닿음.

주어진 음의 아래에 장3도까지의 작은 음정을 쓸 때는 온음과 반음을 조합하면 어렵지 않음. 더 큰 음정을 아래에 써야 한다면 먼저 음정을 전위해서 계산하는 편이 편함. <a href="/음악-이론/21세기-음악이론-한글판/05장-음정/54-음정의-전위/" style="color: inherit; text-decoration: underline;">음정의 전위</a>는 다음 절에서 다룸.
