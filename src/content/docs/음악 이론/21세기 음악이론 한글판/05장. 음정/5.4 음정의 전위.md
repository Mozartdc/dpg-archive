음정은 아래음과 위음, 두 음으로 이루어짐. 아래음을 한 옥타브 올리거나 위음을 한 옥타브 내리면 두 음의 자리가 뒤바뀜. 이 과정을 전위(Inversion)라고 함.



<img src="/images/5.4-음정의-전위-0.svg" alt="음정의 전위" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

단6도를 전위하면 장3도가 됨. 어떤 음에서 시작해도 단6도와 장3도는 서로 전위 관계임.



<img src="/images/5.4-음정의-전위-1.svg" alt="보표에서 확인하는 음정의 전위" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

감음정은 °, 증음정은 + 기호로 줄여 씀. 감음정은 완전음정이나 단음정보다 반음 좁고, 증음정은 완전음정이나 장음정보다 반음 넓음.

음정을 전위하면 두 도수의 합은 9가 됨. 1도와 8도, 2도와 7도, 3도와 6도, 4도와 5도가 서로 전위됨. 성질도 다음처럼 바뀜.


| 전위 전 | 전위 후 |
| --- | --- |
| 완전 | 완전 |
| 장 | 단 |
| 단 | 장 |
| 증 | 감 |
| 감 | 증 |



<img src="/images/5.4-음정의-전위-2.svg" alt="음정 전위표" style="max-width: 100%; height: auto; border-radius: 4px; display: block; margin: 10px 0;" />

주어진 음의 아래에 완전4도까지의 작은 음정을 쓸 때는 온음과 반음을 직접 조합할 수 있음. 더 큰 음정은 먼저 전위한 도수를 위쪽에서 구한 뒤, 같은 음을 아래쪽에 적으면 편함.
