케이던스(Cadence)는 화성이 잠시 도착하고 멈추는 지점임. 글의 쉼표나 마침표처럼 짧은 구절을 귀로 정리할 틈을 줌. 여기서는 네 가지 기본형을 구별함.


| 종류 | 끝의 코드 |
| --- | --- |
| 정격 케이던스(AC) | V–I |
| 변격 케이던스(PC) | IV–I |
| 거짓 케이던스(DC) | V–vi가 대표적임 |
| 반 케이던스(HC) | V에서 끝남 |

록과 팝에서는 3음 없이 근음과 5음만 연주한 코드를 볼 수 있음. 리드 시트에서는 근음 뒤에 5를 붙여 B5처럼 적음.

근음과 3음만 있고 5음이 빠진 코드는 불완전 코드(Incomplete Chord)라고 부름.

Justin Bieber의 〈Love Yourself〉 예시에는 이런 코드가 나옴.
